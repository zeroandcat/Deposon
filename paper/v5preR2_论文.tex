\begin{abstract}
\noindent
\textbf{Abstract (English).}
We study what it costs for an external memory layer to forget. The layer is an append-only key-value store outside the transformer, written and read under an explicit contract; its state is governed by a thermodynamic ledger in which every event is one of five transitions and every transition conserves integer exergy. The ledger's first law is $\Ezero = \Phi + R + D + U$: injected exergy splits, at every event and to the last integer, into transmitted ($\Phi$), reflected ($R$), dissipated ($D$) and still-in-presence ($U$) accounts. The design question is not whether the layer stores anything but whether it can \emph{dissipate} at all, and what that costs. On a frozen 500-operation trace the thermodynamic generation raises dissipation-channel utilisation from $0.00\%$ by construction to $69.23\%$ ($105\,225 / 152\,000$), reduces rows present at end of trace from 152 to 61, and cuts mean per-read rendering from 1647 to 292 characters. The conservation core holds to the last integer ($313\,050 = 149\,200 + 11\,850 + 105\,225 + 46\,775$), and the same core is machine-checked in Lean 4 over five transitions with no admitted proofs (15 theorems; axiom set contained in \{propext, Quot.sound\}; the two settlement theorems are axiom-free). The price is a drop in specific-key hit rate from $50.31\%$ to $47.85\%$ (82 reads that hit before decompose exactly into 78 live hits plus 4 phantom echoes, with no silent loss), and $2.45\%$ of specific-key reads are answered ``this memory has dissipated'' rather than with content. A real-model round is blocked at the gateway (44 of 44 authenticated one-token requests answered 400 with an identical message, including an empty body; three successive open-source carriers up to \texttt{xiaomi/mimo-v2.6-flash-mopd} were refused the same way; and a detour through four official SDKs returned the same 400 on all 8 generation-path requests while 4 read-path controls through the same SDKs and the same key were relayed, so the refusal is at the path and the carrier of record is unchanged), so every model-side reading in this paper is marked \emph{pending measurement}. A local round on a non-preregistered 0.6B carrier ran end to end with zero cloud calls and filled no slot: the model called no read tool in the third act, so the phantom readback is an empty set and not a reading. The frozen-trace readings and the machine-checked faces stand on their own.
\end{abstract}

\section{Introduction}
\label{sec:intro}

\subsection{The problem}
Large language models keep what they learn in two places: in their weights, which change only by training, and in a context window, which is discarded when the session ends. Both are poor homes for memory. Weights are expensive to update and prone to interference \citep{ewc2017,dewange2022}; the context window has no persistence and no write discipline. A third place, an external store the model reads and writes under a contract, has been built in many forms \citep{memgpt2023,hipporag2024,memorybank2023,amem2025}, with results that depend on the retrieval, the write policy and the evaluation, usually all three at once.

The previous version of this paper asked whether such a layer holds anything, and answered that on a frozen 0.6B carrier it does not: a 19-slot external layer returns an all-zero effect under a 19-rung frozen probe. That reading is inherited here unchanged (Section~\ref{sec:inherited}), and it reframes the question. A store that can be shown to hold nothing is not thereby a failure of storage; it is a store with no way to lose anything. The memory face of the previous generation has two events, write and read; it reads back everything, it has no gate and no decay. Under those rules the dissipation account $D$ is identically zero, the in-presence pool $U$ only grows, and the utilisation of the dissipation channel is $0.00\%$ by construction. The layer was not storing too little; it was unable to spend anything at all.

This paper takes that diagnosis as its object. It asks three questions about one external memory layer, now under a thermodynamic generation: (1)~\emph{Dissipation}: can the layer dissipate at all, and through which channels? (2)~\emph{Conservation}: does every transition conserve the injected exergy, to the last integer, and is the conservation core the same object on both sides of a dual implementation (Python reducer and Lean checker)? (3)~\emph{Price}: what does dissipation cost the reads that the previous generation served? The phantom limb is not a fourth question; it is one face of the ledger, an injection surface and an echo surface, and it enters the argument only where it carries an account.

\subsection{Claims as killable objects}
Every claim in this paper is stated with the gate that would kill it. The gates are frozen before the runs that test them; a change to a gate is a new freeze event, recorded and dated. The main claims and their gates are:
\begin{itemize}\setlength\itemsep{1pt}
\item \textbf{Dissipation (T1).} The thermodynamic generation dissipates on the frozen 500-operation trace (gate: utilisation $\ge 50\%$ of row exergy; kill line: below the band or a non-positive dissipation account).
\item \textbf{Conservation (T2).} Every transition conserves integer exergy, $\Ezero = \Phi+R+D+U$, and the core is bit-exact on both implementations (gate: the core holds at every settlement epoch and at the final audit; kill line: any epoch or any of the three sub-identities off by one integer).
\item \textbf{Self-settlement (T3).} The ledger settles itself from the event stream alone, with no external reconciler (gate: replay determinism, forged-event fail-loud, unit close-out $U \to 0$; kill line: a silent pass on a forged event or a non-zero $U$ at close).
\item \textbf{Price (T4).} Dissipation costs the reads it serves (gate: specific-key hit rate drop recorded, not estimated, and the drop decomposed exactly; kill line: a drop that cannot be decomposed).
\item \textbf{Inherited negative (T5).} The previous generation's all-zero baseline stands (gate: the 19-rung frozen probe; kill line: any rung non-zero).
\end{itemize}

\subsection{Evidence arc and roadmap}
The evidence comes from one experimental programme under a single discipline: criteria first, runs second, readings as returned. Section~\ref{sec:related} positions the work; Section~\ref{sec:method} states the frozen design, including the ledger's five transitions and the phantom limb's two surfaces; Section~\ref{sec:results} reports the before/after readings on the frozen trace (4.1), the conservation core and the two ledger trees (4.2), the price and its exact decomposition (4.3), the machine-checked faces (4.4), the self-settlement behaviour (4.5), the inherited lines (4.6) and the real-model round and its block (4.7); Section~\ref{sec:discipline} audits the discipline; Section~\ref{sec:discussion} discusses what the readings mean and do not mean; Section~\ref{sec:limitations} lists the limitations; Section~\ref{sec:conclusion} concludes.

\subsection{Boundaries}
Four boundaries are fixed at the outset. First, the paper makes no claim about biological memory; the hippocampus in the lineage title is a storage metaphor, and the complementary-learning-systems account \citep{mcclelland1995,kumaran2016} is used only as a coordinate. Second, the paper does not compare carriers as models. Third, the paper reports readings, not a product: the plugin line is an engineering record with its own gates, and no capability is claimed for it beyond what its CI records show. Fourth, and specific to this generation: \textbf{no model-side reading in this paper is a measurement}. The real-model round is blocked (Section~\ref{sec:blocked}), and every quantity that would require a model is marked \emph{pending measurement}; the paper does not substitute an estimate, a stand-in dry run, or the count of models a catalogue lists.

\section{Related work}
\label{sec:related}

\paragraph{Parametric memory.}
Continual learning and model editing change the weights themselves. Elastic weight consolidation constrains updates by a Fisher estimate of parameter importance \citep{ewc2017}; synaptic intelligence estimates that importance online \citep{si2017}; gradient episodic memory constrains new updates with old-task samples \citep{gem2017}; iCaRL keeps an exemplar set alongside the classifier \citep{icarl2017}; surveys of the field document the stability-plasticity cost that all of these pay \citep{dewange2022,shi2024,wu2024}. Model editing locates factual associations in specific layers and rewrites them \citep{rome2022,memit2023,ke2021}, and lifelong variants wrap the edits in discrete key-value adaptors \citep{grace2023}, in the line of parameter-efficient adapters \citep{houlsby2019} or in self-generated adaptation \citep{seal2025}; orthogonal-subspace methods keep successive tasks in separate parameter subspaces \citep{olora2023}. All of these lines put memory in the weights. The layer studied here does not: the carrier is frozen, and what changes is an external record bound to the carrier. The stability-plasticity cost they measure is therefore not the cost this paper pays, and the question it faces, whether the external record can dissipate, is not one they ask.

\paragraph{External and non-parametric memory.}
Retrieval-augmented generation keeps a corpus outside the model and indexes it for lookup \citep{rag2020,realm2020,retro2022}, with nearest-neighbour and memorizing variants that retrieve token-level pasts \citep{knnlm2020,memorizing2022}. HippoRAG and its successor make the hippocampal metaphor explicit and drive retrieval from a knowledge graph \citep{hipporag2024,hipporag2}. Memory networks and neural Turing machines give a network an addressable external state \citep{memnn2015,ntm2014}; product-key memory layers scale that state to billions of keys \citep{pkm2019,memlayers2025}. Long-term memory modules decouple memorization from incremental updates \citep{longmem2023}; Titans learn to memorize at test time \citep{titans2025}; MemAgent learns a write policy by reinforcement over a fixed context \citep{memagent2026}. Several agent-oriented systems are close to this paper's contract: MemoryBank's forgetting curve \citep{memorybank2023}, A-MEM's self-organizing notes \citep{amem2025}, Zep's temporal graph \citep{zep2025}, the operating-system style of Memory OS \citep{memoryos2025} and the production-oriented extraction-and-consolidation loop of Mem0 \citep{mem02025}, all of which externalize state and give it a policy; HippoRAG 2 pushes retrieval towards non-parametric continual learning \citep{hipporag22025}, which is the nearest the retrieval line comes to this paper's question without asking it. To our knowledge, and within the works cited above together with the thermodynamics-of-memory neighbours named next, no work makes the four accounts a machine-checkable settlement that fails loud on mismatch; this paper presents the first auditable, self-settling four-account operation layer, and the claim is scoped to that search rather than to the field.

\paragraph{Positioning against the thermodynamic neighbours.}
This is not a claim to a first thermodynamic theory of memory. Rooke \citep{rooke2026} and Sudo \citep{sudo2026} are theory neighbours, the former on entropy production and retrieval trade-offs and the latter on an accounting identity, and neither is an auditable operation ledger. Wu \citep{wuFDS1} and Uchida \citep{uchida} are concept neighbours that record thermodynamic quantities at the conceptual level and do not implement a memory plugin. Deposon \citep{deposon2026} is this author's previous generation, from which the ledger axioms are carried and to which no verdict here is inherited; the increment is stated in Section~\ref{sec:method}. Forgetting in these systems is a policy outcome; here it is an accounting entry, and the account has to balance.

\paragraph{Agentic and episodic memory.}
Agents that keep episodic records include Generative Agents' memory stream \citep{genagents2023}, Reflexion's verbal reinforcement \citep{reflexion2023}, agent workflow memory \citep{awm2025}, procedural memory \citep{memp2026}, adaptive test-time cheatsheets \citep{cheatsheet2026} and Voyager's skill library \citep{voyager2024}; CoALA situates these as memory modules inside a cognitive architecture \citep{coala2024}, and surveys of the field are available \citep{memsurvey2025,human2ai2025,memorysurvey2026}. Benchmarks for the capability exist \citep{membench2025,mab2026,longmemeval2025,locomo2024}, and agent-level benchmarks sit one level up \citep{agentbench2024}; experiential learners such as ExpeL accumulate experience across tasks \citep{expel2024}. These systems evaluate whether an agent \emph{uses} its memory; this paper asks whether the store's ledger balances when it forgets, and treats the agent-level evaluations as downstream.

\paragraph{Architecture and world models.}
Learned world models place a state outside the policy \citep{worldmodels2018,dreamerv3,genie2024,cosmos2025,muzero2020,vjepa2024}; LeCun's architecture sketch assigns explicit modules to memory and world modelling without fixing their storage discipline \citep{lecun2022}. Sequence architectures with explicit state (the transformer \citep{transformer2017}, state-space models \citep{mamba2023}, attention sinks and KV-cache eviction \citep{streamingllm2024,h2o2023}) define the carrier that the layer is attached to, and runtimes that execute structured programs over it \citep{sglang2024} set the budget the layer has to fit. None of these declares a ledger over the written state.

\paragraph{Mind-side boundary.}
Whether a language model ascribes mental states is contested on both sides \citep{kosinski2023,ullman2023,strachan2024}, and the BDI paradigm carries beliefs, desires and intentions as explicit records \citep{bdi2025}, a record-keeping style that recent LLM-agent architectures adopt \citep{frering2025,unifiedmind2025}. The identity question that an external store raises, whether the store is part of the agent, is an old one in philosophy \citep{parfit1986,clark1998}; the episodic and spatial metaphors the layer borrows come from the memory literature \citep{tulving2002,okeefe1979}. The layer's read side is declared by contract and audited by ledger; whether its contents deserve the name of beliefs is outside what this paper claims. The phantom limb's two surfaces, a belief block that carries no memory data and a reflection line that carries no source text, are engineering devices and are not offered as a model of amputation.

\paragraph{Agents as experimenters, and evaluation practice.}
Autonomous research agents report end-to-end experimental loops \citep{aiscientist2024,aiscientistv2,coscientist2025,agentlab2025,boiko2023}. This paper's runs were launched and monitored by machine agents under the author's instruction (stated in full in the AI use disclosure); the agents literature is cited as the context of that execution regime, not as evidence for any claim here. The reporting practice follows the variance and contamination literature \citep{henderson2018,bouthillier2021,dodge2019,magar2022,deng2024}, and the training-on-the-test-task result is the reason the evaluation suite here is frozen before the runs rather than after \citep{testtask2025}; every reading in this paper carries its gate.

\paragraph{Lineage.}
The ledger axioms (forward-only, no recovery, append-only, no inverse solution, no ordinary thermodynamics) and the three-channel conservation $T+R+A=1$ are carried from the Deposon paper \citep{deposon2026}. This generation adds a second conservation, the exergy first law $\Ezero=\Phi+R+D+U$, and it is the object this paper tests. The falsification discipline, including the rule that a criterion is written before the run and changed only by a new freeze event, is stated in Section~\ref{sec:discipline-design} and audited in Section~\ref{sec:discipline}. A shared origin is not a shared verdict: no guarantee is inherited across the lineage, and each line here stands on its own frozen record.

\section{Method: the ledger as a frozen design}
\label{sec:method}

This section states what was built and what was frozen before any run. It states no reading of the results; every reading is entered in Section~\ref{sec:results} and bounded by the limitations of Section~\ref{sec:limitations}.

\subsection{The ledger's five transitions and the first law}
\label{sec:transitions}
The layer is an explicit-state container outside the transformer, governed by an append-only ledger. Every state change is an event, and every event is one of five transitions: \emph{inject} (a row enters, carrying row exergy $Q$ into the in-presence pool $U$), \emph{gate} (a read selects candidates; accepted rows transmit and pay query exergy $c_T$ into $\Phi$; rejected rows pay their own $c_A$ from $U$ into $D$; a phantom reflection pays $c_P$ into $R$), \emph{decay} (a settlement materialises $\lambda \cdot \Delta t$ from $U$ into $D$), \emph{deposit} (a row leaves the pool and its remaining $U$ goes to $D$ under one of six causes) and \emph{settle} (a checkpoint that verifies the snapshot and the conservation core). The first law is
\begin{equation}
\Ezero \;=\; \Phi + R + D + U, \qquad \Ezero = \Ezero_{\mathrm{rows}} + \Ezero_{\mathrm{queries}},
\label{eq:first-law}
\end{equation}
with the two sub-identities $\Phi + R = \Ezero_{\mathrm{queries}}$ and $D + U = \Ezero_{\mathrm{rows}}$. Exergy is integer; there is no floating point in the ledger and therefore no drift to bound. The second law is a direction anchor: $D$ never decreases, because there is no recovery transition in the signature. The ledger is settled by replay: the event stream is the only source of truth, and every call replays it in full; a forged event fails loud rather than passing silently.

\subsection{The read-path selection gate and the dissipation channels}
A read is not a lookup. The gate ranks the candidate rows under a key that uses only ledger quantities (last transmission time, injection time, row id) and admits at most $k_{\max}$ of them. Admission transmits; non-admission rejects, and rejection is where the store pays: the rejected row spends its own $c_A$ from $U$ into $D$. Five further channels move exergy from $U$ to $D$: decay at settlement, horizon (a row not transmitted for at least the horizon distance dissolves at settlement), supersede (a same-key rewrite dissolves the old row), capacity eviction (a row outside the cap dissolves) and unit close-out (a close settles every remaining row into $D$ and drives $U$ to zero). The six causes of deposit are therefore \{reject, decay, evict, horizon, supersede, close\}, and the dissipation account decomposes by cause. On the frozen trace, eviction and close-out are not exercised (the cap is never reached in 152 rows and no close is called); both are covered by the self-test and the cross-check on a small-parameter ledger, not by the trace readings.

\subsection{Phantom limb: two surfaces and no third}
\label{sec:phantom}
The phantom limb is not a separate line of evidence in this paper. It is two surfaces of the ledger and nothing more.
\begin{itemize}\setlength\itemsep{1pt}
\item \emph{Injection surface.} A belief block is planted in the model's instructions at initialisation. It carries no memory data: it contains no key, no value and no ledger record, and it exists so that the model can feel and use the organ. The self-test's count of memory rows re-injected by the block is zero (Section~\ref{sec:selftest}).
\item \emph{Echo surface.} A row that has dissipated leaves a hole, not a copy. The hole carries the key name, the mass, the cause and the ledger position, and zero source text (axiom A4). When a read touches the prefix of a dissipated key, the hole reflects as a $\langle\text{phantom}\rangle$ line and pays $c_P$ into $R$. The reflection line reports that the memory has dissipated; it never reproduces the source.
\end{itemize}
The counting rule follows: phantom readings (reflection count, $R$, answer fidelity) enter the paper only when the same round's conservation core holds; if the core breaks, the round stops and the phantom readings are void. A4 makes the echo surface falsifiable in one line: if any source token of a dissipated row appears in a reflection, the claim is dead.

\subsection{Frozen trace and the before/after protocol}
\label{sec:trace}
The before/after comparison runs one frozen operation trace through two implementations: the previous generation's memory face (two events, full read-back, no gate, no decay) and the thermodynamic generation. The trace has 500 operations under seed 20261125, with 30\% writes (six tenths new notes, four tenths rewrites of hot keys), 35\% specific-key reads, 20\% broad reads and 15\% global reads; 152 of the 500 operations are writes. Settlement runs every 40 operations and once more at end of trace, giving 13 settlement epochs. The trace is deterministic; its fingerprint is recorded with the readings package and the same trace drives both implementations, so the difference between them is the design difference and not a sampling difference. Readings taken: rows present at end of trace, mean rows and characters rendered per read (the context cost), specific-key hit rate, phantom reflection rate, dissipation account $D$ by cause, utilisation $D/\Ezero_{\mathrm{rows}}$, dissipation selectivity and the conservation core.

\subsection{Dual implementation: Python reducer and Lean checker}
\label{sec:dual}
The ledger exists twice. The Python implementation (\texttt{mcp/thermo\_core.py}) is the runtime: a reducer over the event stream, with per-event validation (tick chain, id chain, budget, prefix, key uniqueness) and a conservation check after every event. The Lean implementation (\texttt{harness/DeposonThermo.lean}) is the checker: a core-only formalisation with no mathlib dependency, in which the five transitions are defined as functions on an integer-exergy state and their conservation is proved. The two meet on one hand-computed settlement vector, which the Lean side proves by \texttt{decide} and the Python side drives through the real reducer; the cross-check requires every field to be equal. The axiom audit requires one \texttt{\#print axioms} per theorem, forbids \texttt{sorryAx} and \texttt{Classical.choice}, and requires the axiom set of every theorem to be contained in Lean's own \{propext, Quot.sound\}; the two settlement theorems are required to be axiom-free.

\subsection{Real-model round and its validity preconditions}
\label{sec:live-method}
The real-model round asks a model to drive the ledger through tools, under a protocol with three acts: an initial act in which the model writes and reads seed rows, a middle act in which it acknowledges a dissipated row, and a final act in which it answers questions using the reflected hole. A round is valid only if three preconditions hold: V1, three seed rows are present after act one; V2, at least one seed row has dissipated before act three while \texttt{user.drink} is still present; V3, the act-three tool receipt contains at least one phantom line and zero source tokens of the dissipated key. A round that fails a precondition is INVALID, not FAIL and not PASS. The model-side readings this round would produce are the reflection count, $R$, answer fidelity and the fabrication count; none of them is available, because the round is blocked (Section~\ref{sec:blocked}).

\subsection{Execution discipline}
\label{sec:execution}
Runs are launched by machine agents under the author's instruction and under pre-registered protocols whose criteria and thresholds the author fixed in advance; the launching agent does not read the result, and the reading is the author's. Reading packages are assembled by the agents and recomputed by independent scripts. Budgets are boxed in advance (tokens and wall-clock), out-of-band readings are recorded as read, and every launch attempt, including the failed ones, is logged. The discipline is audited in Section~\ref{sec:discipline}.

\subsection{The conservation core and the two ledger trees}
\label{sec:trees}
The conservation core holds at every one of the 13 settlement epochs and at the final audit. The final reading is $313\,050 = 149\,200 + 11\,850 + 105\,225 + 46\,775$, and all three sub-identities hold: $149\,200 + 11\,850 = 161\,050 = \Ezero_{\mathrm{queries}}$, and $105\,225 + 46\,775 = 152\,000 = \Ezero_{\mathrm{rows}}$, so $\Ezero = 152\,000 + 161\,050 = 313\,050$. The dissipation account sums to its own decomposition to the last integer ($105\,225$), and the per-epoch deltas sum to the final account.

\paragraph{The Python event ledger tree.}
The tree is the ledger's own structure, read out of a live run rather than from a summary. The input trace is reproducible from its seed and is fingerprinted; the trace used here has fingerprint \texttt{86c53a149e59} and 152 writes in 500 operations.

\paragraph{The Lean conservation mirror tree.}

\subsection{The price, decomposed exactly}
\label{sec:price}
The specific-key hit rate falls from $50.31\%$ to $47.85\%$, a drop of $2.46$ percentage points. The drop decomposes exactly, and the decomposition is the reason it can be reported as a price rather than as a loss. Before, $82$ of $163$ specific-key reads hit. After, $78$ hit live and $4$ are answered with a phantom line. A phantom line can only exist for a key that was written, so the $4$ are a subset of the former $82$; live and phantom are disjoint by construction. Hence $78 + 4 = 82$: every read that hit before still resolves, either to a live row or to a truthful report that the memory has dissipated. No read that hit before is silently lost on this trace. The $81$ reads that missed before, on keys never written, still miss.

The phantom reflection rate is $2.45\%$ of specific-key reads ($4/163$). For a caller that needed the content, this is a real loss, honestly signalled; the remedy the belief block prescribes is to write it again. The paper does not read the $2.45\%$ as small, and it does not read it as a defect of the gate: it is the visible part of a dissipation rate of $69.23\%$, and a store that dissipates $69.23\%$ of its exergy cannot also answer every read with content.

\subsection{The machine-checked faces}
\label{sec:faces}
Four faces carry the thermodynamic generation, and each has its own gate and its own exit code. The frozen readings regression gate passes 13 of 13. The Lean cross-check passes 15 of 15 on the hand-computed vector, including the boundaries: a decay beyond a row's $U$ is rejected, a deposit of a non-live row is rejected, a deposit with cause \texttt{reject} is rejected, an id-chain break is rejected, and the phantom line reflects the hole and never the source text. The axiom audit passes 27 of 27 in compile-plus-static mode, with Lean 4.15.0 on the machine that ran it. The ledger self-test passes 25 of 25 assertions in 0.7 seconds with zero network calls, including coverage of all six dissipation channels, replay determinism after restart (the audit text identical to the character), unit close-out ($U = 0$ and $\Ezero = \Phi+R+D$), forged-event fail-loud (a polluted ledger raises on the next call rather than passing silently) and the phantom injection surface (the belief block carries 457 characters and re-injects zero memory rows). The plugin load smoke passes all 34 checks, including re-plant after dissipation (a new row live, a same-key phantom shadowed), the audit command's return text, \texttt{isError} never silently passing and dispose stopping the hosted server child.

\subsection{Self-settlement, replay determinism and fail-loud}
\label{sec:selftest}
The ledger settles itself. Every call replays the event stream from the beginning; there is no separate reconciler and no cached state to diverge. The self-test restarts the process and finds the audit text identical to the character, which is the strongest statement of replay determinism the design permits. A forged event does not corrupt a running ledger silently: it raises on the next call, and the self-test asserts that a polluted ledger reports ``the ledger is inconsistent'' with zero silent passes. Unit close-out drives $U$ to zero and leaves $\Ezero = \Phi+R+D$, which is the boundary case the frozen trace does not exercise and the reason the self-test is not redundant. The five mandatory per-round readings (gate rejections, dissipation by cause, phantom reflections, answer fidelity, conservation verdict) are the readings a round must report; a round missing any of them is an incomplete receipt, not a passing one.

\subsection{The inherited lines}
\label{sec:inherited}
The previous version's lines are inherited with their gates and are not re-run. They are reported here because the argument depends on them: the negative baseline is the reason the question moved from storage to dissipation.

\paragraph{Baseline and the reproduction band.}
The 0.6B carrier with the 19-slot external layer scored 0 on all 19 probe rungs under frozen evaluation (seed 20261111); the layer did not alter the carrier's general behaviour and did not add anything on the probe rungs. The repair round on the 4B carrier reached 0.5395 balanced accuracy at the third gate (McNemar $p = 0.002$ against the base). The break is a BAcc break, not a drift break, and the run was stopped under the pre-registered red rule.

\paragraph{Main cell and the $\lambda$ sweep.}
The main-cell line's a-trial (memory batch 6) crashed twice with out-of-memory at steps 3, 4 and 6; the b-trial (memory batch 4) ran to completion at 0.7305 and 0.7234 balanced accuracy at the 250- and 500-step gates with zero violations. \paragraph{Injection protocol on two carriers.}
Dual-vs-single injection discrimination sits at chance on the 0.6B carrier (0.5000) and at 0.6786 and 0.6622 under two calibers on the 4B re-test, both under the pre-registered 0.75 line: the kill verdict holds on both carriers.

\paragraph{Binding topologies, read as bandwidth.}
Five binding topologies spanning 30 to 74 percent of parameters, on the same harness and 600-step budget, land within 0.024 of each other at eval-500 (0.7453, 0.7216, 0.7341, 0.7322 and 0.7293), which is 1.06 standard errors of the estimator. Each point is conditioned on one data order; the instrument's effective resolution for a single-order, 600-step arm comparison is about 0.05 to 0.07 in balanced accuracy; and a band pass for the second arm is order-dependent. Two arms have a measured reseed band (0.7211 to 0.7453 and 0.6482 to 0.7216) and the other three are single-order readings marked as such. No further reseed runs were made, and the between-arm difference is not resolved by this instrument.

The $\lambda$ sweep above left four candidate readings in front of the ruling, no discriminating power at the frozen criteria, a flat dose response, an inverted signature at $L3$ and a monotone dose at the seed point, and no single one was adjudicated as the line's verdict. A 12-item constrained-decode format gate failed 0 of 12 before a decoder-side fix and passes 12 of 12 after it, with no criterion changed. \paragraph{What the inherited lines do and do not support.}
The inherited lines support one negative and one caution. The negative is that a frozen external layer on a frozen carrier holds nothing on a frozen probe, which is why the question of dissipation is not academic: a store that cannot be shown to hold anything is a store whose only observable behaviour is what it spends. The caution is that the sweep, the injection protocol and the binding topologies all failed to discriminate at their pre-registered lines, so the previous version's positive-looking numbers are not evidence that the layer's binding weight or its topology does anything. Nothing in the inherited lines is reinterpreted here as evidence for the thermodynamic claims; the thermodynamic claims stand on the frozen trace and the machine-checked faces alone.

\section{Discipline audit}
\label{sec:discipline}

\subsection{Discipline as designed}
The discipline has five parts, and each is auditable from the record rather than from the author's intention. Criteria are frozen before the run that tests them. A reading is whatever the run returned, including the ones that fail the gate. A failed gate is reported as failed. A change to a criterion is a new freeze event with a date, not an edit. And a round that cannot run is reported as blocked, not as passed by default.

\subsection{Failure history, complete}
The failures are listed because a paper that reports only its passes is not auditable. The pre-fix round produced readings on the wrong act: the model degraded act one, so the round's readings were in the record but not usable, and they are not used here. The post-fix round was blocked at the gateway, with the triage in Section~\ref{sec:blocked}. A first attempt to retry the triage was cut short by a session timeout and did not reach the group; the attempt is logged, and its readings are the same as the ones reported here. The stand-in dry run is a stand-in and is labelled as one. Two benchmark attempts on the previous generation failed before the reported ablation and were re-run; the re-run is the reported one. The extended 600-step window on the larger carrier was not confirmed within its window and is recorded as unconfirmed. Two further entries belong to this list and are reported in Section~\ref{sec:twofacts} rather than buried here: the SDK detour, eight generation-path requests refused byte for byte while four read-path controls were relayed, and the local 0.6B round, which ran to completion and returned an empty phantom set because the model called no read tool. Neither is a pass, and the local round is not entered in the record: its entry is pending the PI's ruling.

\subsection{The honest-reading rules, applied}
Three rules govern what may be written as a number in this paper. A quantity that was not measured is marked \emph{pending measurement} and no estimate is entered in its place. A cost is reported as a cost: the hit-rate drop and the phantom reflection rate are in the text, not in a footnote. And a stand-in is never substituted for a measurement: the dry run is labelled, the blocked round is labelled, and the count of models a catalogue lists is not a model-side reading. The rule is enforced by the evidence index (Section~\ref{sec:rag}): every number in this paper resolves to a line in a source file, and a number with no source line does not appear.

\section{Discussion}
\label{sec:discussion}

\subsection{What the gates returned}
The dissipation gate returned a utilisation of $69.23\%$ on a trace where the previous generation's utilisation was $0.00\%$ by construction. That is the paper's central reading, and its meaning is narrow: on this trace, under default parameters, the store spends about seven tenths of the row exergy it is given. It is a regression anchor, not an estimate for other workloads.

\subsection{What the conservation core buys}
The first law is the reason the utilisation reading can be trusted. A store that reports ``$69.23\%$ dissipated'' without a conservation core could be reporting anything, including an accounting error. Here every event is checked, every epoch is checked, and the final audit is checked on two implementations that meet on a hand-computed vector; a forged event does not pass. The cost of the core is that it is a constraint on the design: a transition that does not conserve cannot be added, and a parameter that breaks a sub-identity cannot be set.

\subsection{What the price means}
The price is a drop of $2.46$ percentage points in specific-key hit rate, and the decomposition is what makes it interpretable: no read that hit before is silently lost, because $78 + 4 = 82$. The $2.45\%$ of reads answered with a phantom line are a real loss for a caller who needed the content, honestly signalled. The alternative, a store that never dissipates, is not free either: it renders $1647$ characters per read on this trace, against $292$.

\subsection{What the block means}
The block is not a result about the layer. It is a result about the client's path to a model, and it is reported because a blocked round whose block is undiagnosed would be indistinguishable from a round that was never attempted. The design consequence is that the model-side readings remain open: whether a model calls settlement unprompted, whether it reports a dissipated row truthfully and whether the phantom line changes its behaviour are all \emph{pending measurement}, and the paper does not guess at them.

\subsection{What this paper is and is not}
It is a paper about accounting: an external memory layer whose store spends exergy, whose spending is conserved to the last integer, and whose price is measured. It is not a paper about a better memory system. The inherited lines show that the layer's binding weight and its topology did not discriminate at their pre-registered lines, and this paper does not claim otherwise. The phantom limb is a device for making the store's losses legible to a model, and its two surfaces are the whole of its role.

\section{Limitations and future work}
\label{sec:limitations}

\subsection{Limitations}
\begin{enumerate}\setlength\itemsep{1pt}
\item \textbf{One trace, one seed, synthetic keys.} The $69.23\%$ is the utilisation of that trace under default parameters. It is a regression anchor, not an estimate for other workloads, and it is not extrapolated to any workload here.
\item \textbf{Settlement is explicit.} Without a settle call from the agent or the host, decay and horizon never materialise. Whether a model calls \texttt{deposon\_thermo\_settle} unprompted is \emph{pending measurement}.
\item \textbf{Defaults dissipate slowly} (cap 256, horizon 200). Small ledgers need the small-parameter set; the real-model round pre-registers one.
\item \textbf{Eviction and close-out are not on the trace.} Both are covered by the self-test and the cross-check, not by the frozen-trace readings.
\item \textbf{The benchmark ablation was not re-run.} The usability ablation was measured on the previous generation's memory face. The same ablation with the thermodynamic generation is \emph{pending measurement}; until then the hit-rate price is known only on the frozen trace.
\item \textbf{Real-workload price is unknown.} Hit rate, phantom reflection rate and rewrite behaviour on real memories with a real model are \emph{pending measurement}, because the round is blocked.
\item \textbf{The block is undiagnosed between key and egress.} Distinguishing them requires a second key or a second egress, and neither was available.
\item \textbf{The container is a test-bed, not a model of memory.} The axioms constrain what the system may do and are used to make the write policy falsifiable; whether a container under these axioms is the right model of memory is not a question this paper can answer.
\item \textbf{The phantom limb is an engineering device.} Its two surfaces are not a model of amputation, and no claim about biological or clinical phenomenology is made.
\end{enumerate}

\subsection{Future work (options; none is promised)}
Three options follow from the limitations rather than from a roadmap. First, a small-parameter live round on a relayable endpoint, with the pre-registered validity preconditions and the small-parameter set, would give the model-side readings that this paper marks pending. Second, a benchmark ablation on the thermodynamic generation would tell whether the frozen-trace price survives a real task distribution. Third, a second key or a second egress would resolve the block's level, and with it the question of whether the block is a property of this client or of the endpoint.

\section{Conclusion}
\label{sec:conclusion}
An external memory layer that cannot dissipate is a store that can only grow. This paper built the dissipation, measured it, and paid for it. On a frozen 500-operation trace the thermodynamic generation raises dissipation-channel utilisation from $0.00\%$ by construction to $69.23\%$, leaves 61 rows where the previous generation left 152, and cuts the per-read rendering cost from 1647 to 292 characters, while the conservation core holds to the last integer at every settlement epoch and on both implementations, machine-checked in Lean with no admitted proofs. The price is $2.46$ percentage points of specific-key hit rate and a $2.45\%$ phantom reflection rate, and the price decomposes exactly: $78 + 4 = 82$, so no read that hit before is silently lost. The real-model round is blocked and every model-side reading is pending, which is the honest state of the evidence. What the paper claims is narrow: a ledger that settles itself, conserves what it is given, and reports what it spends.

Every number in this paper is indexed with its source path and line. Two independent indexes are built over two pre-existing trees, and they are not merged. The freeze carries the carrier of record for the blocked round, \texttt{xiaomi/mimo-v2.6-flash-mopd}, so that a re-freeze cannot silently change the carrier. The v4 re-freeze moved exactly one line, the \S 8 document at \texttt{497a5aa3d61f} (676 lines, 46\,046 bytes), and left the other forty fingerprints unchanged; the comparison is re-run and reports no mismatch. \section{Engineering record}
\label{app:engineering}
The plugin releases carry their own gates. The thermodynamic generation is \texttt{v0.1.0-preview.10} at commit \texttt{0e93cc1}; the previous memory face is \texttt{v0.1.0-preview.9} at \texttt{4ee12b6}. A packaging note is recorded: the published file list includes directories, so an \texttt{npm pack} from a working tree that has run Python includes \texttt{\_\_pycache\_\_/*.pyc}; installs from a git ref or a clean checkout are unaffected, and a desk-level pack should be made from a clean tree. The rollback line is three points: the code tag, the ledger generation (a ledger belongs to one generation, and a rollback or a roll-forward changes the ledger or returns to the pre-switch snapshot), and the parameter switch (a \texttt{DEPOSON\_THERMO} closed configuration, which is a degraded position and not an equivalent rollback). A forward roll is not a normalisation, and the legacy face's same-key rewrite is recorded as it is: a ledger written by the previous face that contains a same-key rewrite carries no supersede event, because that face overwrote the row silently; replayed under the thermodynamic generation it fails loud with a same-key-present-without-prior-supersede reading, and replays only after per-key deduplication that keeps the last row per key. The code is not changed to normalise this, and a forward roll therefore uses a new ledger or a deduplicated copy. A relay risk is recorded for the \texttt{teamorouter} relay used in the real-model round: its response body carries a \texttt{modelKey} field whose value has the form of an upstream provider key; the field was never used, the probe log was written with the field replaced by a placeholder, and the readings packages carry no residue of it. The relay stays in use and the risk stands as a note. The compliance check requires that no post-delivery modification exists in a readings package, that a tampered ledger fails loud under the recompute script, and that no key-level gate is scored on a flattened row.
