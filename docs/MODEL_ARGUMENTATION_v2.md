## 0. 论证总线

全文论证沿一条主线分四层：

1. 物理类比给出**可审计的账**（守恒、不可逆、可操作的构造定义）——回答「账从哪来」；
2. mean-field 反向与最好响应动态的一致性，把账从逐步核验升级为**轨迹标量**——
   回答「整条演化是否可整体复核」（GT-5b / GT-6 / GT-7 三环链）；
3. 可审计性是散射层的**独占价值**，与准确率优势划界——回答「为什么这价值非散射层
   不可」（E9.5 / GT-2 / GT-3b）；
4. 对五层论证各配一条最强反对意见，标明当前扛得住与扛不住的部分（§5）。

每一层结尾明确该层的依赖关系：后层的强度不超过前层，任何一环被推翻时的
级联后果随文给出。

## 1. 为什么物理类比不是装饰

### 1.1 判据：类比何时是装饰

一个物理类比是装饰，当且仅当移除全部物理词汇后算法逐位不变。检验标准是
**操作化对应物的存在性**：物理性质必须对应算法中一段可定位、可单测、可单独
证伪的代码或恒等式，且该对应物要承担某项没有它就无法完成的功能。以下对三条
性质逐条过这个筛子。这三条的论证骨架来自 1.X §2 小结的三要素命题——
「守恒律 + 不可逆淘汰 + 逐路径审计可作为同一物理实体的推论免费获得」——
本节把它推进一层：不止说三要素同源，而给出每条要素的**操作化对应物清单**，
并回答它到底买到了什么审计价值。

### 1.2 守恒：T+R+A=1

**操作化对应物**（三层，逐层可指认）：

- 公式层：1.X 式 (2) 的三通道归一化（Λ = 1 + g_eff + g_aether），T+R+A=1
  **由构造成立**（式 (3)），非任何 S 矩阵的推论（附录 A.3 如实声明归一化是设计选择）；
- 代码层（生成场对应物）：`deposon_diffusion.py` 的 `project_simplex_rows` /
  `_project_masked`——行单纯形硬投影，掩码子向量逐行归一到质量 1−边界质量，
  边界逐元素冻结（`_project_masked` 只写 mask=True 位置），代码注释自称
  「T+R+A=1 analog」；
- 数值层：1.X §4.4 全部 200 题全部路径逐次核验，|T+R+A−1| 最大偏差
  2.2e-16（双精度机器精度），远低于 1e-6 容差（文档级字段：评测 JSON
  deposon_benchmark_v1_3_*.json 的逐路径审计记录）。

**审计价值**：守恒把「每一次淘汰的能量去向」变成一个必须闭合的方程。非守恒的
筛选机制（投票、启发式打分）可以静默地创造或消灭分数；守恒约束下，任何实现
偏差都以守恒账不平的形式暴露——审计者不需要理解机制，只需要会算加法。
这是 1.X §2(a) 对 ToT/SC 的结构性批评的正面回答：那些被剪枝的分支不复活，
但没有账本记录它们被剪枝时付出了什么。

**强度档：【已证】**——恒等式由构造成立，机器精度核验已闭合。唯一不属「已证」
的部分是「这个恒等式有意义」的断言，它依赖下两节的动力学化。

### 1.3 不可逆耗散

**操作化对应物**：`EtherChannel.dissipate(energy)` 单向累加进只增计数器，
接口层不提供 `recover()`，沉积后 `is_locked=True`（1.X §3.3，工程强制层）；
对应物理论论证为以太建模为无限维正交环境使 Poincaré 回归定理前提
（有限不变测度）不成立、回归时间发散。

**审计价值**：不可逆性是守恒账的**承诺方向**。守恒只保证账平，不保证账不被
撤销；不可逆耗散保证被淘汰路径的能量预算不可回流——审计记录不仅可复核，
而且不可回滚。这正是它与概率剪枝的分界：概率剪枝的决定在下一轮采样中
可以被悄悄翻案，散射层的淘汰留下一条只能单调增长的耗散记录。

**强度档：【一致性证据】与【仅有动机】并存，必须分开**：
工程锁定（只增计数器、无 recover 接口）是【已证】的实现事实；「无限维极限下
耗散渐进不可逆」是【一致性证据】（论证给出但不可数值验证，1.X §5.2 列为
不可消除的理论局限）；「不可逆耗散带来任务收益」是【仅有动机】——
1.X §5.1 的零收益声明在案：全部已测任务上耗散通道从未优于不开启
（合成基准 v1_blocking 与 unified 同分 100%；GSM8K v1_blocking 86.0% ≥
unified 85.0%；StrategyQA 两者 89.9% 打平，数据源
deposon_benchmark_v1_4_gsm8k.json / deposon_benchmark_v1_4_strategyqa.json），
其验证需要迭代重搜场景，留作未来工作。混档自查：本节不把零收益声明包装成
任何正向主张。

### 1.4 Feshbach 类比：构造性定义而非推导

**操作化对应物**：1.X 式 (4) 的有效 S 矩阵单极点修正，在 Breit–Wigner 极限下
归一化给出式 (1) 的 Lorentzian 共振因子 g_eff = g_couple/(1+δ²)
（附录 A.1–A.2 的完整链条在案）。

**审计价值**——这里要推进 1.X 一层。1.X 的口径是「式 (2) 是构造性定义，
式 (4) 只提供动机与词汇，不导出式 (2) 也不产生可检验预测」（§3.1 设计声明，
诚实且当时充分）。v2 视角下可以多说一句：**构造性定义本身是一种更强的审计
性质**。若 T+R+A=1 是某个深层物理理论的推论，则该恒等式的有效性就抵押在
那个理论的正确性上；由构造成立意味着它的有效性不依赖任何未验证的物理主张，
审计链在式 (2) 处终止，不再向上延伸。换言之，「只是类比」的诚实降级反而
收窄了审计的攻击面——这是 1.X 设计声明的推论，当时未点明。

**强度档：【仅有动机】（作为物理对应）+【已证】（作为构造事实）**。
共振通道当前在 1.X 主实验中处于休眠态（δ≡0，§3.1 诚实声明），labelfree
消融的残余依赖（label→weight 转写）如实披露——这两处都不得用来夸大类比的
实证负载。

### 1.5 本节混档自查

守恒【已证】；不可逆的工程锁定【已证】、渐进论证【一致性证据】、任务收益
【仅有动机】；Feshbach 形式的物理对应【仅有动机】、构造事实【已证】。
三条性质合起来的主张（「物理类比非装饰」）的强度等于其中最弱一环的负载部分，
即：类比**在审计功能上**非装饰（有操作化对应物且承担审计职能），在**预测
功能上**目前无负载——本文档不要求后者。

## 2. 为什么 mean-field 反向是最好响应动态的一致性口径

本节把 GT-5b、GT-6、GT-7 组织为「存在性 → 完备性 → 边界」的三环论证链。
全节维持 consistency 口径（与 v2.X §5 同）：证据与势博弈解读一致，
是一致性证据而非形式化证明；「均值场反向 = 无噪声最好响应动态」的小图类
形式化命题尚未补齐。

### 2.0 建模对应物（先把映射钉死）

博弈 G 的操作化定义：每条留一预测边是一个玩家，策略是候选目标节点，
效用是场得分（v2.X §3.1：反向退火结束后掩码行上的分布给出候选排序分数）；
确定性 mean-field 反向（`run_v19_meanfield.py` 的 `init_mode="prior_mean"`：
跳过 Dirichlet 采样、保持前向终态即行均匀先验均值，全程零随机性，等价
DDIM η=0；dirichlet 路径逐位复现 `deposon_diffusion.reverse_denoise` 并有
回归测试锁定）对应无噪声最好响应动态；势函数候选 Φ=−E，其中
E = −log(Σ_{p:s⇝t} Π t_e) + λ·ΣW²（`scatter_energy`，aggregate 口径，
解析梯度 dE/dW[u,v] = −(x[u]·y[v]/x_t)·dt_e/dW 在 `reverse_denoise` 中
逐行实现，注释声明任一 s⇝t 通路上的边都有严格负梯度）。
Φ=−E 的选择有解析依据（反向退火梯度即 −∇E）；「每个任务是独立玩家」的
分解是建模选择而非唯一——这两条如实区分。

### 2.1 第一环（存在性）：GT-5b——存在一个沿轨迹单调不减的标量

主张收窄后预登记：「mean-field 反向动态的势函数轨迹单调不减」，通过线
单调率 100% 的图占比 ≥ 0.8，斩杀线（单调率 <0.5 的图 ≥3）不触发
（`deposon_v20_gt5b.json` → `preregistered` 节）。

结果：22/22 图 `per_graph_summary.*.meanfield_monotone_rate` 全部 = 1.0，
判定 supports_narrowed_monotonicity。逐图最小步增量（min_step_delta）横跨
0（S4）到 3.5e-6（S6）至 3.1e-3（L_biological_taxonomy）——单调性在
浮点精度之上成立，其中 S4 的 min_step_delta = 0.0 需如实标注：严格单调
在 S4 上退化为非降（存在零增量步），收窄主张的措辞「单调不减」恰好覆盖
此情形，不构成违规，但也不应表述为「严格递增」。

**审计含义**：轨迹存在一个对每一步都可重算的标量账——「这一步比上一步
更接近均衡多少」成为可计算量，审计从 200 次独立的逐步合规检查升级为
一条可整体复核的曲线。

**强度档：【已证】（预登记判定闭合，22/22 证据）**。形式化缺口如实写出：
这是 22 张图上的经验普遍律，不是「mean-field 反向对任意图都是势动态」的
命题证明；tol=1e-9 的判定阈是数值口径；主张是收窄后的（GT-5 原终点条件
inconclusive 保留在案，未回溯改写，GT_RECONSTRUCTION §2/§6）。

### 2.2 第二环（完备性）：GT-6——这个标量几乎就是全部

Candogan 流分解的可操作类比：边效用向量 F_e = (x[u]·y[v]/x_t)·dt_e/dW
向有向关联矩阵 B 的梯度列空间做最小二乘投影，非势残余
r = ‖F − B·pinv(B)·F‖²/‖F‖²（`deposon_v20_gt6.json` → `decomposition` 节，
含诚实注明：平滑分量 −2λW 为节点独立自指项、天然属势分量不计入残余；
本分解未沿轨迹积分）。

结果：图级均值 r 的中位数 = 1.594e-29（`verdict.median_residual_ratio`），
低于 0.10 预登记线，判定 potential_game_explanation_complete；降级线 0.3
未触发。**三例外如实**：S4 均值 0.148、L_algorithm_process 均值 0.136、
S5 均值 0.121（`per_graph_summary.*.residual_ratio_mean`），其上势解释为
近似；另有 L_historical_causality 0.037 与 L_project_management 0.046
处于 0.01–0.06 的中间带（未越线但非零，本文档补充点名，避免「只有三个
例外」的印象管理）。数值精度口径随数字同行：1.6e-29 处于双精度下溢量级，
其结构性含义是「边效用向量几乎完全落在梯度子空间内」，不应按绝对量级解读
为物理量（v2.X §5.3 口径沿用）。

**审计含义**：完备性回答「这本账有没有暗账」——残余近零意味着用 Φ 记账
几乎不丢信息，循环流分量在 19/22 图上可忽略；三张循环结构图的残余正是
「账不全」的可定位部位，审计者被明确告知在哪些图上需要补账。

**强度档：【已证】（中位口径，预登记闭合）**。形式化缺口：分解是流分解的
可操作类比而非 Candogan 原定理的应用（未沿轨迹积分、效用向量的取法为
aggregate 口径的场分量本身）；例外图的「近似势博弈」降级没有定量的近似度
理论支撑（残余 0.15 对应多大的均衡偏离，无界）。

### 2.3 第三环（边界）：GT-7——账本只覆盖势，不覆盖命中率

设计：α∈{0.3,0.5,1,2,5,20} + mean-field 端点，4 图 × 5 seed；
α=1 档与 GT-5 dirichlet 臂逐位一致（测试锁定）。
判定 mixed（`deposon_v20_gt7.json` → `verdict.verdict`）：

- GT-5 反转**可复现且系统化**：`gt5_reversal_reproduced_graphs` =
  {S6, L_physics_concepts, L_algorithm_process}（3/4 图），Φ 增益集中在
  高温端（corr −0.87，文档级汇总值，叙事锚 GT_RECONSTRUCTION §7）——
  温度确实控制全局势探索收益；
- 「双赢前沿」**被否**：预登记通过线要求 ≥75% 图存在中间档兼顾命中率
  ≥0.9×mean-field 且终点 Φ 更高，实际 `frac_graphs_with_frontier_temp`=0.5，
  supported_tradeoff_frontier=false；S6 高温档 hits 0.4→0.08 而 Φ 升
  （`per_graph.S6`）——势与命中率是两个目标；
- L_physics_concepts 各温度档 codirectional_all_temps=true 但其 mean-field
  hits=0 使条件退化恒真，属预登记边界情形，如实披露未回溯改规则。

**审计含义**：第三环是前两环的**边界声明**——审计承诺只覆盖势这一本账；
温度（噪声强度）获得博弈论语义（log-linear learning 式的探索-利用分工，
Blume 1993 / Sandholm 2010 为理论支点），但该语义不免费：升温买势、
不卖命中。

**强度档：【一致性证据】**（4 图 × 5 seed 的扫描，非判定性闭合；「温度=探索-
利用旋钮」与经典理论方向一致，但 win-win 被否恰好说明该一致性是受限的）。

### 2.4 三环合起来的论证形态与混档自查

三环不是三条独立证据，而是一条**定义性性质的完备性核验链**：
势博弈的判定性性质（存在单调势轨迹）在 22/22 成立（第一环），且该势几乎
完备地刻画效用结构（残余中位 1.594e-29，例外 3 图在案，第二环），且该
刻画的管辖范围被显式划定（只管势不管命中，第三环）。任何一环单独都不构成
论证：只有第一环，标量可能是平凡存在（见反对意见 O1）；只有第二环，
投影残余小不等于动态沿势走；没有第三环，前两环容易被读成超出数据的双赢
承诺。混档自查：第一、二环【已证】限于其收窄主张与操作化口径；第三环
【一致性证据】；「最好响应动态」的等价命题本身全节无形式化证明，仅
Sandholm (2010) 群体极限作最近支点——这是本节的**总缺口**，不在任何单环
内部，而在三环与「=最好响应动态」的等号之间。

## 3. 审计优势 vs 准确率优势的划界论证

### 3.1 命题与三块划界砖

**命题**：可审计性是散射层的独占价值，而非准确率优势的副产品。
该命题的结构是排除式的：先用前序工作自己的阴性结果封死准确率退路，
再指出审计价值在那条退路上不存在。

**砖一：E9.5 规则过滤器追平（准确率层无独占增量）**。
1.X v1.9 的 6 关键词规则过滤器（仅读标签字符串、不经过任何散射机制）：
GSM8K 0.87 ≥ unified 0.85（McNemar b=0,c=2，p=0.5）；StrategyQA
0.899 = 0.899（b=0,c=0，p=1.0）。散射层对准确率的因果增量在两个真实
基准上与平凡基线不可区分；E9.4 进一步把 vs no_deposon 的表观效应量
（+0.83/+0.78）判定为结构性偏置（BFS 短路径优先 + 免费 type 标签）下的
不可归因数字（数据源：deposon_benchmark_v1_4_gsm8k.json /
deposon_benchmark_v1_4_strategyqa.json 的逐题记录；判定口径见 1.X §4.8）。
**但这块砖只证明「散射层在准确率上无独占性」，它没有证明规则过滤器在
审计上有缺陷**——那是砖二的事。

**砖二：题库轨的机制性免疫（审计-防御联合层有排他区分）**。
GT-2 主协议：攻击者知道关键词表后 evasion_rate=1.000（4/4 图，
`deposon_v20_crossval.json` → `gt2_attacker_meta.*`），rule_filter 平均
−7.5pp，field_mean −0.0pp（四图全零）——**场不读标签，对语义陷阱机制性
免疫**；题库轨 rule_filter=27.5% 与机会 25% 不可区分
（`deposon_v20_quiz_eval.json` → `overall`，n=40/格小样本口径，
±1 题=±2.5pp）。如实口径：主协议预登记判 no_separation（攻击强度未达
决定性），规则失效目前仅在题库轨成立——砖二的强度是【一致性证据】，
不是防御失效的已证主张。

**砖三：GT-3b 跨厂商先验（语义臂的对照组地位）**。
先验臂在族 L 真实语义图上 named Hits@3 0.484–1.000、同图结构臂全 ≤0.22
（`deposon_v20_crossval.json` → `prior_arm_eval`），跨厂商复核三模型族
0 败绩、Kendall W=1.0（`deposon_v20_gt3.json` → 顶层 kendall_W，
H_GT3_supported=true）。砖三的作用不是抬高先验，而是确立**对照**：语义臂
有自己的准确率优势域，但它的优势没有任何守恒账、没有势轨迹、没有
机制性免疫——审计三件套是散射层独占的。

### 3.2 划界论证的完整形态

三块砖合起来的推理是：(i) 准确率维度上散射层与 6 关键词过滤器不可区分
（E9.5），故任何「散射层价值 = 筛选性能」的读法已被前序阴性结果封死；
(ii) 在被设计来击穿规则的场景下，规则臂塌陷至机会水平而场臂机制性免疫
（GT-2 题库轨，小样本宽区间），区分点在机制（读不读标签）而不在调参；
(iii) 语义臂的准确率优势（GT-3b 跨厂商稳健）恰好反衬：准确率优势可以
存在于完全无审计结构的臂上，故「审计优势」与「准确率优势」是**两个正交
维度的价值**，散射层独占前者、不独占后者。这就是「划界」的准确含义：
不是「散射层更好」，而是「散射层的好与准确率无关，且无法被准确率更高的
臂继承」。

### 3.3 可证伪条件

该命题不是修辞，以下任一观察会推翻它：

1. **出现一个无守恒结构、无散射机制的臂，在同协议下复现审计三件套**
   （逐实例守恒账机器精度闭合、轨迹势标量单调、对已知规则击穿机制性免疫）。
   只要一条被平凡基线复现，「独占」即死。这是最强的可证伪条件，也是
   E9.5 教给我们的：6 个关键词就曾追平整条管线。
2. **E9.5 型反转在审计层重演**：某个关键词级或检索级过滤器被证明也能
   产出等价的逐路径可复核记录（哪怕形式不同），则散射层的审计价值降级为
   「多种等价实现之一」。
3. **守恒账被证明对真实失效模式无检出能力**：若存在散射层的实现性错误
   （非参数错误）能通过全部守恒审计（即账平但机制错），则「账平 ⇒ 合规」
   的审计前提失效。目前无此观察；v1.4 的 high_couple 别名 bug 反而是
   正面证据——它正是被守恒审计之外的**逐位对照**发现的，说明审计体系的
   不同层互相兜底，但该 bug 不经过散射公式本身，故不构成反例。
4. **GT-2 反向结果**：若在达到预登记决定性强度的攻击下场臂出现非机械性
   塌陷（塌陷来源不能归因于选项构成假象，GT-2B 已演示过判据被假象破坏
   的形态），机制性免疫主张撤回。

**强度档**：砖一【已证】（1.X 预登记口径，数字机械追溯）；砖二【一致性证据】
（no_separation + 题库轨小样本）；砖三【已证（跨厂商 0 败绩）但带残余局限】
（三族均为中文优化大模型，共享中文语料的同源污染残余不可排除，
`deposon_v20_gt3.json` 及 v2.X §4.2 在案）；划界合命题【一致性证据】——
它是三块不同强度砖的合取，最弱环节在砖二。

## 5. 反对意见预演（五条，每条分「扛得住 / 扛不住」）

**O1：势存在性对任意单调动态都平凡成立？**
反对：任何收敛的贪心下降动态都有单调标量（目标函数本身），22/22 单调
不携带关于「博弈」的信息。
扛得住：第一环确实**不**单独证明博弈结构——这正是论证链要第二环的原因：
GT-6 的残余中位 1.594e-29 表明效用向量几乎完全落在梯度子空间，即
「存在一个全局势使得每个玩家的局部改善同步抬高它」这一**非平凡**性质
成立；对任意拼装效用，该残余没有理由这么小。单调性是必要条件核验，
残余才是实质内容，二者合读才构成论证（§2.4 已明言单环不成证）。
扛不住：22/22 仍是经验普遍律而非命题证明；「残余小 ⇒ 全局势存在」的
方向只在投影口径下成立，未沿轨迹积分，也没有给出残余大小到均衡近似度
的定量界；若换一组同样由单一标量梯度生成的对照动态，GT-5b+GT-6 同样
会通过——论证排除了「拼装效用」，未排除「该动态本来就是梯度下降因而
平凡地是势博弈」的解读，对后者的回应只能停在「这正是主张本身：
最好响应动态与势梯度下降同构」。

**O2：PoA 操作化与经典定义不是同一度量。**
反对：PoA = field_mean / max{random, degree} 是分布级实例比值，
不是 worst-case NE / 社会最优；报 1.333 或 1.5 会误导读者对标 Pigou 4/3。
扛得住：口径限定在 v2.X §5.4 已全部随行——非同一度量、仿射/可分前提未闭合、
子集中位 1.5 与 4/3 的数值接近声明为巧合、全 17 图口径 1.333 低于 4/3、
分母臂集因族 S 上 llm_prior 不可得而只可能偏小（PoA 只可能偏大，方向性
偏保守在案）。族 L 2 图 PoA<1（0.5/0.75）并列披露，与分工边界自洽。
扛不住：无论披露多充分，「PoA」一词本身携带经典含义，被引用时口径限定
大概率被剥掉；这是命名风险而非数据风险，目前只在文中缓解，无结构性解。
强度档：🟡 受限一致（v2.X 表 1 原档）。

**O3：同源污染残余。**
反对：GT-3b 的三个模型族均为中文优化大模型，图生成器又是单一厂商
（Kimi 系），共享中文训练语料的污染通道未排除，「先验优势跨厂商稳健」
可能是同源 artifact。
扛得住：「实质性削弱但未排除」的口径在案；残余局限逐字写进 v2.X §4.2
与 §6.3（图生成器单一厂商未闭合、人工标注图未排期）。本文档对划界命题的
依赖方式也做了隔离：砖三只承担「语义臂有独立优势域」的对照职能，
即使先验优势打折，散射层审计独占性的论证（砖一+砖二）不动。
扛不住：若污染是真，族 L 全部先验数字（0.484–1.000、W=1.0）的解释力
降级为「共享语料记忆」，分工规律的语义分支失去语料内支撑；该残余当前
无任何实验能关闭（需非中文模型族或人工标注图，均未排期）。

**O4：GT-8 只有 2 对配对，样本太小。**
反对：hub 轴语料外复现仅 2/2 同向（对 A +0.7917>+0.1333；
对 B +0.0526>−0.0833，`deposon_v20_gt8.json`），无法支撑任何规律性主张。
扛得住：该实验在 v2.X 中已降为观察性规律 v0（非判别器贡献），功效说明
随行（2 对只能分辨极大效应；分辨 0.1 量级 diff 差需 ≥6–8 对，列 v2.1）；
B_low 上场被 random 反超、degree 在两高 hub 图饱和（diff 0.0/−0.9474）
均如实披露。本文档的强度地图把它放在最低档，不承担主线负载。
扛不住：2/2 同向的鉴别力上限就是「方向与假说不矛盾」；real_semantics 轴
（GT-8b）干脆 inconclusive（唯一有效域 0.7805 vs 0.0732，
`deposon_v20_gt8b.json`），划界规律的语料外证据整体处于「方向性」层级，
任何更强的引用都越界。

**O5：物理类比不可证伪。**
反对：类比既可以提供词汇又可以随时退回「只是类比」，两头占便宜。
扛得住：三条性质的可证伪条件已逐条给出（§3.3 对审计独占命题；§1 对
构造事实——守恒账若在任何参数下不闭合即推翻，且容差 1e-6 先于数据声明；
GT-5b 斩杀线、GT-6 降级线 0.3、GT-7 双赢通过线均为预登记机械规则，
GT-5 终点反转、GT-7 mixed、GT-2B inconclusive 三个阴性/混合结果如实
判出，证明判死规则真实咬合）。类比主张本身已被收窄为「构造 + 动机」，
不可证伪的部分（物理直觉）不再负载任何实证主张。
扛不住：「可证伪的是操作化对应物，不是类比本身」这一结构仍在；
对坚持「类比不应出现在论文中」的评审，只能回答：移除全部物理词汇后，
T+R+A=1 的单纯形投影、只增耗散计数器、Lorentzian 因子逐字留在代码里
（`deposon_diffusion.py` 行单纯形投影 / `_edge_transmittance` 固定映射），
被移除的只是动机层的可读性——这是操作化检验的正面通过，但属于框架
偏好之争，论证无法强迫对方接受该检验标准。
