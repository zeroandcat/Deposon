## 一、Deposon 映射下的复杂思维

### 1.1 热化与退火 = 发散与收敛（且反思需要"均值起点"）

正向热化把确定结构扩散为不确定性——**发散思维**（头脑风暴、假设生成）；
反向退火从噪声中收束——**收敛思维**（批判、筛选、定稿）。
E9.1 的核心教训直接是一条认知定律：**Dirichlet 随机起点的退火保留起点排序**
（50 步收缩后候选排序由初始噪声决定）——这正是**锚定效应**（anchoring bias）
的动力学形式：没有"先验均值"作为反思起点的自由思考，只是把第一印象合法化。
mean-field（均值起点）不是技术细节，是**反思的前提**：有效的收敛思维必须始于
对全部候选的无偏平均（"先悬置判断"），而非始于最先闯入的念头。

### 1.2 透射 / 反射 / 耗散 = 采纳 / 质疑 / 剪枝

散射三通道对应推理链处置的三种心智操作：透射=采纳并传递、反射=拦截回弹
（批判性质疑）、耗散=不可逆剪枝（向"以太"沉积）。v1.9 的零收益发现给出
反直觉但诚实的推论：**单次运行内不可逆剪枝没有可测价值**（v1_blocking 处处
≥ unified）——一次性思考中，"杀死一条思路"不创造收益；价值只存在于
**跨轮**（迭代重搜时，错误模式是否重生）。这对应：一次性交谈里的"放下"
改变不了这次思考的结果，但能改变下一次思考的起点分布——耗散是跨时间尺度的
认知投资，不是当期的。

### 1.3 守恒账 = 元认知报账

T+R+A=1 逐路径成立 = **每一步思维分配都必须报账且账目闭合**。
思维的不可审计性来自"账不平"——给了多少注意力给采纳、质疑、遗忘，从不合计。
守恒账把这些隐式分配变成显式可审计对象；诚实不是美德声明，是
**不可篡改的账簿存在**（mechanism design 语境下的承诺装置，Conitzer-Sandholm
的先动承诺：先记账、后思考，优于边想边记）。

### 1.4 骨架与叶部 = 结构思维与语义思维的分工

场=骨架检测器（hub_concentration β=2.12, p=0.0003）；先验=语义读取器
（真实语义图 0.48–1.0）。思维映射：**先搭骨架（论证结构）后填叶部（知识细节），
且两者不可融合平均**（hybrid 稀释教训——把结构信号和语义信号按 λ 加权平均，
得到的不是兼得而是互稀释）。复杂思维的成熟形态不是"结构+语义各半"，
是**知道当前问题处于哪个价值域**（领域鉴定器作为元认知技能）。

## 二、Deposon 映射下的复杂行为

| 行为现象 | Deposon 映射 | 项目内证据 |
|---|---|---|
| **锚定效应** | Dirichlet 随机起点排序留存 | E9.1：随机起点 vs mean-field 0.176→1.000 |
| **沉没成本/不可逆决策** | 耗散通道向以太沉积 | v1.9 耗散零收益声明（跨轮才可能有价值） |
| **动机性推理**（自我合理化） | **自适应攻击者**：知道规则后绕过规则 | GT-2：100% 绕过关键词表；rule_filter 27.5%≈机会 |
| **框架效应** | 协议敏感性（换个协议结论翻转） | E9.2：N_NEG=10 vs 全候选，三臂符号翻转 |
| **双系统分工** | 场≈直觉完形（结构模式）；先验≈语义检索（分析） | CrossVal：价值域正交互补 |
| **个体理性 vs 集体最优** | PoA=贪心臂 vs 场引导 | GT-4：median PoA=1.33 ≈ Pigou 4/3 |
| **裁判员与运动员同源** | 同源污染（生成与先验同模型族） | 族 L 声明；GT-3 跨模型待办 |
| **面子工程失效** | 字面级规则防线在知情攻击者前归零 | 题库 19.6% < 机会水平 |

**动机性推理的三条行为推论**（GT-2 × 题库放大）：
1. 你制定的"好习惯清单"（关键词表）最先骗过的不是别人而是自己——
   因为制定者最知道如何绕过它（Tramèr 攻击者后手原则的个人版）。
2. 有效的自我审查必须**不看内容看结构**（场不读标签 ⇒ 机制性免疫）：
   检查论证的形式（骨架），而不是检查结论是否"听起来合理"（语义）。
3. 但结构审查有边界：场对 filler 零信号（叶部无骨架）——形式逻辑检测不了
   细节性自我欺骗，那里只能换信息源（先验/外部数据），对应行为上的
   **寻求外部证伪**（GT-3 跨模型 = 找另一个"模型族"审视自己）。

## 三、互补矩阵：脑图经验 × 博弈论经验的共进

### 3.1 分工叙事（脑图 L2）× 均衡选择（博弈 G1）→ 机制选择器

脑图侧：分工>融合（价值域正交互补）。博弈侧：mean-field 的成功是
"从局部极小跳到全局势阱"的均衡选择。**共进**：领域鉴定器不是启发式开关，
而是**机制设计中的机制选择问题**——每张图对应一个博弈，hub_concentration
度量的是**势阱深度**（hub=深势阱 ⇒ 最好响应动态收敛快且全局性好；
平势地形 ⇒ 噪声动态占优）。回归发现 β=2.12 由此获得博弈论根基：
场何时有效，取决于地形（势阱几何），不取决于场本身。
这同时回答了 v1.9 开放问题 #1：mean-field 奇迹是"深阱地形"的特例——
S6 族（hub 集中）是势博弈的完美地形，链/树/无枢纽是浅阱。

### 3.2 平凡基线（脑图 L3）× 自适应攻击（博弈 G2）→ 基线二维评估

脑图侧：tfidf/规则/CoT 三个 BOSS 证明基线要强。博弈侧：自适应攻击者
摧毁字面防线。**共进**：基线注册表升级为二维——**性能 × 攻击鲁棒性**。
tfidf 是性能 BOSS 但它也读标签（攻击者可以用词面相似度构造陷阱骗它）；
field 性能中等但机制免疫。**真正的共进结论**：评估一个基线不再问"它多强"，
而问"它在知情攻击者面前还剩多少"——GT-2 协议应推广到全部注册表臂
（v2.1：对每臂报 clean-accuracy 与 attacked-accuracy 双指标）。

### 3.3 协议敏感（脑图 L1）× PoA 协议依赖（博弈 G3）→ 协议即机制

脑图侧：N_NEG=10 vs 全候选符号翻转（E9.2）。博弈侧：PoA 随自利臂集合
定义变化（llm_prior 不可得时 PoA 退化且偏保守）。**共进**：**评估协议就是
博弈规则（mechanism）**——协议敏感性 = 机制敏感性；审计一个实验等于审计
一个机制的激励相容性。统一检查单：① 规则是否给某方免费信息（E9.4 教训：
BFS 短路径+免费 trap 标签）？② 均衡是否被设计者预埋（对抗性诱饵）？
③ 自利臂集合是否完整（基线注册表）？三个问题任一不过，结论无效。

### 3.4 同源污染（脑图 L5）× 裁判独立（博弈 G4）→ GT-3 的正当性

脑图侧：族 L 生成与先验同模型族 ⇒ 高分可能来自"同一模型的概念惯例"。
博弈侧：玩家与裁判同源破坏了均衡评估的独立性——**没有独立裁判的博弈，
得分只是自我确认**。**共进**：GT-3（跨模型先验）从"补实验"升级为
**裁判独立性公理**：凡生成-评分同源的度量，只能报为"自洽性"，
不能报为"准确性"；跨模型一致性才是知识。这与跨模型 GT-3 排队互证。

### 3.5 临界质量（脑图 L1 量变质变）× 势函数存在性（博弈 G4）

脑图侧：n=1→20 图的质变、12 张标准档。博弈侧：势博弈框架只在势函数
存在时给出收敛保证。**共进**：统计显著性的临界质量（G≥8 图）与理论解释的
适用域（势函数存在）是同一门槛的两面——**数据不够时没有统计结论，
正如势不存在时没有收敛承诺**；在门槛之下只能做"单图个案"与
"局部动态"的如实报告。这把"何时可以下结论"从统计直觉提升为
**统计×理论的双重门控**。

## 五、一句话总纲

**结构给骨架以地形，语义给叶部以内容，账簿给思考以诚实，攻击给防御以边界——
四者不可互相替代，只在各自的价值域里称王；元认知的全部工作，
是知道此刻身处哪个域。**
