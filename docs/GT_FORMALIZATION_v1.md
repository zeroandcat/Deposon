# GT_FORMALIZATION_v1 — Deposon mean-field 动态 = 势博弈最好响应动态：定理化第一步

版本：v1（2026）。范围：把 GT-5b / GT-6 的两条一致性证据升级为可判死的形式化命题。
纪律：所有数字引自 `results/` 冻结 JSON；证明缺口如实标注；每节以「可检验推论」收尾。

## 0. 代码中的真实动力学（定义锚点）

**场与行约束**（`deposon_protocol.py`）：
- `row_normalize`：出边权重行归一，W[i,:] = adj[i,:]/outdeg(i)，零出度节点保持零行。
- `field_scores_init`：完整臂 = `forward_diffuse` → `denoise`（aggregate 能量），起点由 init_mode 决定；mean-field 臂 = `init_mode="prior_mean"`（零随机性，不调 rng）。

**mean-field 反向更新**（`deposon_diffusion.denoise`，L367–408）。每步对掩码自由度：
1. 场梯度（aggregate）：g[u,v] = −(x[u]·y[v]/x_t)·dt_e/dW，其中 x/y 为 source⇝v / v⇝target 的聚合透射率游走和（`_walk_sums`：DAG 上拓扑序 DP，含环时 (I−Gᵀ)⁻¹ 闭式解，谱半径 ρ(G)<1 由 Σ_j t(i,j) < Σ_j W[i,j] ≤ 1 保证），x_t=x[target]，dt_e/dW = 1/(1+g_a·W)²（g_a=0.1 常数）；
2. 平滑梯度：g += 2λ·W（λ=lam_smooth=0.01）；
3. 乘性更新：W[m] ← W[m]·exp(−lr·W[m]·g[m])（单纯形自然梯度 / mirror descent，lr=0.1）；
4. 收缩：W[m] ← (1−lr)·W[m]（向 W_obs 收缩；观测场在掩码处为 0，即纯衰减）；
5. 边界逐元素冻结（Dirichlet），掩码子向量经 `_project_masked` 重新归一到质量 (1−S_b)。

**势函数候选**（`gt_common.phi_potential`）：Φ(W) = −scatter_energy(W) = log x_t − λ·Σ_{i≠j} W[i,j]²（aggregate 口径）。注意 Φ 恰为反向动态的 Lyapunov 候选：更新步 1–3 是 E=−Φ 的 mirror descent。

**Φ 单调判定**（`run_v20_gt5b.py`）：单调率 = ΔΦ_t ≥ −1e-9 的步数占比（`gt_common.monotone_rate`，tol=GT5B_TOL=1e-9）；支持线 = 单调率 100% 的图占比 ≥ 0.8；斩杀线 = 单调率 <50% 的图 ≥ 3 张。结果：22/22 图全单调（`deposon_v20_gt5b.json → verdict.frac_graphs_full_monotonicity=1.0`）。

**非势残余**（`run_v20_gt6.py`）：边效用向量 F_e = (x[u]·y[v]/x_t)·dt_e/dW（场分量本身，平滑分量 −2λW 为自指项天然属势分量，不计入）；向梯度空间 {Bp : (Bp)_e = p_u − p_v} 做最小二乘投影（p = pinv(B)F，B 为 |E|×N 有向关联矩阵），残余比 r = ‖F−Bp‖²/‖F‖²。结果：图级均值 r 的中位数 1.5938e-29（`deposon_v20_gt6.json → verdict.median_residual_ratio`），低于完备线 0.10。

**PoA**（`run_v20_gt.py` run_gt4）：PoA(g) = field_mean named Hits@3 / max（自利臂 named Hits@3)，自利臂={random, degree}（llm_prior 族 S 不可得，如实退化）；median PoA > 1.2 ⇒ 协调价值，≤1.05 ⇒ 判死。结果：median=1.3333，判 field_coordination_value_supported（`deposon_v20_gt.json → GT4_price_of_anarchy.verdict`）。

可检验推论：本节每条定义都有唯一代码行锚点；任何「动力学」表述与上述五行不符即视为表述错误。

## 1. 候选势博弈 G 的构造

**两种参与人构造。**

- 构造 A（边玩家）：每个掩码位置 e=(u,v) 是一个参与人；策略 w_e ∈ [0, m_u]（m_u = 1−S_b(u) 为该行可分配质量）；支付 u_e(w) = Φ(w_e, w_{−e})（全同利益博弈，identical-interest game）。
- 构造 B（行玩家）：每个含掩码出边的节点 u 是一个参与人；策略为该节点掩码列上的分布 w_{u,·} ∈ Δ(m_u)（缩放单纯形）；支付 u_row(w) = Φ(w)。

比较：构造 A 的策略空间是边权的笛卡尔积，不内生携带行约束 Σ_j w_{u,j} = m_u，行约束须外加为联合可行域（博弈论上属「共享约束博弈」，均衡概念需用广义 NE）；构造 B 把行单纯形直接作为策略集，与 `_project_masked` 的行投影一一对应，约束内生。**采用构造 B 为主、构造 A 为分析旁路**（GT-6 的 Hodge 分解在边上定义，天然对应构造 A 的效用向量）。

**支付结构（构造 B）**：u_u(w) = Φ(w) = log x_t(w) − λΣ W²。全同利益 ⇒ G 是精确势博弈（Monderer–Shapley 1996：identical interests ⇒ exact potential，势函数即 Φ 本身），此点无需证明之外的新工具。

可检验推论：构造 A/B 的等价性归约为「行约束是外加还是内生」；代码只实现行投影，故任何以构造 A 陈述的定理必须显式补共享约束条件，否则视为证明缺口。

## 2. 命题 P1：动态等价（或条件等价）

**陈述（P1a，强式，预期证伪）**：mean-field 反向更新一步（§0 第 1–5 项）= 构造 B 中全体行玩家同步最好响应（BR）的一步。

**分析**：BR 一步为 w_{u,·} ← argmax_{Δ(m_u)} Φ(·, w_{−u})。Φ 的 log x_t 分量对行内权重非线性（经 (I−Gᵀ)⁻¹ 全局耦合），argmax 无闭式；且实际更新是 (i) 状态依赖步长 lr·w_e 的 mirror ascent、(ii) 纯衰减 (1−lr)、(iii) 行重归一的复合，三者任一都不等于 argmax。**P1a 不成立**（判死实验见下，预计一击即死）。

**陈述（P1b，条件等价 / 偏差刻画）**：记更新步为 T = Π ∘ C ∘ M（M=mirror ascent，C=(1−lr) 收缩，Π=掩码行投影）。偏差项分解：
- D1（步长偏差）：mirror ascent 是 BR 的一阶（线性化）近似，偏差 O(lr²·‖∇²Φ‖)；
- D2（收缩偏差）：C 把所有掩码权重同乘 (1−lr)，投影 Π 再按行质量重归一——净效应等价于向行均匀先验收缩一个 lr 量级的步（熵正则项），对应博弈论中的 logit/熵平滑 BR（等价类：smooth best response）；
- D3（平滑项偏差）：−λΣW² 本身是 Φ 的一部分，不构成偏差，但使 BR 唯一化（严格凹化）。

**最弱充分条件（P1c）**：若 (i) lr→0 且只看一阶方向，(ii) 收缩项被吸收为熵正则（即把 Φ 换成 Φ_τ = Φ + τ·H(w_{u,·})，H 为行熵），则 T 的一阶方向与 Φ_τ 的梯度上升方向逐分量一致——即 **Deposon 一步 = 熵正则化全同利益博弈 G_τ 的一阶最好响应（mirror ascent on Φ_τ）**。充分条件清单：g_a≥0 任意、DAG 或 ρ(G)<1、掩码行质量 m_u>0、λ≥0。

**证明缺口**：P1c 的「一阶方向一致」可对单步解析验证；但「T 的迭代轨道收敛到 G_τ 的 Nash 均衡（= Φ_τ 在约束集上的驻点）」需要带投影与收缩耦合的离散时间 Lyapunov 论证，现有标准定理（mirror descent 连续时间 / 无收缩离散）不直接覆盖，属新数学工具（见 §5）。

**判死检验 T-P1（可用现有组件直接实现）**：
- T-P1a：穷举全部 n≤8 节点的有向图（边上 0/1，行归一），每图取全部单节点全候选掩码（`full_candidate_mask`），各跑一步 mean-field 更新，与同一状态上数值 argmax（行内网格 + 局部细化）比较：判死线 = 任一图任一行的更新方向与 BR 方向的余弦 < 0（方向相反即严格死）；偏差量化 = max ‖T(w)−BR(w)‖∞。预期：P1a 死、P1b 偏差表落成。
- T-P1b（better-response 版）：同穷举集上检验 ΔΦ = Φ(T(w)) − Φ(w) ≥ −1e-9；判死线 = 任一图 ΔΦ < −1e-9。这是 GT-5b 在小图穷举集上的强化版（GT-5b 为 22 图 × ≤10 任务的抽样）。

可检验推论：P1a 今天即可判死；P1b 的存活条件是「更新方向与 BR 方向余弦 > 0 且 ΔΦ ≥ −1e-9 在全穷举集成立」，任一图违例即收窄主张。

## 3. 命题 P2：Φ 单调 ⇒ 精确（或加权）势函数存在

**陈述**：(i) 若 GT-6 的 Hodge 残余 r = 0，则边效用向量 F 可由节点势 p 精确表示（F = Bp），即动态存在精确势；(ii) 若 0 < r < ε，则 G 为近似势博弈（Candogan et al. 2011 口径），近似界由 r 控制；(iii) Φ 轨迹单调（GT-5b 事实）是存在性结论的动态侧证，二者经「F 是 −∇Φ 的场分量」衔接。

**证明（(i)，今天可证）**：线性代数标准事实。F ∈ R^E 满足 F = Bp 有解 ⇔ F ⊥ ker(Bᵀ)。ker(Bᵀ) 恰为图的循环空间（每个基本环上的环流）。故 r=0 ⇔ F 在每一有向环上的环量和为 0 ⇔ F 路径无关 ⇔ 存在节点函数 p 使 F_{u,v} = p_u − p_v。p 由最小二乘 p = pinv(B)F 显式给出（连通分量内唯一，差常数）。∎

**与实证的关系**：GT-6 实测 r 中位数 1.59e-29（双精度下溢量级）⇒ 在数值精度内条件 (i) 成立；3 张含循环结构的图 r ∈ {0.148, 0.136, 0.121}（S4 / L_algorithm_process / S5，`deposon_v20_gt6.json → per_graph_summary.*.residual_ratio_mean`）⇒ 这些图上只成立 (ii)，势解释为近似。**注意诚实边界**：r 度量的是「F 是否梯度场」，不直接证明「动态是 BR」——后者是 P1 的内容，两者不可互替。

**证明缺口**：(iii) 中「Φ 单调 + F 梯度场 ⇒ 存在使该动态成为 BR 的加权势」不成立为定理——单调性只给 Lyapunov 函数，加权势（Monderer–Shapley 的 w-potential）要求边际支付跨玩家成比例，此处支付全同 ⇒ 加权退化为精确（权重全 1）。故 P2 的真实内容是：单调性证据 + r≈0 ⇒ 主张可收窄为「精确势 + 非 BR 但势上升的动态」。

**判死检验 T-P2**：在 T-P1a 的同一 n≤8 穷举集上，对每个状态计算 r（复用 `run_v20_gt6.hodge_decomposition`）；判死线 = 任一无环支持图 r > 1e-9（无环图上循环空间为空，r 必须恒 0，非 0 即实现 bug 或口径错误）；含环图报 r 分布，r > 0.30 的图占比 > 1/3 ⇒ 「完备势解释」降级（沿用 GT-6 预登记阈值）。

可检验推论：无环图上 r>1e-9 即证伪实现；含环图上 r 不近零即主张自动降级为近似势博弈，无中间地带。

## 4. 命题 P3：耗散通道 = 承诺装置的形式化

**陈述**：代码中耗散以常数 g_a = g_aether = 0.1 进入边透射率 t_e = 1/(1/W + g_a)（`_edge_transmittance`）。博弈论转译：g_a 是对每条边施加的公共知识、不可逆的「透射税」——它把 t_e 压到 W 所决定值的单调之下，等价于从 G 中**移除行动**（任何玩家无法通过单边偏离恢复被税收走的透射质量）。形式化：G(g_a) 是从 G(0) 经支付扰动 Δ_e(w) = log t_e(w; g_a) − log t_e(w; 0) 得到的受限博弈；「承诺装置」主张 = 存在 g_a > 0 使 G(g_a) 的均衡集在审计维度（Φ 轨迹可复核性）严格优于 G(0)。

**等价性引理（今天可证）**：g_a 对 t_e 的作用是关于 W 的严格单调递减、严格正的逐边变换，不引入跨边耦合 ⇒ G(g_a) 与 G(0) 的效用向量场只差逐边对角缩放 D(g_a) = diag(d log t_e/dW 之比)。因此 GT-6 的 Hodge 分解在 g_a=0 与 g_a=0.1 下的势/非势划分**不变**（对角正缩放保持梯度子空间成员性的判据——环量和为零——不变：环量和 Σ F_e 经逐边正缩放后一般不保持为零……此处给出**反例即证伪**：对角正缩放不保持环流为零 ⇒ 等价性引理只在「每环上 d 比恒定」时成立，一般不成立）。**如实结论：P3 的「移除行动与支付扰动的等价性」一般不成立**，可成立的最弱形式是「G(g_a) 是 G(0) 的逐边支付扰动博弈，扰动量 Δ_e 有闭式」——承诺装置解释因此是**建模类比而非等价定理**，其可检验内容是：扰动 Δ_e 是否改变 BR 结构。

**判死检验 T-P3**：在 T-P1a 穷举集上，对 g_a ∈ {0, 0.1, 1.0} 三档分别计算 (i) r（Hodge 残余）与 (ii) BR 不动点集（数值）：若 r(g_a=0.1) ≠ r(g_a=0) 超过 1e-9，则「耗散只是支付重参数化」判死（预期：在含环图上死）；若 BR 不动点集在 g_a 三档间相同（容差 1e-9），则「耗散改变策略结构」判死（预期：存活，即耗散不改变均衡集——与 1.X「耗散零收益」阴性结果互洽：承诺装置无租金）。

可检验推论：P3 的两个方向都各有一条判死线，且预期结论（均衡集不变 + 含环图非等价）与既有阴性证据一致；任何「耗散带来博弈论租金」的未来主张必须先过 T-P3。

## 5. 脑图语境之外：任意有限有向图 + 任意标签源的最小假设清单

该形式化不依赖 LLM/脑图语料的条件，成立所需最小假设：

1. 有限有向图 (V, E)，|V|=n < ∞；允许环（闭式游走和已覆盖），仅要求行随机 W ≥ 0、Σ_j W[i,j] ≤ 1（行归一由 `row_normalize` 构造保证）；
2. source ≠ target 且 source 可达 target（否则 x_t = 0，Φ = −∞，动态退化为纯平滑项——可判定的退化情形，非假设失败）；
3. 谱条件 ρ(G) < 1：由 t_e < W 逐元素成立而自动满足（`deposon_diffusion._walk_sums` docstring 已论证），无需额外假设；
4. 掩码结构任意：每行掩码质量 m_u > 0（m_u = 0 的行无自由度，自动退出参与人集）；
5. 标签源任意：金边只进入评估（gold_rank / Hits@3），按 SPEC 防泄漏契约不进入能量（`scatter_energy` 体 `del gold_edges`）⇒ 博弈 G 的构造与评估标签完全解耦，任意标签源（人工标注、检索、规则）皆适用；
6. 数值条件：双精度、容差 1e-9 量级（GT5B_TOL），r 的解读以下溢量级 ~1e-29 为「数值零」。

可检验推论：1–4 皆可在任意新图上 O(n³) 机械核验；任一假设不成立时动态有明确定义的退化模式（纯平滑臂），不会出现未定义行为。

## 6. 今天能证明 / 需要新工具 / 可能证伪

**今天能证明（本备忘录已给出证明或证明梗概）**：
- 引理 L1（P2-i）：F 可势表示 ⇔ 环流量为零；p = pinv(B)F 显式构造。（完整证明，§3）
- 引理 L2（P1c 一阶版）：在 Φ_τ = Φ + τH 下，更新步的场分量方向与 ∇Φ 在掩码切空间上的投影一致（mirror ascent 定义即证；收缩分量是 O(lr) 的向均匀先验的拉回）。（梗概，需把投影算子的切锥条件写全，约 1 页）
- 引理 L3（P3 扰动闭式）：Δ_e(w; g_a) = log[(1/W + 0)/(1/W + g_a)] 的逐边表达式，及其对 BR 结构不变 ⇒ 均衡集不变的方向（单调变换不改变逐边 argmax 的序——在构造 B 行约束下需验证行内序保持：dt/dW 逐边递减 ⇒ 行内 BR 排序不变 ⇒ 均衡集不变）。（梗概，行内序保持是关键一步，可解析完成）

**需要新数学工具**：
- 带「乘性更新 + 纯衰减 + 行重归一」复合算子 T 的不动点存在唯一性与收敛率（现有 mirror descent 定理不覆盖 C∘Π 耦合；候选工具：Hilbert 投影度量下的收缩映射 / KL 几何下的非扩张性）；
- P1b 的 O(lr) 偏差界常数显式化（需要 Φ 在单纯形上的光滑常数，涉及 (I−Gᵀ)⁻¹ 对 W 的二阶敏感性）。

**可能证伪（附实验设计）**：
- P1a：T-P1a 穷举，预计一击即死（这正是设计目的——把「动态=BR」的口头主张变成可判死对象）；
- P2 的「完备势」：若 T-P2 在 n≤8 含环图上 r>0.30 的图占比 >1/3，主张降级为近似势博弈（沿用 GT-6 阈值，不回溯改写）；
- P1b 的 better-response 版：T-P1b 任一图 ΔΦ<−1e-9 即死——此检验比 GT-5b 抽样严格（全小图穷举），GT-5b 的 22/22 不保证穷举存活，**这是当前主张最脆弱的环节，优先执行**。

可检验推论：本节每项「能证」给出证明位置，「缺工具」给出候选工具名，「可能证伪」给出判死线与预期——任何一项落空即为下一版备忘录的待办。
