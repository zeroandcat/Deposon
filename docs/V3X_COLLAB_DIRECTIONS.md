## 0. 定位：我们带来什么，不是什么

**我们带来的是三件可核查的资产，不是物理隐喻。**

1. **判死纪律作为信任基础设施（判死级，已发生）**：我们把「v3 动态系统与博弈论的等价」拆成三层主张逐一预登记 kill-test（系统采样 61 图 × 状态全穷举口径：61 张 n≤8 系统采样图五族 × 338 个单节点全候选掩码任务 × 20 步 = 6760 个判死状态，判定纯函数先于运行冻结），结果是三层全灭——P1a（偏差界：max_dev_inf=0.857，方向偏差 1−cos≈0.91 几乎不随 lr 变化——O(1) 偏差而非 O(lr²) 离散误差；median_c_lr2=202.1 仅为常数拟合口径，不构成二次律证据）、P1b（方向对齐：min cosine = −1.0）、T-P1c（最优全局/逐态重参数化 τ 均救不回：best-τ 下 min cos 仍为 −1.0）。必须精确表述：**死的是「我们的动态等价主张」，不是对方领域的任何问题**——best-response 动力学、势博弈理论本身无恙，是我们的系统不构成它们的实例。
2. **守恒审计的工程样板（判死级）**：三通道会计恒等式 T+R+A=1 守恒审计在 v19 冻结基准（全部变体 × 200 道合成题）逐路径通过，最大残差 2.2×10⁻¹⁶。
3. **耗散承诺的机制性前提证据（判死级，P3 附带发现）**：P3 双向判死的副产物——g_aether=0（无耗散通道）时 338 个任务中有 **58 个谱发散**（17%，g_a=0 且支持含环时 ρ(G)=1 使 (I−G) 奇异，闭式动力学发散）；收敛的谱条件 ρ(G)<1 恰由耗散 g_a>0 保证——这是 g_a>0 的**构造内嵌性质**，作为机制性前提证据归档（非任务级收益主张：任务级租金在全部已测任务上仍为零）。同时 P2 降级为**近似势博弈**：无环图势残余 ≤5.9×10⁻¹⁶（机器精度），含环图中位 0.669（92.4% 高残余）。

**我们不是什么**：不主张量子同构（混合劣势↔测不准已在思考文档第一部分判死：无共享不变量、权衡方向相反、本体不同）；不主张 Feshbach 旋钮已有博弈论语义（探索性，未立案）。

## 1. 四个合作问题

### P-A：均衡稳定化成本——均衡迁移成本的对偶

**问题陈述**：王老师的《Cost Minimization for Equilibrium Transition》（AAAI）问的是「花多少激励成本把博弈**推到**目标均衡」（APX-hard + 近似算法）。对偶问题是：**花多少不可逆代价能让系统留在目标均衡不离开？**——均衡的「稳定化成本」。迁移与稳定化合起来才覆盖均衡管理的全生命周期。

**与王工作的挂点**：直接对偶于其 AAAI 问题的目标函数结构；其品味（结构性参数→紧近似比/复杂性分界）正适合问「稳定化成本作为图结构参数的函数是否有紧界」。

**我方已有资产**：耗散 = 内生承诺装置（烧桥）的机制性前提证据（终稿口径：g_a>0 的构造内嵌性质，非「首个机制收益」强表述）——无耗散时 338 个任务中 58 个谱发散（g_a=0 且支持含环时 ρ(G)=1 使 (I−G) 奇异）；收敛谱条件 ρ(G)<1 由耗散通道构造性地保证。翻译：承诺能力缺失 ⇒ 动力学不收敛。这不是哲学类比，是系统采样图族上的谱事实；同时如实声明边界：这是「保证收敛存在」的前提证据，任务级租金（准确率收益）在全部已测任务上仍为零。

**预登记判死线样板（可机械执行）**：在 v21 同口径合成图族（61 图/338 任务、seed=210021、ga∈{0,0.1,1.0}）上检验猜想「使系统谱条件收敛所需的最小耗散强度 ga* 与图谱间隙 λ_gap 满足 ga*·λ_gap ≥ c₀」。判死线：若 λ_gap 最小十分位图组的 ga* 中位数 **不大于** 最大十分位组的 0.8 倍（Mann-Whitney 单侧 p<0.05 且方向为反），则单调关系猜想死，归档为 inconclusive 不回溯。

**双方分工建议**：我方出图族、动力学实现、判死管线与全部数值；对方出稳定化成本的问题形式化（cost function、参与者效用模型）与复杂性/近似比分析。

**预期产出形态**：先出一篇 workshop 级「问题+证据」短文（对偶问题的定义 + 58/338 谱事实 + 猜想与判死结果），定理层面视判死线结果再定。

### P-B：LLM 智能体机制的可验证宣言

**问题陈述**：王老师的近期议程是「机制设计遇见信息设计」（信念分解、Bayes 诱导结构）。信息设计管「机制向玩家披露什么」；当玩家是 LLM 智能体时的下一个问题是「玩家向机制**证明**什么」。我们提议的议程延伸：**机制设计遇见可验证审计**——智能体报告的不只是答案，而是一条满足守恒律的推理审计轨迹（可验证宣言）。

**与王工作的挂点**：信息设计×机制设计交叉的直接下一步；其「简单机制+信息受限+紧保证」品味对应「简单审计协议+推理不可直接观测+可验证性保证」。

**我方已有资产**：T+R+A=1 逐路径审计协议（v19 冻结基准全部变体 × 200 道合成题逐路径通过，最大残差 2.2×10⁻¹⁶），作为工程样板已存在且可复现。另有一项终稿新增资产可佐证「统计声明同样工件化」：E9.5 功效诚实化——规则过滤器打平检验的差值置信区间按非配对 Newcombe 混合区间（保守上界）计算并冻结为工件 `results/deposon_v22_e95ci.json`（GSM8K −2pp，95% CI [−11.8pp, +7.8pp]；StrategyQA 0pp，95% CI [−8.8pp, +8.8pp]；配对不和谐对仅 0/2 与 0/0，配对区间退化）——阴性结论的「未检出差异」口径本身是机器可复算的冻结 JSON，而非正文手写数字。

**高压线（必须正面列入研究计划，不回避）**：**守恒 ≠ 真值**。守恒只排除「账不平」的行为（会计完备性），不排除「账平但虚假」（语义操纵）。把工程守恒升级为「操纵会被检测 ⇒ 激励相容加强」的定理，需要一个**失真界**——这是本提案的第一号开放问题，写在提案正文而非脚注。

**预登记判死线样板**：对抗性实验——构造一个知道审计协议的操纵者，任务为「生成满足 T+R+A=1（容差 1e−12）但结论错误的路径」。判死线（对「守恒审计有检测力」这一猜想）：若操纵者在 n≥200 次独立尝试中**成功率 ≥ 50%**（二项置信下限），则「守恒即检测力」死，研究计划退守到「守恒+语义抽查的复合协议」分支，如实归档。

**双方分工建议**：我方出审计协议实现与攻击者构造环境；对方出「可验证宣言」的机制设计形式化（宣言空间、验证成本、激励约束）与失真界的理论刻画。

**预期产出形态**：一个定义+不可能性/可能性分界的论文骨架；若失真界可证，是「LLM 智能体机制设计」方向的早期定义性工作。**P-D 为其完整性基础设施**（见下）。

### P-D：可审计账指纹算法——从工程惯例到可验证协议（探索性）

**问题陈述**：我们现有「可审计账」纪律——判定纯函数先于运行冻结、5 枚 SHA-256 前 12 位时间锚、冻结 JSON 工件、数字溯源公理——已在 2026-08-30 首次真实重跑审计中 PASS（run_v22_p1c.py / run_v22_e95ci.py 重跑与冻结 JSON 逐位一致，唯一差异为 runtime_sec 墙钟；9 项论文关键数字全部溯源到冻结 JSON 字段路径；pytest 398 通过，审计记录见 `AUDIT_2026-08-30.json`）。但这是**工程惯例**，不是**协议**：单工件哈希锚只能证明「这个文件没动」，不能证明「工件集合完整、顺序未被重排、没有工件被静默删除或替换」。我们提议把「工件+哈希锚」升级为**形式化指纹方案**：内容寻址（每个冻结工件以 SHA-256 寻址）、清单哈希（manifest = 工件哈希的规范序列化，定序、定字段、定编码）、根指纹（hash-of-hashes，Merkle 式聚合为单一根值，一次公布即锚定整本账）、追加式运行日志（append-only `runs/` 目录的哈希链，每条记录含前一条的哈希，篡改历史必然断链）。目标是使「账本可审计」从纪律声明变为任何第三方可独立验证的密码学协议。

**与王工作的挂点**：机制设计×信息设计中的**可验证披露/宣言**（verifiable disclosure）——披露的可信度不只来自激励，也来自承诺装置。指纹协议正是「统计声明工件化」（P-B）的承诺装置：让可验证宣言具备密码学完整性，披露方可验证地**无法**事后改写自己宣言了什么。**定位声明：P-D 是 P-B 的基础设施而非独立卖点**——它本身不直接回答失真界问题，但没有它，P-B 的「宣言」只是字符串。

**我方已有资产**：完整可运行的工程前身（5 枚 SHA-256 锚全部 PASS、冻结工件体系、首次重跑审计 PASS 记录），以及一条血写的教训：**字符串锚点审计 ≠ 真审计**（v36–v41 只做 grep 校验、从未重跑，直到 2026-08-30 才补上）；另有安全教训：密钥检测规则自身曾泄漏密钥片段（已净化）——指纹方案设计必须把「验证器不泄漏被验证内容」列为显式需求。

**机械判死线（探索性档，两条，任一触发即处置）**：
1. **成本线**：若 12 个月内指纹协议不能在第三方复现场景中把审计成本降至人工 grep 审计的 1/10 以下（计时实验，n≥10 个独立审计任务，任务集与计时规程预登记冻结），则降级为工程附录，不再作为合作方向占用对方时间。
2. **表达力线**：若根指纹方案与现有 SHA 锚实践相比无表达力增量——即不能捕获任何单工件哈希无法捕获的篡改模式（工件删除、集合重排、追加日志回溯改写三类攻击的构造性检验，攻击脚本预登记）——则判死，归档为「哈希锚已够用」的否定结论，不回溯。

**双方分工建议**：我方出现有锚体系的全部工件、攻击脚本与计时实验环境；对方出可验证披露语境下指纹协议的形式化（披露承诺、验证成本、与激励约束的交互）。

**预期产出形态**：先出一份协议规范+开源参考实现（我方自足）；若表达力检验存活且 P-B 推进，指纹协议作为 P-B 论文的基础设施章节并入，不单独成文。

### P-C：审计强度的两相结构——制度空间的连续参数化

**问题陈述**：v3 原始定义中 v1 阻塞 / v2 穿越是同一实体在 g_aether 参数下的两个极限态。博弈论翻译：**同一博弈在「强审计」与「弱审计」制度下是连续参数族的两相**，中间是连续的制度空间。这与王老师固定价格机制工作（简单机制的近似比随信息参数连续变化，STOC'23 区间 [0.71, 0.7381]）精神同构：把「制度强度」做成可分析的连续参数，问保证如何随之变化。

**与王工作的挂点**：固定价格机制「结构参数→紧保证」方法论的平行问题；亦可与其信息设计议程合流（审计强度 = 一种连续的信息结构参数）。

**我方已有资产**：**已实测的两相划分（判死级降级证据）**——P2 中无环图势残余 ≤5.9e−16（数值零，精确势）、含环图中位 0.669（92.4% 高残余，触发降级判定 downgraded_to_approximate_potential_game），环结构（循环空间维数 ker(Bᵀ)）是审计动力学的划界参数。

**预登记判死线样板**：猜想「近似势残余 r 随循环空间维数 d=dim ker(Bᵀ) 满足标度律 r ≈ a·d^b（b>0）」。判死线：在含环图集（n=328）上做 log-log 回归，若 **R² < 0.3** 或 b 的 95% 置信区间包含 0，则幂律标度猜想死，改登记「分段/阈值」备选模型，不回溯。

**双方分工建议**：我方出图族生成（可控环维数）与残余测量管线；对方出两相结构的机制设计语义（制度参数进入效用/信息结构的方式）与两相划界的理论刻画。

**预期产出形态**：实证标度结果（我方独立完成可发技术报告）+ 若标度律存活，合作理论论文「审计强度的连续制度空间」。

**四问题的取舍说明（若对方只接一个）**：优先级 **P-A > P-B > P-D > P-C**。P-A 证据最实（谱事实已存在）、挂点最精准（直接对偶其已发表问题）、对方边际投入最小（形式化+分析，不依赖我方工程交付）；P-B 天花板最高（定义性工作）但失真界开放问题可能多年无解，须按长期线管理预期；**P-D 紧随 P-B，因为其为 P-B 的完整性基础设施**——工程前身已存在（首次重跑审计 PASS），探索性档，表达力线若不存活则快速判死不拖累主线；P-C 我方自足度最高，可作为合作的低摩擦起步项，先建立联合工作流程再上攻 P-B。

## 3. 沟通策略

**首次沟通只带一张幻灯片：判死三行 + 一个对偶问题**（思考文档 `docs/THINKING_V3_GT_CONTRIB_2026.md` Q7）：

- P2 势博弈：**降级为近似势博弈**（无环 5.9e−16 数值零 / 含环中位 0.669、r>0.30 占比 0.924 过降级线）；
- P3 耗散通道：**双向皆死**（非纯支付重参数化 0.1585；均衡集真实移动 0.8442），但换来机制性前提证据——谱条件 ρ(G)<1 由 g_a>0 构造性保证，无耗散时 338 个任务中 58 个（17%）发散；
- 由此问：「均衡的**稳定化成本**（烧多少不可逆代价留在均衡）是否像均衡迁移成本一样有紧界？」

这张图同时给出纪律证据与精准挂点，且不浪费对方时间去证我们已知为假的东西。

**三档强度声明前置**：任何口头/书面交流中，判死（已执行事实）、观察性（数值规律）、探索性（猜想）三档标签随论断同行；两个高压线主动亮出——「守恒≠真值」失真界是开放问题（非回避项）、硬惩罚 ×0.1 的 Goodhart 风险已列入我方工程前提。姿态：我们带来的不是结果清单，是一条「先把自家主张杀掉一半再谈合作」的管线。
