## 4. 禁示条款

- 不超过 1 页 A4(王老师时间稀缺)
- 不在摘要中写"我们认为"等主观措辞(用"判死 / 死 / PASS"等机械语言)
- 不在摘要中复述实验细节(留给完整报告)
- 不在 D7 之外主动发摘要(避免显得焦虑)
- 不在摘要中提 BOSS 测法技术细节(王老师视角不需要知道 RBR/RM 是什么)
- 不在摘要中承诺 Phase 1 启动(只列"后续选择", 让王老师拍板)

## 5. 锚点 SHA-256 前 12 位约定

D7 摘要必须包含:
- 至少 1 个 P-D 根指纹(7d6d3d39fad8 主线 / f88d855aaf83 PD2 / e66e44e63f5a EIS,任选 1-3)
- 4 份 SPEC 的 5 锚 SHA-256 前 12 位(在附件 JSON 中)
- 至少 3 个冻结 JSON 路径

## 6. 完整中文判死报告(备查附件,10-15 页)
