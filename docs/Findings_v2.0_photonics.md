## 一、映射表（抽象 → 可制造组件）

| Deposon 抽象 | 光子组件 | 物理同构 |
|---|---|---|
| g_eff = g_couple/(1+detuning²) | **ring 谐振器** | Lorentzian 谐振峰与公式**天然同构**（δ↔(ω−ω0)/γ） |
| t/r 分束 | **MZI** | cos²(Δφ/2)/sin²(Δφ/2) 功率分束，热相移器设置 |
| **耗散 a（以太不可逆沉积）** | **PCM 相变单元（GST 类）** | 吸收能量≥E_th 后非易失晶态→非晶态转变——"以太"最直接的**可制造化身** |
| g_couple 可调 | ECM/EAM 电吸收调制器 | 载流子注入调耦合强度 |
| 反向退火（50 步 ×0.9） | **绝热相位斜坡** | 逐步调谐各 ring Δω，收缩因子 ↔ 斜坡步进 |

## 二、实验结果

**P1 映射自洽性**：硬件级 t/r/a（ring+MZI+PCM 实现）守恒偏差 = 浮点零；
S6 全部 9 条直接 named 边硬件可达（9/9）。抽象散射公式与组件传递函数
在公式层等价——**v1.4 的物理叙事通过了第一次自洽性检验**。

**P2 可行性（真实边界，非走过场）**：22 图逐图损耗预算（SiN 0.1 dB/cm、
MZI 0.7 dB、ring 0.5 dB、PCM 1.5 dB、耦合器 0.2 dB，TYPICAL）：
- **14/22 图可探测**（残余功率 > 10×NEP@1Hz），**8/22 不可探测**——
  长路径累积损耗 >40 dB 耗尽 SNR 余量；
- 规模定律：每跳 ~2.9 dB ⇒ **>14 跳即越界**；
- 推论：**枢纽型浅层结构（S6 族——场的基本盘）天然适配光子实现**；
  长链/深层复杂脑图需中继放大或更低损耗工艺。
  这与领域鉴定器形成跨层互证：**场有效的图（高 hub）恰好是光子可制造的图。**

**P3 拓扑优化**：三拓扑对比——指标最优 = shared_bus_ring（MZI 数 49→44、
总插损最低 108.25 dB），但单总线使全部节点共享一个 ring、丧失逐节点独立
detuning（g_eff 个性化的物理基础）；**工程推荐 = hybrid_tree**（保留逐节点
ring，组件数居中 138）。双口径如实并列：指标最优 ≠ 功能最优。

**P4 退火 = 相位斜坡（硬件可实现性）**：热相移器典型控制精度
σ≈0.01–0.05 rad（TYPICAL）下斜坡保真偏差 <σ 量级（噪声不放大）——
50 步退火调度硬件可实现；σ≥0.2 rad 时噪声超过后期步进（0.17 rad 偏差），
需反馈稳相——硬件边界如实标注。
