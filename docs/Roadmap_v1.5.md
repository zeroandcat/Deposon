# Roadmap v1.5 — 凝子场扩散生成（Deposon Diffusion）

## 方向概述

v1.5 将凝子散射层从"路径筛选器"推广为"结构生成器"：以凝子格点化场为生成对象，用扩散式前向/反向过程在图结构空间做生成，并用散射审计量作为内生的质量判据（生成-审计同体）。

管线：

1. **凝子格点化场**：候选图/器件/推导结构表示为凝子格点场（节点=格点，携带类型、能量、g_couple/g_aether、势垒等参数）。
2. **前向热化加噪**：按类型分布与边权分布对场逐步热化加噪，直至退化为已知先验。
3. **反向退火去噪**：逐步退火重建结构；**每步去噪结果过 T+R+A=1 幺正性硬投影**，保证中间态始终是合法散射场。
4. **条件生成 = 边界值问题**：已知元件规格作为边界条件（Dirichlet 式固定），生成在边界约束下求解内部场。
5. **物理判据即质量度量**：散射通过率 / 陷阱捕获率直接作为生成质量的物理判据——生成器与审计器共用同一散射内核，无需外挂判别器。

## 三大鸿沟（开放问题）

1. **离散性**：图结构（节点类型、拓扑）是离散的，扩散需要连续松弛——候选方案为单纯形连续化 + argmax 回投影。
2. **条件化**：把"已知元件规格"形式化为严格的边界值条件（哪些自由度固定、边界如何传播到内部场）。
3. **置换等变**：图的置换对称性要求噪声调度与评估均置换等变，否则先验在等价图之间不可迁移。

## G2 教训（硬约束）

G2 集成消融（Table 9，run_g2_ensemble.py 重写版）表明：无场引导的采样崩溃至 1–2%，Born 加权虽有增量但远不及场引导 argmax。**扩散生成的 score 函数必须含场引导项**（场透射/能量梯度），纯计数或无场采样不可用作生成分数。

## 与 v1.4 的关系

- 复用：统一极限参数化、T+R+A=1 幺正性投影、散射审计器（§4.3）、陷阱基准（§4.1）直接充当生成的质量评估器。
- 新增：格点化表示、热化/退火噪声核、边界值条件化求解器。
- 风险：G2/G3 的负面结果提示"时间换质量"与"势垒通道"均非免费午餐；v1.5 的任何增益声明都须以可复现脚本 + 种子固定为门槛。
