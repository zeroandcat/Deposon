## 二、脑图方向：成立的主张（保守口径）

1. **场=骨架检测器（结构上成立）**：全候选协议下 field_mean 在枢纽/链式结构上
   显著优于 degree 基线（H-A2 跨口径稳健，16/16 正，p=3.05e-5，过 Holm）。
   ——`results/deposon_v20_corpus_eval.json → verdicts.H_A2_field_mean_gt_degree`
2. **先验=语义检测器（语义上成立）**：labels-only LLM 先验在真实语义图（族 L）
   named Hits@3 0.48–1.00，4/4 域第一；biology 域 = 1.000。
3. **价值域正交互补**：枢纽集中度是场效力的主导预测子（OLS β=2.12, p<0.001），
   给出两特征领域鉴定器（hub_concentration, real_semantics）。
4. **融合不增（稀释效应）**：λ∈[0,1] 凸组合在任一图上均不优于单臂最优——
   「1+1<2」是稳定现象而非调参失败。
5. **机制性免疫**：自适应攻击者 100% 绕过关键词规则基线，场对语义陷阱免疫
   （GT-2，evasion=1.0 / field 塌陷=0）。

## 四、博弈论方向：已实证的三个结果

1. **GT-1 势博弈解释成立**：噪声反向动态（dirichlet）相对确定性极限（mean-field）
   收敛差 gap=0.30≥0.2，且 20/20 运行严格劣于极限——场可解释为势博弈的无噪声
   最优反应极限（理论锚点：Monderer-Shapley 1996 / Sandholm 2010 / graphon 极限）。
2. **GT-4 场有协调价值**：median PoA=1.5>1.2；族 L 上 PoA<1（负协调）如实披露——
   与分工叙事一致：场只在结构域创造价值。
3. **GT-2 边界定理实证版**：自适应攻击下规则防御退化至机会水平——
   机制设计（守恒账=承诺装置）叙事有实证支撑。
4. 文献定位（80 条全核验）：三个空位——势博弈×扩散模型交集 / PoA≈Pigou 4/3
   实例级复现 / 边界分析体裁（Negative Results 范式）。
