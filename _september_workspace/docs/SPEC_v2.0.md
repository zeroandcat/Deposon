# SPEC v2.0 — 多图语料预登记（三大规律设计 × 博弈论转向首批实验）

> 2026-08-28 预登记。先于任何 v2.0 数据产生。分析方法与判定规则冻结于此；
> 修正只能以「修正案」追加，不得回溯改写。
> 设计思想：量变质变（找相变点）、否定之否定（结构性否定 v1.9 图）、对立统一（成对孪生图）。
> 三轨纪律：大材小用（只打可验证靶点）、落到实处（每实验有 JSON 交付）、与死同行（每条假设带斩杀线）。

## 1. 语料构成（≥8 张，R3 最小档）

### 族 S：结构合成族（零 API，6 张）——否定之否定
v1.9 单图是「9 纯辐条 + 汇聚 GOAL」的场偏置完美对齐特例（R1 开放问题 #1）。
族 S 逐型否定该结构，检验 H-A（mean-field 场=骨架检测器）的成立域：

| 图 | 结构 | 否定的对象 | N（节点） |
|---|---|---|---|
| S1 | 单链（root→…→leaf 线性链） | 辐条/汇聚 | 20 |
| S2 | 平衡二叉树（深度 4–5） | 单 hub | 31 |
| S3 | 多 hub 竞争（3 个 GOAL 式汇聚点） | 单汇聚 | 30 |
| S4 | 带横向跨链的 DAG（层级+跳跃边） | 纯树 | 40 |
| S5 | 稀疏随机 DAG（Erdős 式，无枢纽） | 一切枢纽结构 | 45 |
| S6 | v1.9 同型辐条汇聚图（对照锚点，新种子新标签） | —（肯定项，检验可复现性） | 45 |

named/filler 操作化定义（冻结）：named = 主干结构边（链/树的父子主链、DAG 的最长路径族），
filler = 其余结构边；不加任何诱饵边（v1.4 教训：不自建对抗性）。
标签：族 S 用程序化概念层级（内置小本体，零 API），标签语义与结构脱钩——
LLM 先验臂在族 S 上只作辅助臂，主终点不靠它（先验价值在族 L 检验）。

### 族 L：LLM 生成族（API，2–4 张）——真实语义
- 由 kimi 生成真实概念脑图（给定主题域 + 结构约束），prompt_sha256 落盘，
  同源污染风险声明（先验臂与生成臂同模型族）。
- 主题域选择对立统一原则：两个「抽象→具体」域（如物理概念、生物分类）+
  两个「过程→结果」域（如算法流程、历史因果），方向语义天然相反，
  用于检验 GOAL 中心反向是否语义惯例差异（v1.9 开放问题 #3 的廉价版）。

### 量变质变扫描（叠加在族 S 上）
对 S1/S2/S6 三型各做 N ∈ {20, 35, 45, 60} 尺寸扫描，named Hits@3 随 N 的曲线：
寻找场效应的出现/消失相变点（若有）。预登记：相变点定义 = 相邻两档 named 差 ≥0.3。

## 2. 主终点与判定（冻结）

- 主终点：每张图 named Hits@3（全候选协议，E9.2 raw 口径），臂 = field_mean。
- 主比较（α=0.05，Holm 校正 4 检验）：
  - H-A1：field_mean > random（图级符号检验，G=8 起步）
  - H-A2：field_mean > degree（同上）
  - H-B1：field_mean filler Hits@3 < 0.15（骨架检测器边界跨图复现）
  - H-S6：S6 复现 v1.9 锚点（named ≥0.8）——可复现性检验
- 辅助臂：llm_prior（族 L 才主报）、Adamic-Adar、Jaccard、规则过滤（平凡基线前置）。
- 图级统计：符号检验为主；图级 cluster bootstrap（B=10000）报 95% CI；
  边级 McNemar 仅辅助并声明行聚类。overall 一律非劣效口径（TOST 0.03）。
- **斩杀线**：H-A1 不显著或 ≥3 张图效应反转 → H-A 判死，转「适用边界」论文；
  H-B1 在 ≥3 张图上 filler ≥0.15 → 「骨架检测器」边界主张撤回。

## 3. 博弈论首批（GT-1 / GT-4，零 API，先于族 L 完成）

- **GT-1 势博弈收敛**：同一留一任务上，噪声反向（dirichlet，T=20 个独立运行）
  vs 确定性反向（mean-field）的命中率差与收敛分布。命题：噪声动态收敛于势函数
  局部极小（named 命中率显著低于确定性极限）。判定：dirichlet 命中率均值 <
  mean-field − 0.2 且 20 运行中 ≥15 劣于 mean-field → 支持势博弈框架；否则 GT-1 判死。
- **GT-4 无政府代价（PoA）**：每张图上 PoA = field_mean named Hits@3 /
  max(greedy 自利臂 named Hits@3)。自利臂 = {random, degree, llm_prior}。
  判定：全图 median PoA > 1.2 → 场有协调价值；median PoA ≤ 1.05 → GT-4 判死
  （场无协调价值，v2.3 前重写博弈论叙事）。

## 4. GT-2 自适应攻击者（族 L 完成后，低耗 API）

攻击者知道规则关键词表 {trap,dead,end,impossible,guess,wrong}，
用 LLM 生成**绕过关键词**的语义陷阱标签（如同义改写 dead-end→cul-de-sac），
注入族 L 图；防御方 = 规则过滤（原表）与 field_mean。
判定：规则防御在自适应攻击下准确率塌陷 >20pp 且 field_mean 保持 → 场有独立于
关键词的防御价值（H-C 的第一个潜在反例）；两者都塌陷 → 公开披露，防御主张全面降级。

## 5. 工程纪律

- 图生成器确定性（seed 落盘）；每张图一个 JSON（结构+标签+named/filler 划分+sha256）。
- LLM 调用：预算族 L ≤ 8 prompt × 2 次尝试；GT-2 ≤ 4 prompt × 2 次；
  key 仅从环境变量读取，prompt_sha256 落盘，缓存幂等。
- 阴性结果 `_negativeresult.json` 归档；verifier 新版本验收；GitHub 留痕同步（无论文）。
