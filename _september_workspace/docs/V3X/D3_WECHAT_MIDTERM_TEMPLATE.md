## 0. 简报格式约束(王老师 ≤ 5 分钟微信)

- **总长**: ≤ 5 行(微信阅读时长 < 30 秒)
- **行数固定**: 3 行判死状态 + 1 行总览 + 1 行签名
- **判死状态二元**: 生(✅) / 死(❌) / 在跑(🟡)— 三选一,不允许"部分通过""待定"等模糊措辞
- **数字附后**: 关键数字以括号附后,不超过 10 字
- **不写段落**: 微信不渲染段落,所有内容单行化
- **不附问题**: 不在简报中再问任何问题(王老师已回"不指定"=三问全默认锁定)

## 1. 微信中期简报模板(D3 起 5 行格式)

```

KT-A1: {生/死/在跑} ({关键数字 ≤ 10 字})

KT-D0: 引用已闭合 PASS
{1 行总览: 整体状态/预计 D7 交付时间}
— Mavis
```

## 2. 判死状态说明

| 状态 | 含义 | 触发条件 |
|---|---|---|
| ✅ **生** | 判死线成立(PASS) | 对外判死线 + 内部判死线双跑 PASS |
| ❌ **死** | 判死线不成立(FAIL) | 任一判死线 FAIL,且 BOSS baseline 不抵御 |
| 🟡 **在跑** | 跑中未出判死 | D3 当日仍在跑,D5 出判死 |

## 3. 关键数字约定(≤ 10 字/条)

- KT-A1: `H1 ≤ 1.3× (1.18)` / `H0 ≥ 2.0× (FAIL)` / `Mann-Whitney p=0.013`
- KT-B1: `攻击 ≥50% (52%)` / `攻击 <50% (FAIL)` / `AUC 0.83`
- KT-C1: `R² 0.71 b=0.42` / `R²<0.3 (FAIL)` / `b CI 含 0 (FAIL)`
- KT-D0: 不附数字,只"引用已闭合 PASS"

## 4. 1 行总览示例

- ✅✅✅✅: `4 线全 PASS, D7 摘要 ready`
- ✅✅❌✅: `3 PASS + KT-C1 死, 主线成立, 副线降级`
- ✅🟡🟡✅: `KT-A1 闭合, KT-B1/C1 在跑, D5 末判死`
- ❌✅✅✅: `KT-A1 死, BOSS-A1 抵御? 待 D5 末`
