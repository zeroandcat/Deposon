## 一、判定总表（α=0.05，Holm m=4）

| 假设 | 判定 | 证据 |
|---|---|---|
| **H-A1** field_mean > random | **支持**（G=20：15+/3−/2 平，p=0.0075，过 Holm） | 跨 20 图成立，不再依赖单图 |
| **H-A2** field_mean > degree | **支持**（18+/0−/2 平，p=7.6e-6） | 度基线全面被压 |
| **H-B1** filler < 0.15（骨架检测器边界） | **支持但出现 2 例违规**（斩杀线 3 例未触发） | L_algorithm_process 0.158、**L_historical_causality 0.344** |
| **H-S6** S6 复现锚点 | 0.471 < 0.8 阈值未达，**但逐位复现 v1.9 E9.2 同协议锚点 0.470588** | 阈值口径来自旧 N_NEG=10 协议；同协议复现为强回归信号 |

**核心边界发现**：锚点图 named=1.000 的奇迹**不泛化**（新结构 0.04–0.47），
但「场优于 random/degree」**泛化**（20 图符号检验显著）。H-A 的成立域 =
「相对平凡结构基线的优势」，不是「绝对天花板」；绝对水平随结构否定而塌缩——
否定之否定的设计目的达成：v1.9 的强主张被否定，保留的合题是稳健但有限的相对优势。

## 二、三大规律实证回收

1. **量变质变**：S1/S2/S6 三族 N∈{20,35,45,60} 扫描——named 随 N **平滑衰减**
   （如 S2: 0.222→0.069），相邻档差均 <0.3，**未检出相变点**（阴性结果，如实归档）。
   规模不是场效应的相变旋钮；v1.9 的 n=1→n=20 才是本轮真正的质变。
2. **否定之否定**：六型结构否定逐项生效——单链/平衡树/多 hub/跨链 DAG/无枢纽随机 DAG
   上场的绝对命中率大幅低于辐条汇聚锚点；但相对优势（vs random/degree）在否定后
   依然存活（16/20 图）。被否定的是「场=通用骨架检测器」，保留的是「场=结构敏感的优势排序器」。
3. **对立统一**：族 L 四图按方向语义配对（抽象→具体 ×2 / 过程→结果 ×2）。
   矛盾显形：过程→结果域（historical_causality）filler 0.344 违规、场输给
   Adamic-Adar/Jaccard（0.043 vs 0.174/0.217）——**场的汇聚偏置与因果链结构反对齐**；
   抽象→具体域表现分化（biology 平 random、physics 输 rule_filter）。
   对立统一不是修辞：named/filler 的偏置对齐轴在真实语义图上旋转变向。

## 三、博弈论首批（GT-1 / GT-4）

- **GT-1 势博弈收敛：支持**。dirichlet T=20 均值 0.10 vs mean-field 0.40（gap 0.30 ≥ 0.2，
  20/20 严格劣）——噪声最好响应动态收敛于势函数局部极小，E9.1 升级为框架性证据。
- **GT-4 无政府代价：支持但有裂缝**。median PoA = 1.333 > 1.2（协调价值成立）；
  但 4 张真实语义图中 2 张 PoA < 1（L_historical 0.5、L_physics 0.75）——
  **协调价值在因果链/部分物理概念图上为负**，与 H-B1 违规同源的边界信号。
