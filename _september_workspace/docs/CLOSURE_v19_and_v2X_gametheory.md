## 二、三大规律复盘（复杂思维模型）

### 2.1 量变质变规律——积累到阈值，性质才跳变

- **图数量变 → 统计质变**：n=1 图时一切「显著」都是个案；R3 证明图级符号检验 G<6 连显著的可能性都不存在，G≥8 功效才到 0.80–0.87。**统计合法性不是渐强而是相变**：12 张图（标准档）是质变的临界质量，这正是 v2.0 的全部意义。
- **λ 参数的量变质变**：λ∈[0,1] 内融合是凸组合（量变），λ>1 跨出凸性边界瞬间变为反场 artifact（质变——11 条 filler 命中的机制整个翻转）。教训：参数空间的合法域本身就是一条质变线。
- **噪声 vs 信号**：负池扰动 sd≈0.066 时 overall 臂间差 < 噪声（量变淹没）；换全候选协议后采样器敏感性归零（协议质变）。**测量仪器的精度不到阈值，数据积累再多也不产生知识。**
- 对 v2.X 的推论：任何新场景先做「临界质量估算」（需要多少图/题才可能有质变），不达临界质量的实验不启动——这是「落到实处」的量变质变化。

### 2.2 否定之否定规律——螺旋上升，不是回到原点

- **正题（v1.4）**：物理层有效——GSM8K 85% vs 2%，效应量 0.83。
- **反题（v1.9）**：E9.4/E9.5 否定——效应结构性不可归因，6 关键词规则追平全管线；high_couple 0.86 是 bug。
- **合题（v2.X）**：不是退回 v1.4 的乐观，也不是停在 v1.9 的虚无——否定保留了真东西：① mean-field 场=骨架检测器（named=1.000 是反题中诞生的新肯定）；② 守恒账/可审计性（从未被否定的内核）；③ 预登记-修正案-阴性归档的方法论。**v2.X 的博弈论转向就是合题的形态：把「物理层有没有用」上升为「在什么博弈结构下、对谁、以什么代价有用」。**
- 每次否定都保留审计性这一内核、抛弃效应量虚荣——这正是「与死同行」的辩证法表达：旧我死亡是新我的存在方式。

### 2.3 对立统一规律——矛盾双方共处于一个势函数

- **场 vs 先验**：v1.7.1 视为竞争（λ 争抢权重），E9.1 揭示实为分工——场管骨架、先验管叶部，统一于同一评分函数；但先验叶部零覆盖使分工在本图失败。**矛盾双方既对立（稀释）又统一（同一势场），其转化条件是数据结构。**
- **named vs filler**：场的归纳偏置在 named 上对齐、在 filler 上反对齐——同一偏置是一体两面，overall 指标把两者平均是对立统一的误用；正确做法是分而治之（骨架子集主张 + filler 边界刻画）。
- **耗散 vs 守恒**：不可逆耗散零可测收益（对立面死了），但其死亡反衬出守恒账的独存价值（统一面上升）——v2.3 终审给这对矛盾正式下葬或复活。
- **攻击 vs 防御**：对抗性诱饵（v1.4 自建矛）戳穿了 v1.4 的盾（E9.4）——矛与盾同一设计者之手，这是 v2.X 博弈论转向最天然的入口。

## 三、v2.X 博弈论转向（理论框架）

### 3.1 转向的理由

v1.9 的三个发现本质都是**博弈论陈述**而非物理学陈述：
1. E9.4：偏置不在边权而在结构——**规则制定者（设计者）无意中兴建了对某方有利的博弈**（mechanism design 的反面教材）；
2. E9.5：规则基线追平 LLM——**高成本信号（LLM 先验）相对免费信号（关键词）无租金**（signaling 理论：信号价值 = 与廉价替代的分离度）；
3. E9.1：场=骨架检测器——**势函数在骨架方向上提供了全局最优的梯度**（potential game：所有参与者的最优响应被同一势函数统一）。

### 3.2 形式化框架（预备）

- **补全即势博弈（potential game）**：候选边为玩家，场值为势函数 Φ；mean-field 反向退火 = 向势函数极小点的确定性最好响应动态。可证命题候选：Dirichlet 随机起点 = 带噪声最好响应，收敛于 Φ 的局部极小（解释了 v1.7.1 的失败）；mean-field = 无噪声极限。**这把 E9.1 从经验发现升级为定理候选。**
- **先验即廉价空谈/信号博弈（cheap talk vs signaling）**：LLM 先验是无代价声明（cheap talk），其可信度须由 E4 式弃权、E1 式置换不变等「可验证性装置」支撑；规则基线是免费公开信号。**分离均衡存在条件 = Deposon 价值条件**：仅当先验携带规则不可得的分离信息时管线有租金——这直接操作化了 H-C。
- **审计即机制设计**：守恒账 = 承诺装置（commitment device）；verifier = 可验证披露（verifiable disclosure）。论文卖点从「物理隐喻」转「可审计机制」——与 v1.9 后论文的已改定位无缝衔接。
- **对抗即零和子博弈**：诱饵注入者（攻击者）vs 场+规则（防御者）。E9.4 说明当前防御者的胜利是设计者偏置的赝品；v2.X 要求**攻击者自适应**（知道防御规则后优化诱饵），只有在自适应攻击下仍存的防御才合法。

- **大材小用**：博弈论只用于给已观察到的现象立法（E9.1→定理、E9.5→分离条件），不做无实验承载的纯理论。
