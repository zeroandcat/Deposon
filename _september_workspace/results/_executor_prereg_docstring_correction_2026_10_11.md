### §2.2 实际实现（**L408–L417 · 逐字照录**）

```
408    min_score = gap * (m + n)        # 全 gap 退化
409    max_score = match * max(m, n)    # 全 match 对齐
410    if max_score == min_score:
411        return 0.0
412    norm = (raw_score - min_score) / (max_score - min_score)
413    # clamp 到 [0, 1] (DP 在 mismatch=-1 / gap=-2 时一般不会越界, 但 clamp 兜底)
414    if norm < 0.0:
415        return 0.0
416    if norm > 1.0:
417        return 1.0
```

### §2.3 闭式（**可复算**）

记 `M ≜ max(m,n)`、`S ≜ m+n`；代入 `match=+2`／`gap=−2`：

| 记号 | 定义 | 代入后 |
|:--|:--|:--|
| `N`（分子 · **两式恒同**） | `raw + \|gap\|×(m+n)` ≡ `raw − min_score` | `raw + 2S` |
| `D_字面` | `2 × max(m,n)` ＝ `match × max(m,n)` ＝ **`max_score`** | `2M` |
| `D_实现` | `max_score − min_score` | `2M + 2S` |

⇒ **`实现值 ＝ 字面值 × 2M/(2M+2S) ＝ 字面值 × ρ`**，`ρ ≜ M/(M+S) ＝ max(m,n)/(max(m,n)+m+n)` —— 即**字面式分母漏减负地板 `|min_score| ＝ 2(m+n)`**。

**`ρ` 之值域推导（`m,n ≥ 1`）**：设 `k ≜ min(m,n)`，则 `1 ≤ k ≤ M` ⇒ `S ＝ M + k ∈ [M+1, 2M]` ⇒ `ρ ＝ M/(M+S) ∈ [M/(3M), M/(2M+1)) ＝ [1/3, 1/2)`。
**下限取于** `m ＝ n`（`k ＝ M` ⇒ `S ＝ 2M` ⇒ `ρ ＝ 1/3`）；**上限恒不取到** —— `M/(2M+1) < 1/2` 且随 `M→∞` 单调趋近 `1/2`。

**本方实测（穷举 ＋ 随机）**：① `1 ≤ m,n ≤ 400` 全部 **160,000 组** ⇒ `ρ_min ＝ 0.33333333333333331`、`ρ_max ＝ 0.49937578027465668`、**越界组数 ＝ 0**（即 `[1/3, 1/2)` 成立）；② 随机 **5,000 组**（`m,n ∈ 1..6`、6 字母表）残差 `max|实现 − 字面×ρ| ＝ 1.1102230246251565e−16`（浮点级 ⇒ 恒等式坐实）；③ `ρ` 反例：实测得 `1/ρ ∈ (2, 3]` 之膨胀因子。
