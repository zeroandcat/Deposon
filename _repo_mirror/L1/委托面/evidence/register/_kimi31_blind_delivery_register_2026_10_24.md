## §4 `B-F` 之可执行判式（外委交付之实体收获）

外委所给判式（其 `T5_input_B_occupancy_K31B_2026_10_24.md` §B-2.2／§B-2.3 原文照录）：

```text
function FEAS(t, k, occupancy_table):
    if occupancy_table[t] is missing or unit_of(B_t) is NOT_IN_RANGE:
        return UNOBTAINED              # not the empty set
    require unit_of(occupancy_t) == unit_of(r_t_k) == unit_of(B_t)
    return { a in options_t : occupancy_t[a] <= r_t_k and h_t_k >= 1 }

function UPDATE(t, k, selected_action):
    require selected_action in FEAS(t, k, occupancy_table)
    r_t_(k+1) = r_t_k - occupancy_t[selected_action]
    h_t_(k+1) = h_t_k - 1
    n_t_(k+1) = n_t_k + 1
    return (r_t_(k+1), h_t_(k+1), n_t_(k+1))
```

组合规则（其 §B-2.3）：原子选择（一决策点恰选一动作）；序列 `(a_1,…,a_m)` 可行 **iff** 每一前缀于其自身 `k` 满足 `FEAS`，且 `Σ_{k=1..m} occupancy_t[a_k] ≤ B_t`，且 `m ≤ H_t`。

起始态（其 §B-2.1，`k=0` 即首动作之前）：`r_t_0 = B_t`、`h_t_0 = H_t`、`n_t_0 = 0`；其读法为**算子起始态为主、组合规则初值为辅**。

**三条可采之纪律性质**（本代理判读）：
1. **`UNOBTAINED` ≠ 空集**——缺输入时不得产出可行集基数、非空键结果、收窄计数或最大化器；此与在册「`不明`不可作终判」同族。
2. **资源与步数分维度**——异量纲不得运算，步限不得并入资源占用；此堵住「把步数当资源」之混算。
3. **占用不得由 payoff 或动作位次派生**——断了「反推正解」之路；此为盲态设计之实体保障。

**单位释义**（其 §B-1.1）：`unit`＝该格所名资源之不可分量子（物理身份与换算**未供**，跨场景不可通约）；`hour`＝3600 s、`day`＝86400 s（`NIST SP811 App. B.9`）；`round`＝一完整决策周期（起讫未供，故不作秒换算）；`step`＝模型中一次原子动作选择（**模型计数单位，非物理时间**）。
