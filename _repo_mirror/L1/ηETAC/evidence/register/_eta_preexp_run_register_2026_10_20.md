### §2-1 构造式（逐字照录 `d52a5d94a002` L77–L78）

```text
w(o) = (1 - η) · 1{v(o) = best} + η · g_couple · (v(o) / best) + g_aether
P(o) = w(o) / Σ_o w(o)     if the sum is positive
```

📌 **码载实现面之对照（本棒逐字实测·`ce64b9b97489` L187–L194）**：

```python
best = max(values.get(o, 0.0) for o in options)
for o in options:
    v = values.get(o, 0.0)
    t = 1.0 if v == best else 0.0          # 透射: 最优直达
    r = (v / best) if best > 0 else 0.0    # 反射: 价值耦合(归一化)
    a = self.g_aether                       # 耗散: 均匀底
    weights.append((1.0 - self.eta) * t + self.eta * self.g_couple * r + a)
```
