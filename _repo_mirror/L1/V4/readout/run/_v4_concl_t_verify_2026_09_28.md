## 3. 端点渐近分析（β→∞，即 `t_rel`→0）

由 `Γ_c = ½·asinh(1/sinh(2K))`，`K = 1/(4 t_rel) → ∞`：

- `sinh(2K) ≈ ½e^{2K}` ⟹ `1/sinh(2K) ≈ 2e^{-2K}`（小量）
- `asinh(x) ≈ x`（小量）⟹ `Γ_c ≈ e^{-2K}`
- `h_c/J = Γ_c/K ≈ e^{-2K}/K`

代入 `K = 1/(4 t_rel)`：`2K = 1/(2 t_rel)`，得

> **h_c/J ≈ 4 · t_rel · exp( -1 / (2 t_rel) )**

**数值验证（实测值 / 渐近式）：**

| `t_rel` | 实测 h_c/J | `4 t e^{-1/(2t)}` | 比值 |
|---|---|---|---|
| 0.05 | 9.079985958735387e-06 | 9.07998595249697e-06 | 1.00000000069 |
| 0.02 | 1.1110355091971214e-12 | 1.1110355091971216e-12 | 0.9999999999999998 |
| 0.01 | 7.714999391855672e-24 | 7.714999391855671e-24 | 1.0000000000000002 |
| 0.005 | 7.440151952041672e-46 | 7.440151952041673e-46 | 0.9999999999999998 |

渐近式在小 `t_rel` 区吻合到 ~1e-15 相对量级，**符号推导无误**。

**端点判定：`t_rel → 0` 时 h_c/J → 0，且为指数式趋零（`~ e^{-1/(2 t_rel)}`），既非 →1，也非发散。**
偏差随 `T→0` 发散一事，就本条曲线本身而言，**成立**。

## 4. 三元组 + 临界条件能复现 h_c/J = 1 吗？

本节是归因的关键，结论与直觉相反，故分三层实测。

### 4.1 三元组在 `t_rel = 0` 附近严格单调，`h_c/J = 1` 只在一个有限温度点上被命中

沿本棒复算的曲线 `h_c/J = 2 t_rel · asinh(1/sinh(1/(2 t_rel)))`，它关于 `t_rel` **单调递增**：
`t_rel→0 ⟹ 0`，`t_rel→∞ ⟹ ∞`。二分求解

> **h_c/J = 1 的落点：t_rel = 0.5672963285532555**

即：三元组给出的曲线**并非「处处给不出 1」**；它恰好在 `t_rel ≈ 0.5673` 处给出 `h_c/J = 1`，
在 `t_rel = 0.01` 处给出 `7.7e-24`。**「7.7e-24 vs 1」的偏差，是拿 `t_rel=0.01` 这一个特定温度点与 1 相比，而不是拿曲线的 `T→0` 端点与 1 相比。**

### 4.2 该命中点正是经典自对偶点（声明的约定是对的）

`K = Γ` ⟹ `sinh²(2K) = 1` ⟹ `K = Γ = ½·asinh(1)`：

> **K = Γ = 0.4406867935097715**

与 1D TFIM 的公认自对偶耦合 `0.4406867935` 相符（参考值仅给到 10 位有效数字，残差 `9.8e-12` 纯属参考值舍入，非不一致）。

且 `t_rel = 1/(4K) = 1/(4×0.4406867935) = 0.5672963286...`，与 §4.1 二分得到的 `h_c/J=1` 落点 `0.5672963285532555` **是同一个数**。

⟹ 声明的三元组（`K ≡ βJ/4`、`Γ ≡ βh/4`）连同 `sinh(2K)sinh(2Γ)=1`，**精确复现了 1D TFIM 的自对偶点**。这是该约定为标准约定的强证据。**三元组本身没有写错。**

### 4.3 该曲线是「自对偶 / 关联长度特征线」，不是有限温相界

`#12` 执行件自身已在两处显式登记了这一点，本棒逐字摘录：

- L114-122（件内自查勘误）：初版以「2×2 迁移矩阵 leading eigenvalue 简并」推导临界条件**有符号错误**，推得的 `h_c/J = 2 t asinh(e^{-2/t})` **已作废、不参与任何判定**；改用「1D TFIM 的标准精确临界条件 `sinh(2K) sinh(2Γ) = 1`」，并注明「1D TFIM 在有限 L 下恒有隙，量子临界是 L→∞ 极限的能级交叉，**不是**有限 2×2 迁移矩阵的本征值简并」。
- L673-674（结果件 `physical_note`）：「1D TFIM 在**有限 L 下恒有隙**；量子临界是 L→inf 极限的能级交叉，**不是**有限 2x2 迁移矩阵的本征值简并」。

⟹ **`#12` 从未声称其曲线的 `t_rel→0` 端点等于零温量子临界点 `h_c/J=1`；`#12` 自己就写明量子临界是能级交叉。**
结论 T 的否证所攻击的，是 `#12` **没有提出过**的主张。

## 8. 结论三态

> **(iii) 条件式**

否证**仅在附加前提 P 下成立**：

- **前提 P**：「三元组 + `sinh(2K)sinh(2Γ)=1` 给出的曲线，其 `t_rel→0` 端点必须等于该模型的零温量子临界点。」

**在前提 P 下**：
- §2 数值同值成立（`7.714999391855672e-24`）；
- §3 端点 `→0`（指数）成立；
- ⟹ R-J5 结论 T 的**算术与曲线行为描述均成立**。

**去掉前提 P（默认不接受）**，结论 T **不成立**，因为：
1. §4.1 三元组给出的曲线在 `t_rel = 0.5672963285532555` 处**确实给出 `h_c/J = 1`**，「不能复现 1」不成立；
2. §4.2 该点即自对偶点 `K=Γ=0.4406867935`，说明**三元组与临界条件都是标准正确的**；
3. §4.3 `#12` 自己已声明量子临界是能级交叉、不是该线——**结论 T 攻击的是 `#12` 未提出的主张**；
4. §5 死因是**口径错配**（有限温自对偶/特征线 vs 零温能级交叉），不是声明错误。

**因此对结论 T 的最终裁定**：
- 「`t_rel=0.01` 时该线读数为 `7.7e-24`」——**属实，本棒独立复算同值**；
- 「该声明三元组**错**」——**不成立**（三元组自洽，且命中自对偶点）；
- 「该声明三元组**不能复现**模型零温临界点」——**不成立**（曲线在有限温度处命中 1；两者非同一物理对象）。

**建议裁定时措辞**（供 verdict-keeper 取用，本棒 0 代判）：
把结论 T 由「三元组不能复现零温临界点」改述为——
「**该自对偶线在 `t_rel→0` 的端点为指数趋零，与零温量子临界点（能级交叉，`h_c/J=1`）非同一对象，不可同口径比较；`#12` 三元组本身正确。**」
