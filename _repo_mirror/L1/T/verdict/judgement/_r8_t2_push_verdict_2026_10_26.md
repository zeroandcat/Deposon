## §2 · 甲组明证之实（**逐条·本棒开卷**）

### §2-1 甲组三要点（① **7,597／`7803d32f7e49`** 之 **L18–L61**）

**(1) IC 与最小期望失真：有标准式，但须区分下界方向（L20–L38）**

- Fox–Tishby §2／§3.1 给出 `I_C = I(M_{t-1}, O_t; M_t) ≤ R_M + R_S`，及容量约束下的最小可达失真 `D*_θn(R_M, R_S)`。
- 📌 **L26 逐字**：「**`I_C ≤ R_M+R_S` 是信息率上界，不是容量下界。**」
- eLife Eq.1／Fig.1C 给出容量—失真关系 `D*(C) = min_{Q:R(Q)≤C} E[d] ⇒ D(Q) ≥ D*(C)`——即容量产生的是**最小期望失真下界**。
- 📌 **L34–L36 逐字**：若所问是「达到 `L_cand` 至少需要多少容量」，可由定义机械反演 `C_min(L_cand) = inf{C : D*(C) ≤ L_cand}`——「**这是替代判据，不是冒充原文公式**；双容量 `R_M`／`R_S` 应保留可行区域，**不能无依据合成一个标量**」。

**(2) `H` 与轨迹加权：文献只给有限步等权均值，**不给本项目之 `H` 值**（L40–L51）**

- Fox–Tishby §1.1 之目标为 `J_n = (1/n) Σ_{t=1}^{n} E[d(W_t, M_t)]`。
- 📌 **L46 逐字**：「**只有规格明确 `H=n` 时才能对应；不能仅凭字母相同认定。**」
- 由该式机械展开：若有 `N` 条轨迹，`D̂ = Σ_{j=1}^{N} w_j · (1/H) Σ_{t=1}^{H} d_{j,t}`，`w_j ≥ 0`、`Σ_j w_j = 1`；等权轨迹取 `w_j = 1/N`。
- 📌 **L50–L51 逐字**：「**这不是指数折扣；若规格另指折扣或 `H≠n`，须另给定义与证据。**」

**(3) `P_new ≥ L_cand`：现有一次局部优化结果不能证明（L53–L59）**

- 若 `P_new = inf_{π∈Π} J_H(π)`，**只有两类合格证书**（📌 **L55–L57 逐字**）：
  - **证书一**：**精确枚举或可信全局优化直接求得 `P_new`**，再与 `L_cand` 比较；
  - **证书二**：给出对**所有可行策略**均成立的 `LB ≤ J_H(π)`，并证 `LB ≥ L_cand`。
- 📌 **L59 逐字**：「Fox–Tishby §4.1、§4.4、§6 明确：完整序列问题非凸，算法只求局部最小。局部解费用是全局最小值的**上界**，不能用来证明所需的**下界**。因此，**`R-8` 不能凭这些文献直接归零**；仍缺**规格映射**及**全局证书**。」
