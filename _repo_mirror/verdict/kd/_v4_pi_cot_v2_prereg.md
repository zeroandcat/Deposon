## §1 学习目标结构（v2.2 核心）

从 PI 思维链文本提取**判据结构规则集**（IF 场景特征 THEN 判据类型序列/优先级/权衡模式），三面度量：

1. **可提取面（保真）**：推理文本中的判据结构可被规则化提取（判据类型确定性编码表：判死线/成本/准则/风险/时机/委托 6 类）。
2. **可迁移面（学习）**：规则集在 held-out 场景生成的推理结构与 PI 推理结构**相似度 ≥ 0.8**（判据类型序列对齐率）。
3. **批判性面（不盲从）**：规则集判定与 PI 判定**分歧处 100% 附显式批判理由**；**盲从率**（无理由一致）**≤ 0.10**——「批判性学习」的机械可判化。

## §2 claim（可证伪命题）

从 N≥50 跨日 PI 判定事件（推理全文必采）学得的判据结构规则集，在 held-out 判定事件上：(i) 推理结构相似度 ≥ 0.80；(ii) 分歧处批判理由覆盖率 = 100%；(iii) 盲从率 ≤ 0.10。任一不达标 = 批判性学习不成立。

## §3 实验设计

1. 采集：特制蒸馏问卷（Mavis 撰写，轻量型：一次 1-2 题、推理 1 句级），v2 样本单列 `_v4_pi_cot_v2_dataset.json`。
2. 规则学习：纯函数确定性（zlib.crc32/hashlib，禁内建 hash()），决策树 ≤4 层 + 判据序列模板；seed=42。
3. 检验：held-out 0.30 分层（含纠正）+ 判定-配对随机重排负对照（结构相似度维度）+ 排列检验 n=1000 + bootstrap CI 1000。
4. 双读法：主读法=全样本结构对齐；替代读法=剔除纠偏事件子集。分歧如实并报。

## §4 kill-line（三分支 + 批判性线，预注册即锁）

- **(a) 学习线**：结构相似度 < 0.80 → FAIL（思维结构学不到）
- **(b) 批判线**：分歧批判理由覆盖率 < 100% 或盲从率 > 0.10 → FAIL（批判性不足 = 画像式模仿）
- **(c) 稳健线**：bootstrap CI（1000, seed=42）下界 < 0.50 → FAIL

任一成立 = FAIL（限构造域）；全不成立 = PASS。判定表每行附根因三分类。
