## 2. 补审构造（沿预登记 §1.2 #10 (a)(b)(c) 字面，0 私设阈值）

```
(a) model 维真 variation —— 逐 model 抽 model-specific 子集
    逐 model m 从「该 model 自己的 60-cell 标签总体」按 N 档重采样：
      k ~ Binomial(N, T60_m/60)   （从固定 60-cell 总体有放回抽样的精确边缘分布，非近似）
      p_draw = k / N
    N 档 = [5, 10, 15, 20, 30, 40, 60]   （沿 P_C spec §4.1「跨 7 档 N」字面；另附 2 档敏感性网格）
    逐 model 独立重算幂律 R² —— 不沿用 V2 阶段 5 全 pooled dataset

(b) η 重解释为温度抖动（Langevin-style，取代原「纯 scaling 旋钮」读法）
      logit(p_draw) <- logit(p_draw) + scale · z,   z ~ N(0,1)
      scale = η（logit 绝对温度；另附 η/100 归一化温度敏感性腿）
    逐 (model, N, η) 独立 RNG 流（np.random.default_rng([SEED, mi, N, j])）

(c) per-model bootstrap 95% percentile CI，n = 1000（沿 §1.2 #10(c) 字面）
```
