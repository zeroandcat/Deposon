### §2.2 为什么「v2 面上 α 腿不可 PASS」是**结构事实**而非读数巧合（只读复算，0 翻案）

把 `361aff516219` 的两处字面接起来即可**闭式**读出 `field_mean` 臂的行为，无需任何统计：

1. `options = [gold] + tset + decoys`，其中 `len(decoys) = 3 − T`（L64-66）⇒ 选项内**图内候选取数量 ≡ (3 − T) + 1**（gold 本身在图内）。
2. 陷阱标签不在图节点集内 ⇒ `s = fscores.get(o, -np.inf)`（L107）⇒ **陷阱永不参与竞争**。
3. ⇒ `field_mean` 的唯一失分来源 = **某个图内诱饵的场分超过 gold**，而**诱饵数 = 3 − T**。
4. ⇒ `acc_field_mean` 是 `3 − T` 的**单调非增**函数 ⇒ **`acc` 随 T 单调非减**；且 `T = 3 ⇒ 诱饵 = 0 ⇒ 失分不可能 ⇒ acc ≡ 1.0`。

**盘上实测与该闭式读出一致**：`a2ae7997ee67` 的 `field_mean` = `0.375 / 0.525 / 1.0`（严格递增，终端恰 `1.0`）；`b59bef293712` §3.2 `C1` 记 v2 面 24/24 域级值 `≡ 1.000`、零变异。

⇒ **α 腿（`|acc_field(T) − acc_field(1)| ≤ field_tol` 对所有 T）在现构造下的 FAIL 是构造必然**，不是素材或工具的偶然失灵。**这与 v2 判定件裁「假证伪」同向、只加强不推翻**：v2 终态 **FAIL 一字不动**（§2.3）。

## §4 构造候选（**≥2 案并列 · 0 自创即定 · 每案不预判档位**）

> **共线为何是恒等式（先说清约束）**：`n_options_fixed = 4` + 「1 gold + T 陷阱 + D 图内诱饵」⇒ `1 + T + D = 4` ⇒ **`D ≡ 3 − T`（在恒 4 项约束下 T 与 D 数学上不可能解耦）**。⇒ **任何 v3 案都必须至少放弃「恒 4 项」之一**（恒 4 项 / T ∈ {1,2,3} / D 恒定 三者不可同时成立）。这是本件的核心几何事实，**不是偏好问题**。

### §4.1 候选总表

### §4.2 逐案详述

#### **A-案 1｜保恒 4 项 · 削 T 档（`T ∈ {1,2}`、`D ≡ 1`）**

- **定义**：`build_bank_t` 的 `decoys` 长度由 `3 - T` 改为**常量 1**；`T_LEVELS = (1, 2)`；`options = gold + T traps + 1 decoy` 恒 4 项。判据（`field_tol = 0.05`、三态表、刀锋规则）**一字不改**。
- **与 `C0` 的关系**：**共线被解除**（`D` 恒为 1，`T` 只改陷阱数）。但**根因未消** —— `C4` 原样：陷阱仍 `-inf` ⇒ **`field_mean` 仍然永不与陷阱竞争**；T 抬升仍只改变「非陷阱选项」的构成（本构造下选项集恒 4，唯一的构成变化就是陷阱标签替换）⇒ **该案治的是「共线」这一个症状，不是「陷阱从不构成竞争」这个病**。
- **代价 / 风险**：①**丢档**：T = 3 消失 ⇒ `C1` 结构性恒等格（24/24 ≡ 1.000）**在新面结构性不可达** ⇒ 但这不等于「病好了」，只等于「病最显眼的那个格子没了」；②**`C1` 的诊断价值随之丢失**（它是 v2 判定裁假证伪的独立机械证据）⇒ 新面须**另找**非同退化证据，否则「α 腿 PASS」将**无法与「诱饵少了」区分**；③`N_ITEMS_PER_MAP = 10` × 域 ⇒ 每格 items 数与 v2 同量级 ⇒ 粒度披露义务照旧（§5.2）；④与 as-run 面（3 T 档）**不可直接混池**（面形状不同）。
- **对既有三态与结论上限的影响**：**v2 三态 0 触动**；v3 三态**独立**落档（`0/1` 档位**本件 0 预判**）。结论上限 = **v3 构造域**（`2 T × N seed × 4 域 × 40 items × 3 臂`）；`C3`（4/6 域）**照旧生效** ⇒ 0 外推全 6 域；`C4` 机制免疫披露**必须随 v3 结论同读**（沿 `b59bef293712` §8）。

#### **A-案 2｜双因子全交叉（弃恒 4 项）**
