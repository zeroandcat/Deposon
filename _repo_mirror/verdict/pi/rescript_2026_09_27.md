## 5. 根因分离：4 组对照（工具失灵 vs 构造失灵）

| 对照 | 做法 | 实测 | 证明什么 |
|---|---|---|---|
| **CTRL1 正对照**（synthetic，**不作判定证据**） | 同 {30,60,540} 网格下给**档间有变化**的 P（`P = 2.0·C^(−0.45) + 0.02` × seeded 噪声） | `r2_full` = 0.99972806 / 0.99991333 / 0.99984361；2 点裁剪 `r2_clipped` **≡ 1.0**（SS_res ≈ 1e-31）；delta = −0.000272 / −0.000087 / −0.000156（**≠ 0**） | ① 执行器**非退化**（有档间变化时能给有定义 R² 与非零 delta）；② 2 点裁剪的 R² ≡ 1 是**代数必然** ⇒ delta ≡ r2_full − 1 ⇒ **PASS 分支机械饱和、FAIL 分支不可达**（顶替面即使有数据也承载不了 FAIL 档） |
| **CTRL2 no-op 复现** | 把 clipped 阶梯错算成 full 阶梯（复现 V3 no-op 形态） | **3/3 delta = 0.0** | 执行器**能**返回 0 ⇒ 0 恒返回非零 |
| **CTRL3 反事实**（**仅证机制，0 作判定证据**） | 仅对 30 档计数加 seeded ±1 cell 抖动，打破 `T60 = 2×T30` 恒等 | `r2_full` = 0.469958（3/3 有定义）；delta = −0.530042（≠ 0）；扫描 0.3→PASS / 0.5→FAIL / 0.7→FAIL | **只**打破档间恒等即让 R² 恢复有定义 ⇒ 顶替面的未定义源于**数据恒等（构造不适用）**，**0 是执行器/工具失灵** |
| **CTRL4 设计算术探针** | 用真实 P 直接算 3 个裁剪变体的 `r2_clipped` | [60] → 点数 < 2 未定义；[30,60] / [60,540] → `SS_tot = 0` 未定义（SS_res ≈ 1e-34） | 本件比「PASS 饱和」更早一步：**连 2 点裁剪都未定义** |

> **根因判定（沿「诚实的根因是不误导」纪律）**：顶替口径的不可判 = **构造失灵（构造不适用）**，**0 是「命题被证伪」**。cell 计数档是同一 cell 集的精确倍增/汇总，对标度律问题（难度/规模轴）**0 携带信息量**——它不是「数据噪声太大」，而是**该轴按定义无变化**。
