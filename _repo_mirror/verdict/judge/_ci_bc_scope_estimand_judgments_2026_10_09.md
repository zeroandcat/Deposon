### §2.3 本官独立判断

> **结论 K-1 ＝ 条件适用，采「同门柱 · 分母口径化」档。**
> **表述**：① **在 PI 未另给「分母口径化等效门柱」数值之前，`0.1100` 半宽门对 B／C 两线恒不适用**（非「免比」之默许，而是「该门在 S4 构造域内对其结构性不可达」之如实登记）；② **若 PI 坚持 B／C 亦须受半宽门约束**，则须**由 PI 另给一个按分母规模／比率方差口径化的等效门柱**（如对比率类统计量以 `√(p̂(1−p̂)/n)` 之口径设门，而非直接沿用均值类统计量之 `0.1100`）；**本官 0 自设该数值**（数值权限在 PI，沿 `329c1c5e91d1` §4.1 之权限判定）。③ **无论 PI 采何者，B／C 均不得被默默豁免** —— 须**显式登记**其「受何约束／不受何约束」。

**理由一（为何 0 采「照字面适用」—— 空门之机械必然性）**：`h ∈ [0.25, 0.3125]` ＝ 门柱之 `2.27`–`2.84` 倍；两套独立算法反解之 `n_req ≈ 55`–`171` ≫ 上界 `37` ⇒ **在 S4 构造域内不可能达成** ⇒ 该门于 B／C 恒「不达标」⇒ **0 分辨任何构造、0 分辨任何素材面，只产出一条恒定读数** ⇒ 与 PI 已裁死之 `held-out ≥ 50` **同病同源**（`329c1c5e91d1` §3.3）。**FTFB 之要义在「门须能证伪」：一条恒不触发的门 ＝ 0 证伪力。**

**理由二（为何亦 0 采「默默免比」—— B／C 是 C-1 的判别力所在）**：⚠ **此为本官 0 采免比之最实质理由**。盘上事实：**当前 C-1 口径下，A 线（含 A／D 之 CI）之半宽几乎恒在 `0.1037`–`0.1444` 之内**（`329c1c5e91d1` §2 表第 1–5 行：v3 `0.1326`／alt `0.1444`／v3r1 `0.1165`／r1 `0.1037`／v3r1-alt `0.1111`）⇒ **同一 held-out 集之下，三构造之半宽全部落入门柱 `[≤0.1100]` 之邻近带（`0.1037`–`0.1444`）** ⇒ **A 线之半宽门在现有盘上证据中几乎 0 分辨力**（区分不出三构造）。**若再将 B／C 免于任何 CI 约束，则 C-1 将成为「0 证伪力之线」** —— 恰是 `329c1c5e91d1` §5.2 已作之让步面（「C-1 确为代理量」）之极端化。**故 B／C 须留在判读面内，但须以可达之口径留在。**

**理由三（为何是「分母口径化」而非「另设更宽之数」—— 后者违「0 事后调」之同一病）**：若 PI 仅为 B／C 另给一个「宽一点的数」（如 `0.30`），则该数**只能由观测值反推**（盘上 `0.25`–`0.3125` 之邻近）⇒ **阈值成为观测值之函数** ⇒ **复现 `329c1c5e91d1` §5.1 已驳之「看着结果立线」**。而「按 `p̂(1−p̂)/n` 口径化」之形式**先于观测**（比率方差之公式在任何比率统计量上皆成立），其数值仍须 PI 给，**但数值之由来可被独立复算、可被证伪** ⇒ **形式之正当性与数值之裁量被分离**。**此为本官判断之核心结构。**

**理由四（为何 B／C 之分母规模本身是其病源，构造面须绑）**：B／C 之分母 `n ∈ [8, 15]`（v3/v3r1 面）**远小于 A 线之 held-out 全域 `n = 23`** ⇒ **同一 `0.1100` 施于不同分母规模之统计量，本身即是「口径不可比」** ⇒ **本判断之第一顺位结论是「口径须按分母归一」，第二顺位才是「数值须 PI 给」** —— 前者可由本官判定，后者不可。

**⚠ 须 PI 给之出口（本判断明确保留，三项）**：

1. **数值出口**：若 PI 采「条件适用」之第二腿（B／C 须受半宽门），**须 PI 另给分母口径化之等效门柱数值**（本官 0 自设、0 代裁、0 沿用 `0.1100` 之形）。**附本官之可复算参照区间（供 PI 勾选 · ⏳ 0 代裁）**：以 `√n` 缩放法，取 n=23 之观察半宽中位（约 `0.2692`）为锚，`n_req = 23 × (h/0.1100)²` ⇒ **若 PI 采「与 A 线同 δ 相对形」（δ ＝ 17.0492%，`4ab2464a266e` §2.3）**，则 B／C 之分母口径化门柱 **须另算、不可直接沿用** —— 故本官**只给形式，不给数**。
2. **范围出口**：若 PI 采「免比」，则须**同时明示**：B／C 在 C-1 之判读面内**是否受任何 CI 侧约束**？**若全无 ⇒ C-1 于 B／C 之判别力归零**（本官**强烈不建议**，理由二）⇒ **「免比」不应等于「免 C-1 对 B／C 之任何约束」**。
