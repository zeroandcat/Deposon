## §4 本体注册表（5 个 = 派工单建议 4 个 + 增补第 5 个，理由先声明后跑）

| ID | 本体 | 派工槽位 | 动力学（可复算字面） | 目标可达 |
|---|---|---|---|---|
| **O1** | 离散 cell 重分配 | 建议 ①（= 第一梯队基线） | 60-cell 整数三元组 (T,R,A) 每步把 1 个 cell 从盈余最大类移到亏缺最大类，直到命中扰动目标三元组（R/A 按盘上真实 r0:a0 比例吸收 T 份额差额）；步数 = n_iter；结构上限 60 必收敛；`priority=surplus_first` | 是 |
| **O2** | 连续时间 replicator ODE（字面） | 建议 ② | 2 态 (T vs rest)，`ẋ = x(1−x)(f_T − f_A)`，RK4（dt = 5e-3）；fitness 由扰动条件植入 `f = (x0, 1−x0)`；命中 = 到最近**边界**不动点距离 ≤ TOL | **否（可证）** |
| **O3** | logit/量子响应动态（logit 正规形） | 建议 ③ | 2 态，`logit(x_{k+1}) = (1−s)·logit(x_k) + s·logit(x0)`，s = 0.25（softmax 响应映射的 logit 正规形）；内点不动点 ≡ x0，几何收敛 | 是 |
| **O4** | imitation dynamics（按收益差比例复制） | 建议 ④ | 2 态离散 replicator 映射 `x_{k+1} = x·u_T/(x·u_T + (1−x)·u_A)`；收益矩阵 `A(x0) = [[0, x0], [1−x0, 0]]`（反协调，内点 NE = x0，收益差 `D(x) = x0 − x` 斜率 −1）；命中 `|x − x0| ≤ TOL` | 字面「是」→ **实测退化为常值映射，见 §7 PR-2** |
| **O5** | 连续时间 replicator ODE + 软竞争 | **增补第 5 本体** | 3 态 (T,R,A)，`ẋ_i = x_i(g_i − ḡ)`，`g_i = c·(f_i − x_i)`，c = 0.5，RK4（dt = 0.05）；`f` = 扰动目标三元组（归一化份额）⇒ 内点不动点 ≡ f、负频依赖稳定、Σx_i 严格守恒；命中 `max_i |x_i − f_i| ≤ TOL` | 是 |

**增补第 5 本体的理由（先声明）**：O2 字面与 O4 字面都在**数学结构**上有已知坏点
（O2 只有边界不动点；O4 内点 NE 处 `|g'| = 1 + x*(1−x*)D'/2 ≥ 1` 恒扩张）——
「它们在本数据上到底能不能用」须分辨是**数据**问题还是**结构**问题。O5 只加一个标准负频依赖
软竞争项（自有份额超出目标即降适应度），把 O2 的字面形式修成内点可收敛；c = 0.5 为实现常数
（只定速度，不动点与 c 无关），非判据。

## §6 择优建议（4 条判据全过 = 3 个；结合诊断面给出主推 / 次选 / 排除）

**主推：O5（连续时间 replicator ODE + 软竞争，3 态）**

- 4 条判据全过：rates n_distinct = 9、rel_std = **0.4128**（5 本体中判别力最强）、
  0 触顶、0 地板、抽级 n_distinct = 784、双进程复算逐字一致。
- **真命中扰动目标**：终态到扰动三元组距离 mean 9.99e-07 = 容差量级（900/900 抽在上限内收敛到目标）。
- **唯一携带 `T_frac60` 之外信息**：`T_frac60` 相同的 2 对 model（doubao-seed-2.0-lite vs glm-5.3，
  同为 0.8667 但三元组 52/8/0 vs 52/6/2）在本体下 rate 差 **120.2%**（17.95 vs 72.03）；
  O1 同对差 7.9%，O2/O3 同对仅差 ~1.7%。即：O1/O2/O3 基本是 `T_frac60` 的（重标）函数，
  O5 才能分辨 R/A 结构差异。
- **保留意见（须随正式跑同报）**：`ρ(最小目标分量, n_iter_mean) = −0.3667`，方向与「最小份额是瓶颈」
  一致（doubao-2.0-lite 最小分量 0.0 → rate 17.95；glm-5.3 最小分量 0.0209 → rate 72.03），
  但只解释部分离散度 ⇒ **O5 的跨 model 离散度不可全部归因于「盆地深度」，也不能全部归因于
  最小份额瓶颈**；正式跑时须逐 model 同报 `f_target_min_component` 供 PI 判读。

**次选（并列保留为基线/对照，不建议作唯一本体）：O1 离散 cell 重分配（第一梯队已落地）**

- 4 条判据全过，且与第一梯队落地件 **9/9 逐字一致** ⇒ 正式实验沿 O1 跑可保全既有链连续性。
- 局限（实测）：抽级 n_distinct 仅 **4**（cell 整数粒度，`n_iter ∈ {0,1,2,3}`）、地板率 16.0%
  （1/6 抽样起点即等于目标）、mean n_iter 仅 1.48 步 ⇒ 分辨率粗、动态信息薄。

**备选（交叉校验用，不建议作主本体）：O3 logit 正规形**

- 4 条判据全过、真命中目标、算力最省（31,146 步、约 0.3% 的 O5 成本）、0 伪影。
- 局限：rel_std 仅 **0.0129**，9 model 挤在 [0.3390, 0.3557] 的 ±2.4% 窄带，2 个 model 同值
  0.3454；同 `T_frac60` 配对内只差 1.7% ⇒ 判别力弱于 O5，适合作 O5 结果的交叉校验而非主读数。

**排除：O2（连续时间 replicator ODE 字面）——「判据全过但语义不对题」的典型**

- 4 条判据**字面全过**（本件不擅改判据面，字面结果如实保留），但 `final_target_distance`
  mean = **0.2870** 份额单位、max = 0.4919 ⇒ **扰动目标从未被接近**。
- 根因（可证）：plain replicator `ẋ_i = x_i(f_i − f̄)` 只有**边界**不动点，扰动份额 x0 不可能是吸引子；
  其 `n_iter` 实为「流到最近边界的步数」，大小由 `|2·x0 − 1|` 支配 ⇒ 实测 `ρ(T_frac60, rate) = −0.9916`，
  实质是 `T_frac60` 的单调重标（含 2.56% 触顶，集中在 `x0 ≈ 0.5` 的分岔带，deepseek-v4-pro 单 model
  rate 512.3 拉高均值）。**判「效果好」不能只看 4 条判据。**

**排除：O4（imitation dynamics / 离散 replicator 映射）—— 结构性退化**

- 实测：900 抽 `n_iter ≡ 1`，9 model `rates ≡ 0.01` 全常量、抽级 n_distinct = 1 ⇒ C1/C2 判否。
  这**正是 #26 原构造 `9/9 ≡ 0.1` 的同款病**（判据退化为常量）。
- 根因（可证）：为让 x0 成为内点 NE 而取的 `A(x0) = [[0, x0], [1−x0, 0]]` 给出
  `u_T = (1−x)·x0`、`u_A = x·(1−x0)`，两式共享 `x(1−x)` 因子，在 replicator 映射中**约掉**
  ⇒ 映射退化为常值函数 `x ↦ x0`（一步到点，与起点无关）。
- 附加结构事实：一般 Maynard Smith 离散 replicator 映射在内点 NE 处 `|g'| = 1 + x*(1−x*)D'/2 ≥ 1`
  恒扩张 ⇒ **不存在任何收益标定**能让它收敛到内点目标。模仿动力学在本测量口径下结构上不可用。
- **不重调 payoff**（无解，且重调即属擅调阈值）；如实交付该结构性结论。

**给 PI 的一句话口径**：5 本体中 3 个（O5 / O1 / O3）过全部 4 条判据；按「4 条判据 + 语义对题性 +
信息量」综合，**主推 O5、保留 O1 作基线、O3 作交叉校验；O2 与 O4 排除**（前者目标不可达、
