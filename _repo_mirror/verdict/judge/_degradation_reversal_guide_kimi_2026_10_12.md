## §1 问题定义：长任务降智的四种可观察形态

「降智」在本项目语境中不是隐喻，是**可登记、可归因、可逆化**的操作现象。以本项目 9 月–10 月实证，长任务（长会话 / 长链条 / 多棒接力）中代理能力下降呈四种形态：

| 形态 | 表现 | 本项目实证锚 |
|---|---|---|
| **F1 仪器退化** | 扫描/计数工具返假阴性或假阳性，代理直接采信 | 防护件 §0 G-1：PowerShell 管道作用域失效致「本地 0 件」假阴性（`_upload_guard_mirror_pair_2026_10_08.md`，`d923371cdbce`） |
| **F2 记忆漂移** | 长会话后段对前段数值/裁定转录失真（同形异义、尾位错、串形混） | `6042d09623d` vs `602c4d09623d` 两串字面不一致（委托 v0.3 §4.4）；我本人 10-01 笔记误记批 3 回执尾位 `937/93f`（10-01 执行前回报 §3 更正条） |
| **F3 判据软化** | 「但／然而／仍有希望／不排除」渗入判定；不明面被静默收口 | C5 补充判定件卷首铁律：「0 软化措辞」「凡落不明必挂 γ 根因」（`c5_guard_0_1_recheck_verdict_2026_10_01.md`，`24418fa60ede`） |
| **F4 空门运行** | 防护门因触发条件结构性不可达而恒不启动，代理仍以「有门」自安 | `_ci_detail_decoupling_degradation_baseline_2026_10_09.md` §1.2：`held-out n ≥ 50` 在 S4 面上界 37 ⇒ 空门实证（`688fbbc3aa6b` 族） |

**逆化目标**：不是「让代理更聪明」，而是**让退化不可被隐藏**——任何降智后果在进入证据链前被结构性拦截。

## §2 逆化机制目录（七项 · 均已在册实证）

### M1 判死线先冻（预登记先于实验）

- **机制**：判定阈值、判据字面、kill-line 在实验运行**之前**冻结并 SHA 锚定；冻后 0 改。
- **实证**：C5 判死线预登记（`_v5_v3_deg_fix_prereg_2026_09_29.md`，`98286cc1aec7`）先于 B3 产出约 14 天；FTFB 论文判定层纯函数 + SHA-256 锚（arXiv 稿 §5）。
- **逆化原理**：降智最危险的后果是**事后移动球门**；先冻使代理后段的任何「重解释」都撞在不可改的字面上。

### M2 独立复算，0 复用自报值

- **机制**：判定棒对 worker 读数**逐项独立重算**，0 采信自报；不一致即落「缺报／漂移」。
- **实证**：verdict-keeper 对 C5 补报 23 项复算（`24418fa60ede` §1），查出 `coords_k` 三行缺报与 `family` 缺报——读数可信不等于判据比对可省。
- **逆化原理**：长任务后段的代理**报告欲**上升、**核算欲**下降；独立复算把「我以为我算过」变为「盘上另有复算」。

### M3 仪器自限登记（G-1 体例）

- **机制**：凡仪器（脚本/管道/扫描器）出过假阴性/假阳性，**主动登记废弃值**，全部结论以修正重跑为准；0 静默丢弃。
- **实证**：防护件 §0 G-1（`d923371cdbce`）；核验登记 `3f806e44a13f` §7 B-8 同族。
- **逆化原理**：降智不仅发生在代理，也发生在**代理造的仪器**；登记假阴性使下游不以 0 命中自安。

### M4 防退化门合取绑定（A 形态）

- **机制**：达标判定与防退化门**合取**——`半宽 ≤ 0.1100` ∧ `n_distinct > 3`（15 项逐项自证非退化，二值指示项剔除后再测）；缺一即「不明」，**0 判达标**。
- **实证**：`_ci_degradation_binding_form_a_register_2026_10_09.md` §2（生效即锁）。
- **逆化原理**：单项指标达标可被退化过程「碰巧命中」；合取门使「退化但达标」的假象结构性不成立。

### M5 空门检测（触发条件可达性证明）

- **机制**：每扇防护门须附**触发条件可达性**的盘上依据；结构性不可达的门 = 空门，须修订触发（如 `K-V3S-4-4` 改无条件常设）。
- **实证**：baseline 件 §1.2 四项依据链（上界 37／分散约束 34／PI 已裁移出／读数 28/30 两读并列）。
- **逆化原理**：长任务中代理倾向「引用门」而非「检验门」；可达性证明逼使每扇门被当真。

### M6 盘活态重测 + 停手条款

- **机制**：任何时点表（件数/SHA/HEAD）只对该时点有效；执行前**重测并报差异**；同址异内容、SHA 不符 ⇒ **立即停手回报**，0 强行合并。
- **实证**：委托 v0.2 §2 盘活态条款（10-01 面 110→112→160 件的连续漂移如实登记）；本轮 v0.3 执行前 2,450/2,450 复测 0 漂移、196 碰撞停手登记。
- **逆化原理**：降智的隐蔽通道是**用过期的自我记忆冒充现时事实**；重测条款把「记得」降级为「实测」。

### M7 追加式留痕（0 回改 + 逐 commit revert）

- **机制**：文书 0 回改（新版本另立名）、git 纯追加、回退 = 逐 commit `git revert`；每动作入 SHA 漂移登记件。
- **实证**：委托 v0.3 §6.4；`_freeze_manifest` 族另起名体例（10-01 Q1：`…_q1.json` 0 覆写批 3 manifest）。
- **逆化原理**：可回改的历史会被退化中的代理「顺手美化」；追加链使所有 prior error 永久可见、可被点名。

## §3 长任务 SOP（实验侧代理可直接执行的最小规程）

1. **开工三读**：读最新委托定稿 → 读最近回执 → 读台账/清单；**0 凭记忆接续**（记忆只作索引，不作事实源）。
2. **写前实测**：引用任何数值/SHA/件数前，盘上重测；转录值一律标「转录面」。
3. **会话中段自检**（每约 20 个动作或每个阶段边界）：重读一次任务书的硬约束段；对照当前动作逐条核。
4. **上下文压缩后**：以交接笔记 + 盘上文件重建状态，**笔记标「notes, not proof」**，关键事实重新实测后方可依赖（本会话即按此规程恢复，10-01 笔记之 `93f` 笔误即由重测更正）。
5. **疑似敏感/疑似退化**：停止上报原样指纹与位置（掩码），**0 自行删改后继续**。
6. **出件前**：撞名实测、三门扫描（密钥/key 字段/隐私词 + 任务专项 token）、规则自扫入范围。
7. **收工必留痕**：回执双份落盘（工作区 + 仓内），含失败/跳过/异常逐件列（0 静默丢弃）。
