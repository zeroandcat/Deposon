| 措施 | 收益 | 证据 |

| 前向轨迹双臂共享（mean-field/dirichlet 每任务只算一次） | **1.34×**（S6 全图 49 任务 ×2 臂：6.53s→4.87s） | fastcheck F2 |

## 二、早停：测试后拒绝（与死同行，阴性结果）

反向退火每步自带 0.9 收缩 ⇒ 相对更新天然地板 ~10%/步，收敛式早停阈值
（rel_tol ∈ {1e-6, 1e-7, 1e-8}）**在 50 步内从未触发**（120 任务实测 steps_mean=50.0）。
绝对量准则在 50 步内同样不触发（0.1·0.9^t < 1e-7 需 t>131）。
结论：固定 50 步是该调度下的正确选择，早停不提供收益——deposon_fast 保留早停
钩子但默认参数下零行为改变（F1 逐位等价 max_abs_diff=0.0，排序级等价
rank_mismatch=0，tests 锁定）。

## 三、泄漏事故全记录（加固过程中最有价值的发现）

1. 为提速把 node2vec 嵌入改为**按图缓存**（每图训一次），墙钟 504s→44s——
   但 BOSS 事件从 6 暴涨到 24，node2vec 从 0/20 全胜变 18/20 第一（S6 named 0.471、
   L_bio 0.864、filler 甚至 1.0）。
2. 归因：按图缓存使嵌入训练图**包含留出的金边**（转导式），游走把金边当正样本——
   「胜利」纯泄漏 artifact。链路预测的留一协议里，**归纳（留边训练）是基线有效性的
   前提条件**。
3. 处置：回退逐边归纳训练；以「归纳双预算」取回大部分提速（cheap 默认 + full 参考），
   BOSS 结构复归诚实状态（6 事件）。教训写入 BASELINE_REGISTRY 与 LESSONS：
   **提速不得越过协议纯度；任何缓存设计先问「缓存键是否穿越了留一边界」。**

## 四、加固后的性能预算（预登记口径）

- 单任务场分（双臂共享轨迹）：N=45 约 0.06s、N=100 约 0.16s、N=150 约 0.32s。
- 全图 LOO 评估：E×上述单价；N=150/E=300 图 ≈100s（双臂）。
- GT-1 式 T=20 重复运行：预算 = 20×全图 ≈33min（N=150）——可接受但需后台执行；
  更大图（N>200）预登记要求先跑 scaling_benchmark 再定协议。
- API 链：全部驱动具备指数退避 + 幂等缓存断点续传；单 prompt 超时不再杀批。
