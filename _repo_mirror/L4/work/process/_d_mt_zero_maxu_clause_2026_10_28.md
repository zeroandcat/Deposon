## §1 选边：四读之比较与**选定**（**⛔ 0 只列不断**）

> 📌 **本节之结论先行**：**选定（丁）之具化 ＝「定义域扩展 ＋ 兜底分母（fallback）」，即 `Z-NORM-1` 之形态。**
> **不采（甲）**；**不采（乙）**；**不采（丙）之全局极差化**（代价见 §1-3）；**（丙）之 `|max_u|` 为无效候选**（于 `max_u = 0` 仍为 `0`，**不解决**本问题）。

### §1-1 （甲）**`D = 0`** —— **不采**，三条理由

1. **数值上不真**：`T4-N05` 之 `u*` ＝ `0.0`（`Mixed` 之支付），而错选 `Heads`／`Tails` 之损失 ＝ `|0.0 − (−1.0)|` ＝ `1.0`（**每决策**）。⇒ 「零和博弈 ⇒ 无失真可言」**为伪命题**：零和者乃**均衡收益**为 `0`，非**玩家之损失**为 `0`。此判可核：`exp_harness.py` **L594** 之 `value` 之三项与本棒算术复核（§2 之 PC-1）。
2. **是「约定为零」，不是「定义为零」**：`Z-2.3` 之零由「分子恒 `0`」导出（定义后果）；（甲）之零由「我们规定如此」导出。二者在**可证伪性**上不同类：前者可被 `range = 0` 之格证伪，后者不可。
3. **与在册之戒相冲，且方向性有害**：在册已有明文「**⛔ 0 注入 `0.0`…当作有效值**」（`results\evidence\register\_null_u_aggregation_caliber_draft_2026_10_16.md` **L79**，转引 v1 **L169**；该件 **L12** 列三径候选：**径甲剔格／径乙置零／径丙单独报**，其**径乙之字面与该戒直接冲突**）⇒ （甲）即该径乙之同族。另：置零会把**最难之格**（混合策略均衡，正确率最低之一）记成**零失真**，方向与度量之目的相反（失真面之低估，非高估）。

### §1-2 （乙）**未定义（`UNDEFINED`）＋ 不入统计** —— **不采**，三条理由

1. **把「归一化不可定义」误报为「量不可定义」**：本问题中**原始损失有定义**（`T4-N05` 每决策损失 `0` 或 `1.0`）⇒ 不可定义者**仅分母**。以「量不可定义」之名弃之 ⇒ 弃者多于失者。
2. **与已裁相牴**：PI 裁四 **L40** 逐字「**①`T4-N05` 之格保留（⛔ 0 排除出 cell 集）**」⇒ 以「不入统计」处置之，即以**实施**排除该格 ⇒ 与裁相牴。
3. **聚合面会留洞，而洞本身是新缺口**：`D` 进 `失真倍数`（spec **L68／L88**）⇒ 进跨 `(M,T)` 之 `mean` ＋ 95% bootstrap CI（spec **L91**）⇒ 进 `kill_decision`（spec **L103–L110**）⇒ 若三格（`M1/M2/M3 × T4`）空缺，则 `mean_mult` 与 `theory_U_hit_rate` 之可评性皆受损 ⇒ **不采（乙）者承担一个未裁之聚合口径缺口**。（在册已有同族处置之先例形态可参照：`…\_null_u_aggregation_caliber_draft_2026_10_16.md` **L78/L80** 之「剔格（complete-case）／单独报（split-report）」——⚠ 该件之射程为 `null-U` 之**聚合面**，**非**本面；**⛔ 0 以先例充定义**。）

## §2 四件齐（判据／阈值／测量法／正控）

### §2-1 **判据**（＝ `Z-NORM-1` 之 `Z-1`／`Z-2`／`Z-3`，此处述其**机械执行序**）

1. 取该格之支付值集合 `V_Ω`（`Ω` 依 §0 之 `Z-1`）；取生效之归一化常数 `c`。
2. 算 `u* = max V_Ω`；算 `range = max V_Ω − min V_Ω`。
3. 按 `Z-2` 之序取首中之命中者，得分母 `c_final` 与标记 `norm`。
4. 分子 ＝ `Σ_t |u*(a_t) − u(a_t)|`（spec **L61**）；`D(M,T) = E_π[分子] / c_final`。
5. 依 `Z-3` 随读数登记 `norm`。

### §2-2 **阈值**（**字面冻结 · 事后不调**）

| 项 | 值 | 说明 |
|:--|:--|:--|
| 主切换点 | `c > 0` ⇔ `c ≤ 0` | **字面 `0`**，无模糊带、无 `ε` 参与 |
| 次判点 | `range > 0` ⇔ `range = 0` | **字面 `0`** |
| ⛔ 不得使用 | `ε` 充当分母 | `ε` 之射程 ＝ 失真倍数之分母（spec **L68／L88**）；其值在册未给（`…\_pb_scale_caliber_correction_2026_10_28.md` **L128** 之 `H-6`） |

| 冻结时点 | **测量前** | 本条生效即锁；事后调整 ＝ 违 FTFB |
