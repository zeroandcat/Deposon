## 二、种子值语义推荐与守恒账血统、v1.6 先验臂结构的契合度

**结论：核心判断（守恒不动、否掉参数发生器）正确且强契合；「同构 v1.6」论证方向用反；种子映射自身可复核性设计缺位。**

### 2.1 血统——最强契合点 ✓✓

守恒恒等式是**构造性**的：Λ=1+g_eff+g_aether，T=1/Λ、R=g_eff/Λ、A=g_aether/Λ，**对任意参数值成立**（论文 L10「for arbitrary parameters」、L45「for any path and any parameters」；逐路径能量审计最大偏差 2.220446049250313×10⁻¹⁶＝双精度机器 epsilon）。种子＝(g_eff⁰, g_aether⁰) 逐节点初值，逐点不动恒等式——账本血统零损伤。且两参数状态本身就是二维初值槽，种子槽位天然存在。**「守恒律不动」是本方案与凝子本体契合度最高的一条，应保持为 SPEC 第一原则。**

### 2.2 同构 v1.6——论证方向需修正 ✗（部分）

- 结构不严格：v1.6 先验是**边级**（parent→child 语义边+confidence，零泄漏 prompt 只给标签），注入方式是**事后线性融合**（W_done+λ·prior_scores）；V5 种子是**节点级初值**，作用路径是轨迹演化。注入点不同，「同一条先验线上的自然延伸」过强；诚实表述是「**先验注入点从融合权重移位到节点初值**」。
- 更关键：v1.6 线的注册证据是**负结果**，对象件却引为支持理由——
  - v16 六臂实测（`deposon_v16_llm_prior.json`）：field_guided named_path top-3 = 0.1765，hybrid@λ（0.25/0.5/1/2）全部 = 0.2941，`ge_0.4` 全 false、`pass` 全 false、`any_lambda_pass: false`——**预登记成功判据未达**；
  - 论文 E9.6：凸组合融合在已测 λ 上只稀释（0.484→0.452），λ=2 表观增益为 anti-field 伪影，结论「**若融合增益存在，必须来自非线性机制**」。
- 正确的论证方向：种子=初值注入**恰好是非线性生效路径**（初值→轨迹→终态），与 E9.6 结论兼容；而线性融合路已被判死。所以种子方案的正确辩护词是「避开 v1.6 已判死的线性融合路、继承其零泄漏纪律」，而非「与 v1.6 同构」。

### 2.3 判死协议可复用 ✓（有保留）

审计链（逐路径 T+R+A=1 第三方可重算）不断 ✓。但「初值→演化轨迹→终态」的**动力学层**主张继承两条已判死/降级结论：P1（dynamic≠BR）三档全判死、势博弈降级 approximate（有环图中位残差 0.669）。SPEC 中终态差异类主张必须携带 approximate 标签，不得写成定理级。

### 2.4 否掉「参数发生器」✓✓——正确，但须补一刀

参数来源双层化稀释机器可复核性的判断正确。**但同一标准反身适用于种子映射本身**：若「心哲范畴→初值」映射是即席 LLM 判断（每次运行现判），审计链断在第 0 步——「参数从哪来」照样答不出，与参数发生器同罪。必须**预登记固定种子映射表**（范畴→初值的版本化冻结表），LLM 若参与生成该表须整套继承 `llm_prior.py` 红线：零泄漏 prompt、总预算≤2 次、响应落盘缓存（`results/llm_prior_cache.json` 体例）、无 key 抛 RuntimeError 严禁 mock。

## 四、Bratman 意图主线（三环论证）与 GWT 备选线强弱评估

**结论：主线选择合理，但第二环须降档重写，且存在一处未处理的范畴张力（本评审最强发现）。**

### 4.1 三环逐环

- **第一环（哲学）**：Bratman「意图≠欲望+信念的加权和，是独立承诺状态」为「承诺度」作为独立参数提供存在性辩护——判断正确，确实是分析哲学里工程最友好的一段。BDI（Rao & Georgeff）形式系统是外部生态资产，仓内 0 前驱（BDI/Bratman/Rao & Georgeff 均字面 0 命中）——「工程锚点齐全」是对外部世界的陈述，SPEC 引用时不应写成仓内资产。
- **第二环（机制）——全文档最需修正处**：
  1. **强度拔高**：注册件自评是「**观察性规律（谱发现）+ 探索性（博弈论翻译）**」，且明写「58/338 是合成图上的数值谱分析，离『定理』还差：①发散机理的解析刻画；②到博弈均衡存在性/稳定性的桥」。对象件图式把它写成「无承诺系统动力学上不稳定」——58/338 是 58 块图（17.2%）发散，不是全称命题。须降档为「无耗散时 58/338 合成图谱发散（观察性谱发现，未达定理级）」。
  2. **缺并列的零收益句**：论文 L63「the irreversible dissipation channel has never outperformed its disabled counterpart on any task measured so far…its benefit claim currently has only theoretical motivation—validation requires iterative re-search scenarios」。耗散=承诺装置的**任务级**证据目前为零，唯一机制证据就是谱发现。V5 SPEC 引用第二环时必须两句并列（谱证据有、任务收益无），否则违反三档强度不混装纪律。顺带：这正是 V5 意图节点的实验机会位——迭代重搜场景是论文自留的 future work。
- **第三环（设计）——范畴张力**：图式「低承诺→**意图撤销**→行动子图剪枝」要求意图**可撤销**，但：
  - 仓内注册的「承诺」是**博弈论式不可逆承诺装置**（论文 L18 原句：能量一旦凝入无限维 aether 不能回流、被淘汰路径的预算不能复活；工程上 `dissipate()` 单调累计、无 `recover()`）——Schelling 血统；
  - Bratman 意图是**可重新考虑的规划态**（BDI 有 intention reconsideration 机制）。
  - 两者范畴不同。意图撤销在耗散通道上**无实现位**（A 通道单向）。V5 须三选一并显式登记：
    - (a) 意图=不可逆承诺——偏离 Bratman 可撤销性，哲学锚改引 Schelling 式承诺装置线（诚实，但等于换了理论）；
    - (b) 撤销走 R 通道新增「折返再入射」机制——须预登记判死+守恒账扩展设计（反射能量再入射的记账规则）；
    - (c) 撤销=承诺度参数自身衰减（不占 A 通道；A 只管写入终局）——最贴对象件原意，但「承诺度衰减动力学」是 V5 **新增未审机制**，须明写。

### 4.2 GWT 备选线

「结构同构性最强但缺机制证据叙事」的评估公允。两点补充：其一，v1.5/v1.6 场臂已是字面意义的全局广播机制，GWT 线的仓内机械亲缘比对象件所述更实（见 §三）；其二，该亲缘伴随注册负结果（0.176 vs 0.412，物理场在语义边上输随机）——GWT 线须与 Bratman 线同等携带负结果约束。**两条候选线各背一条已注册负结果（耗散零收益 / 场臂输随机），这是诚实评估的对称要求。**
