## 3. 根因定位（供 v3 正式重排与评审留档）

**缺陷代码**：`build_ftfb_tex.py`（v1 轮构建脚本）`##` 标题处理器三分支——
- `## Abstract` 分支：输出 `\begin{abstract}`；
- `## References` 分支：输出 `\end{abstract}`（**全文唯一闭合输出点**）＋ `\section*{References}`；
- 编号节（`## N. …`）else 分支：仅置 `in_abstract = False`，**不输出闭合**。

**触发条件**：md 中 Abstract 段之后紧跟的是编号节 `## 1. Introduction`（入 else 分支）而非 `## References`，闭合被推迟至全文之末。实测错位位置即证：v1 tex `\end{abstract}` L392、`\section*{References}` L394；v2 tex L409/L411（均隔一空行）。

**渲染后果**：article 类 abstract 环境 = \small＋quotation（左右各缩 \leftmargini=27.3pt），摘要段＋全部正文＋AI 披露段被排入窄栏渲染；References 在环境外——这也是缺陷版末页（References 页）文本块宽度正常的原因。

**v2 未修复的原因**：`build_ftfb_tex_v2.py` 的 F1–F10 均为其他排版层修复（H1 消费、表头 No.、\allowbreak 断点、静默重定义等），`##` 处理器逐字复制 v1，缺陷原样继承。

**修复点**（`build_ftfb_tex_v3.py`，试排管线）：任何非 Abstract 的 `##` 标题，若 `in_abstract` 为真，先输出 `\end{abstract}` 再排节标题；References 分支不再输出闭合（保持环境计数 1/1）。修复后 abstract 恰含摘要段：begin L69 → end L74 → `\section{Introduction}` L76。

**防再犯（两层）**：
1. 生成期 T-1 结构断言（断言失败即停）：环境计数恰 1/1；`\end{abstract}` 必须先于首个编号 `\section`；环境内禁六类结构块（\section/\subsection/\begin{table}/\begin{itemize}/\begin{enumerate}/\item）。
2. 编译后 `visual_gate.py`（G1 tex 结构＋G2 页面几何，见 §4）。

**两轮全零绿未捕获的机理**：Z1–Z4 为日志层（错位环境是合法 LaTeX、不产生错误/Overfull/缺字形/未定义引用四类信号）；S1–S6 为文本层（环境包裹不改变文本内容与元数据）。两层均不检查 tex 环境结构，也不检查页面文本几何——视觉语义层为此前管线的结构性盲区，本轮以 G1/G2 补齐。

**v3 正式重排指引**：以 `build_ftfb_tex_v3.py` 为基，仅换 SRC 为查理 C-1–C-4 修复版链头 md＋替换全 SHA 锁，管线无需再动。
