## 1. DAS 定位素材（逐条可直接入稿）

### 1.1 DAS 系统是什么

**入稿定位句（建议形制，中英可按终稿语言改写）**：

### 1.3 边界如实声明（limitation 素材句，逐条可直接入稿）

1. **DAS 核心生成代码未发布**（GitHub README 明示 "DAS method code: To be released"）——本项目未运行 DAS 生成任何内容；DAS-2M 检索产出不构成"由 DAS 系统生成的综述或结论"。
2. **semantic_text 模板词污染**：DAS-2M 的 semantic_text 含元数据模板短语（抽样 2000 条，32% 含 "backbone model:"），与模板词碰撞的查询词会被严重稀释（Q4 案例：BM25 precision 0.10；重设计后回升至 0.25）。应对纪律：查询词避开 backbone/paradigm/motivation/dataset/evaluation 等模板词，改用自然语言组合词。
3. **publication_date 字段不可信**：该字段为 LLM 提取产物，2026 分卷中仅 55.9% 标注 2026 年，且存在 1828/2029 等荒谬值——本项目日期一律以 arxiv_id 前缀（YYMM）为准。
4. **覆盖窗口**：分卷只到 2026-07（months=7）；2026-08 以后的文献不在湖内。
5. **无独立第三方评估**：DAS-2M 检索端的评测只出现在 DAS 论文自家 benchmark（DAS-Bench）内；本项目实测 precision 表（§1.2）是目前唯一针对本项目查询域的独立度量。
6. **元数据版本陈旧风险**：semantic_text 为静态快照的 LLM 提取产物，可能滞后于 arXiv 现行版本（本轮核验捕获 1/55 例：2607.08665）；故引用一律以 live arXiv abs 页一手核验为准。
7. **DAS 论文正文细节未逐页核验**：本素材包对 DAS 的全部断言依据为 arXiv abs 页（摘要全文）＋GitHub README＋项目页＋HF 数据集页＋机器之心报道五源交叉；论文正文内部细节（judge 配置、backbone 敏感性实验数值等）未读原文，**终稿如需引用这些内部细节须先取 PDF 一手核验**。
