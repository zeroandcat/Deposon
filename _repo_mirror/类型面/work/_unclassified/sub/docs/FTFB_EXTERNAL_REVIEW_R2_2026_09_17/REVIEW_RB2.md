## K. Weaknesses（≥3，逐条锚定）

1. **Channel II 的 translatability 判据内部不一致，不变性主张受其牵连**（L92、L100、L102、L109、L267）。错在哪：L100 的定义句先给出广义清单——"a derivation that someone can rerun, **a limiting case that someone can verify**, a model whose behavior can be compared against targets"——随后将 checkable 单义化为"re-derivable by a competent third party from the reconstruction alone"；两者不重合（"verify" 的对象不必从 reconstruction 重推导）。在何处：L100 的自我冲突；连锁处：L92 声称两造共享"exhibited in a checkable form"，L102 断言"Brown's stock cases are precisely scenarios whose yields survive translation"，L109 据此记 D 为"unresolved by design; the claim is worded to be invariant under either resolution"。但在 Brown 自己的立场上（L90 转述无误：yield "not reducible to derivation"），stock cases 的 warrant 恰不可由重构独立重推导——若采狭义，Brown 侧案例会被 L102 的 threshold 条款逐出 channel，不变性失效；若采广义，L100 的单义化句必须重写。怎么改：在 L100 区分 content-translatability（产出可被第三方独立检验）与 warrant-translatability（保证可从重构推导），声明 channel 判据取哪一层，并同步校准 §8.3 对 machine hypotheses 的"recomputable by a third party"（L267）属哪一层。**必须修复。**
2. **三检查对四通道的判别力不足，且论文未接通自己的 F-C1**（L25 vs L285–288、L298）。错在哪：T 与 R 在四个 channel 行全部 Pass，差异全集中在 D 列，而 D 按设计（L36）从不返回 verdict；论文自认 T/R 的通过部分是 selection 的产物（L298），却未与 F-C1（"if the checks return the same profile for types that are supposed to differ — the typology is weakened"，L25）正面接通——按 F-C1 的字面标准，当前主表的趋同档案是一个真实的压力点。在何处：L25、L285–288、L292、L298。怎么改：或给出一个 channel 层面被三检查否决的 worked negative case（例如一个流传广但 dated priority 崩塌的"科幻启发科学"传说），以展示装置的判别力；或在 §9.1/§9.2 增补一段，说明"输入类型 + D 的四种理由"足以承载 pairwise separability、T/R 趋同不触发 F-C1 的理由。
3. **§6.1 的 genre 侧判据缺乏引文级支撑，mapping 的忠实性不可复核**（L176、L184–190、L354）。错在哪：四项 genre 侧判据均为无引号转述（"the world's books must run no deficit"、"checkable by observers inside the world" 归 [R37]；"the story writes no supernatural checks"、"its world stays continuous with known science" 归 [R36]），而论文同时以"we do not manufacture a sharper one: the mapping below inherits exactly these four demands and nothing else"（L176）把忠实性立为 mapping 的合法性前提。以我对 hard SF 定义文献（SFE 词条的 definitional 讨论、*The Hard SF Renaissance* 导言）的了解，这些措辞并非可即时辨认的原文短语，必须以引文坐实；且 [R37] 为在线版未注访问日期（L354），转述对象在时间上不稳定。怎么改：给出 [R36] 导言与 [R37] 词条的原文引文及定位（页码/词条小节），补 [R37] 访问日期；若转述与原文有出入，相应修订 M1/M5 的 genre 侧单元格。
4. **Channel I 两处史学表述超出其锚所载**（L60–62）。错在哪：(a) "for a long period these structures referred to nothing physical"（L62）——pre-1905 记录并非如此：Riemann 1854 habilitation 本身已把空间度量的经验问题交给物理学，Helmholtz（1870《论几何公理的起源与意义》）与 Clifford 公开赋予非欧几何以可能的物理所指，1900 年前后已有对空间曲率的经验界讨论；该句对原始构造（Bolyai 1832、Lobachevsky 1829–30）成立，对"long period"不成立（Lobachevsky 本人晚年亦以天文观测检验几何）。(b) "the physics arrived later and found the language ready"（L62）——GR 的语言并非现成可用：Einstein–Grossmann 的转译劳动、Einstein 1913–1915 对一般协变性的 retreat、Levi-Civita 平行移动（1917）晚于 GR 的事实，均说明"ready"是修辞性简化。怎么改：将 (a) 限定为"原始构造期无物理所指；1870 年代起存在零散的物理猜测，但未产生被采纳的物理理论"，将 (b) 弱化为"found the language available"一类表述——这也与论文自己的标准（L60 "whether the system was built without the later physical use in view is a historical question with a datable answer"）相称。

6. **"three-line search" 未被规定**（L52、L204、L298）。错在哪：全部 uniqueness/novelty 声明挂在这个检索上（"made strictly relative to our three-line search completed on 2026-09-16"，L52），但检索式、数据库、筛选规则均未披露，第三方无法重跑该门槛。怎么改：脚注披露三行检索式与数据库，或明确声明该门槛全部让渡给已排期的 second-round novelty check（L52、L204）并删去正文中的相对化表述。
