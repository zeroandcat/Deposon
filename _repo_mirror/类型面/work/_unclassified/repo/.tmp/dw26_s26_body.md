**第三则 · 「同内容异名」不足以证改名**（本棒实测）：`README_source_2026_10_30.md` 与 `README.md` 之 bytes／SHA-12 **逐位相同**（9,039／`07243344c6ba`），然 mtime 相隔 **19 分 47 秒**，且一手记录中 `Move-Item`／`Rename-Item` 命中 **0**（§26-4 ④ 第三段）。**其判读**：**内容同源**可证，**改名之归属不可证**；**以内容同源推断改名之归属** ＝ **由果推因之伪证**——**⛔0 充归属之证**。**此与本册卷首 §0 之纪律同族**（**⛔0 以推测补**）。

**第四则 · 「0 命中」之三型须分（本棒实测）**：本棒于同一命题上得**三种 0**，其义互异——①**阴断之 0**（不存在之串 0 命中 ＝ **有效**，如台账 `bg_deadbee0` 0 行、`§26` 节点 0 命中）②**已存在之物之 0**（如本棒首验「不互抄」0 命中 —— 实为**探针字符形之误**，**册面有 20 处**）③**不可得之 0**（如改写者 0 命中 —— **其义为「不可得·其因」**）。**其判读**：**三者不可混为一谈**；**§10③ 之判准一（「写全称命题＋并列同域正控」）之所以必须，正因第二型会伪装成第一型**——**若不并列正控，则「探针之误」将被读作「册面之缺」**，**且无从自陈**。**本棒即以其一误为实证**（§26-7 第 8 项·**已自陈·⛔0 掩饰**）。
