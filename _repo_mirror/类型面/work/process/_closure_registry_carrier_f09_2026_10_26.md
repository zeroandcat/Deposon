## §2 append-only 之形

### §2-1 只追加之律

1. **本件只追加、⛔ 0 回改**——既有行**一字不动**（不删·不改·不重排·不改行号·不改其既有字节）。
2. **每一次登记另起一行**，并**附时点**（GMT+8·到秒）；**一行 ＝ 一次登记**，⛔ **0** 一行记二事。
3. **登记之先决**：须先具「登记时点」＋「面名（含读之归属·甲／乙）」；**闭之裁未得 ⇒ ⛔ 0 登记**（登记栏**留空**即为「未登记」之合法态）。
4. **⛔ 0 代 PI 裁·⛔ 0 代销记**（销记权归 `verdict-keeper`／PI）——登记之**落笔人**可与**裁者**不同，但**裁之内容须逐字照录 PI 之裁**（⛔ **0** 释义·⛔ **0** 转述充逐字）。
5. **勘误以追加行落账**（⛔ **0** 回改历史行）——追加行须自陈「**勘误·更正第 n 行**」并附**原行指纹**（`件名·行号·SHA-12`）。
