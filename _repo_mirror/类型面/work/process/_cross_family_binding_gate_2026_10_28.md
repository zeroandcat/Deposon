## §0-3 判据：系结性之唯一定义

> 📌 **定义（拟案·惟一定义）**：
> 件 X 对族 F 之撤回门 `G_F` **具系结性** ⇔ **X 之变更改变 `G_F` 所读之任一读数面 `R_F`**（即改变其读数面所依之内容／次序／提示面，或改变其派生之读数）。
> **非** 以「X 与 F 是否同族」为准 —— **族属不作判据**（PI 裁一之原话，见 `v577` **L64**／`v574` **L13**：「判据＝「系结性」非「族属」」）。

**为何「族属」不可作判据（一条即足）**：族属之在册定义是**出处链／沿革**，非依赖关系 —— `v265`（**4,607／`cb94dba3acd3`／LF 83**）**L27** 逐字：「**定族规则 ＝ 以该件在 deposon 树中之「历史归属」定其族**——即依其**出处链／沿革**（该件最初为哪一立项、哪一棒、哪一族所立）定族属，**⛔0 依其当前所在目录或现名定族**」。⇒ 族属回答「它属于谁」，系结性回答「谁的门读它」；**二者正交**（§3-2 之口径固化）。

**面之三型**（与在册 `role` 字段一一对应；本面据此建判据表）：

| 型 | 判别 | 机械标记（在册已有） | 漂移之效果 |
|:--|:--|:--|:--|
| **门成员面**（系结） | 该件是族 F 锚表之一 | spec 锚表行（例：P_B spec **L24–L30**） | 触发 `G_F`（除 §0-4 之免触发事由） |
| **系结伴随面**（`value_determining`） | 该面之读数**决定**该族判定值 | 锚件中 `"role": "value_determining"`（锚件 **L42**） | 触发 `G_F` |

## §0-4 传导条件：何者应传导 · 何者不传导

**应传导（触发 `G_F`）之五情形**：

| # | 情形 | 机械判据 |
|:-:|:--|:--|
| **C-1** | X 之变更使 `R_F` 中任一读数之值改变 | 重跑该族复现协议之读数步，读数**超出该族之既有容差**（P_B 之容差 ＝ ±5%，见 spec **L131**） |
| **C-2** | X 之变更使 `R_F` 所比对之基准（冻结 run／基线／判死族）之内容或次序改变 | 逐位／逐格比对出差异（冻结 run 五成员之逐位见锚件 **L173–L248**） |
| **C-3** | X 为 `R_F` 之执行路径上之件（直接或经 import），且其指纹变动 | 静态依赖面枚举命中 ＋ 指纹差 ≠ 0 |
| **C-4** | X 之产出物为 `R_F` 所读之中间物，且该中间物之**内容／次序／提示面**变 | 重跑比对出差异 |
| **C-5** | X 之变更使 `R_F` 之**定义**改变（该族复现协议自身被改） | ⚠ **本项须走 §0-6 之冲突解序** —— 在册先例为「非系结面·不单独触发」（锚件 **L106**） |

**不传导（不触发 `G_F`）之五情形**：

| # | 情形 | 机械判据 |
|:-:|:--|:--|
| **N-1** | X 与 `R_F` **无任何依赖**（既不为其执行路径之件，亦不产其读数面所依之中间物） | 静态依赖枚举 ＝ 负 ＋ 重跑比对 ＝ 逐位相同 |
| **N-2** | X 之变更**仅及** F 族之**非系结伴随面** | 锚件 `role` 字段判别（**L106** 之先例） |
| **N-3** | X 之变更**已获授权**且满足**免触发三要件**（§0-5 之阈值 T-3） | 三要件逐件对位齐（`v16` **L28** 之形） |
| **N-4** | X 属**他族**且其族**自设撤回门** —— 此**不构成**不传导之充分理由，仅为**不得据族属径行豁免**之戒 | ⛔0 以族属代系结性（`v265` **L27** 之口径） |
| **N-5** | X 之影响**止于**该族之**构造域之外** | 构造面判定，**外推边界 ＝ 构造域**（在册先例：`v171` **L22** 逐字「**射程仅及甲-C5 构造域**（⛔0 外推为原构造面之命题存活）」） |

## §0-5 默认规则：**默认传导**（选边 · 非「只列可能」）

> 📌 **本面之选边（拟案）**：**无明示时，默认传导。** 即：**⛔0 允许以「未列入清单」「属他族」「无明文」为由径行豁免**；每一件在受问时**须先作一次系结性判定**（§0-8 之程序 B），判定结果为「不系结」者方不传导。

**选「传导」之四条理由（逐条附据）**：

1. **系结性是事实关系，非裁量关系** —— 门之所以存在，是为守住「该族 V0 之读数可复现」（P_B spec **L126–L132** 之复现协议、**L32** 之撤回条款）。故**举证责任在「证明不系结」**，不在「证明系结」：若默认不传导，则每一未列入之件皆自动豁免，而本缺口之真形恰是**「族外充空白」**（`v571` **L51** 逐字：「此形为「**族外充空白**」」）。
2. **在册已有「不得以未列入／以自限充空白」之戒** —— `v570` **L51–L52** 自纠一之机理逐字：「本部**把「某件之自限」读作「在册之空白」**……新形态：**自限充空白**」；`v571` **L25** 之「误之机理」逐字：「**查得不全即下断，而所断之词为「无」**」。⇒ 默认若为不传导，正复制该形态。
3. **代价不对称**（见下表）—— 两条径之代价量级不同，不可互代。
4. **与在册之非系结面机制相容** —— 非系结面之免触发**并非**靠「不在清单」取得，而靠**逐面判别**取得（锚件 **L106**：spec 本尊之变动为「伴随面·非系结面」⇒ 不单独触发）⇒ 默认传导**不与之相牴**：非系结之认定仍须逐件作出。

**代价不对称（PI 裁择时须知）**：

| 径 | 多花什么 | 少花什么 | 失误之代价 |
|:--|:--|:--|:--|
| **默认传导** | 每一件受问件须作一次系结性判定（读数比对 ＋ 依赖面枚举）；误传导时须走一次**多余之撤回／重锚**（可逆、局部，其证据面仍在） | 省去「逐族重新论证」之成本 | 多余之撤回与重跑（**可逆**） |

## §0-6 冲突解序（两族皆声明 · 双族件 · 真冲突）

**情形一 · 双族件（非冲突 · 并联）**：一件同属 F1、F2 之读数面（两族各持撤回条款）⇒ 其变更**同时**触发两门；两门**各自独立判定**；其撤回范围**取并集**，**不相消**。

⇒ **本面据此确立通则**：同件两族 ⇒ **两门并联 · 撤回取并集 · ⛔0 以一门之不触发消解另一门之触发**（此即 `v31` **L60**／**L152** 逐字「**两族锚面本件分列登记，⛔ 0 互相代充**」之同族戒）。

# §2 正面回答三问

## §2-1 问一：现存之「面专属」裁例 —— 归「不传导之例」抑「系结性不足之例」？

**答（本部之断 · 拟案）**：**两者皆非。**「面专属」是**射程**之限，**不是事由**；故须**二维归类**——**事由（grounds）× 射程（scope）**。在册之面专属不触发裁例，其**事由皆非「系结性不足」**，而是**第二类「授权型免触发」**（G-2）或**第三类「判据面／构造面消解」**（G-3）。

## §2-2 问二：「系结性」如何机械判定？

**答**：**§0-8 之程序 B（三步）＋ 判据表 B-1…B-8 ＋ 测量法 M-1…M-4 ＋ 正控 PC-1…PC-5**。要点复述：

1. **唯一判据句**：「X 之变更**改变** `G_F` 所读之任一读数面 `R_F`」⇒ **系结**（§0-3）。此句之两侧皆可机检：左＝「是否改变」（M-2 之逐位／逐格比对）；右＝「所读」（该族复现协议之逐读数步，`R_F` 之闭列）。
2. **判据表**给出**八种情形**之唯一判读（触发／不触发／授权免触发／构造消解／并联／不明），使他人可照之作**同一判断**（AC-2）。
3. **三步程序**（定面 → 定依赖 → 判读）保证**不得跳步**；其中「定面」须**先闭列 `R_F`**，否则「改变读数面」无从判起。
4. **五正控**保证判定程序**对已知例不出错**；五控皆须在真机上给出可核读数（PC-1…PC-5 之逐条命题见 §0-8-4）。
5. **阴性断言之射程纪律**：M-3 之「未检出依赖」须同报 `0/N_obs`、`N_full`、缺失清单、覆盖范围、判定口径（沿在册之第 17 型之戒），**⛔0** 以「0 命中」充「确无」。

## §2-3 问三：两族皆声明撤回条款，而某件同属两族之读取面，冲突如何解？

**答（三层）**：

1. **非真冲突 —— 并联**：两门**各自独立判定**、**同时触发**；撤回范围**取并集**；**⛔0 以一门之不触发消解另一门之触发**（`v31` **L60／L152** 之戒）。**在册先例已书此形状**：KT-A1 **L457**「本 SPEC 与 P-A V0 spec 同时」｜KT-B1 **L601**「本 SPEC 与 P-B V0 spec 同时」｜KT-C1 **L510**「本 SPEC 与 P-C V0 spec 同时」｜KT-D0 **L334**「P-D V0.1 同时撤回」⇒ **现成实例**：`tools/exp_harness.py` 同属 P_A（**L52**）与 KT-A1（**L261**）之读数面 ⇒ 其变更触发两门（P_A **L54／L135**；KT-A1 **L263** 等），两门并联。
2. **真冲突（同族同件 · 两规则相反）** —— 解序六条（§0-6）：明示 > 默认｜授权型免触发 > 触发（须三要件齐）｜后裁 > 前裁（后裁自纠前裁之误者以其为准）｜面专属 ≠ 通则（窄者不废宽者，且窄者不得外推）｜⛔0 互相代充｜解序尽用仍相牴 ⇒ 判「不明」并登记，交 PI／`verdict-keeper`。
3. **本面之自限**：本面**只解「何时触发」之规则冲突**，**不判「撤回是否发生」**——后者属 PI／`verdict-keeper`（锚件 **L314**）。
