### 6-2 新增 §7-4「补传面：远端独有件（GLM 侧等）之规则」

**背景（本部实测）**：远端 `_repo_mirror/agent_shared_2026_10_23/` 实存 **324 项**，含大量 `_alan__*` 与 GLM 侧件（例「`GLM_增补实验设计提案_2026-09-17.md`」）；本地 GLM 侧件 **60 件**。

| 规则 | 要 |
|:--|:--|
| **P1 识别** | 逐面枚举远端全部件，与本地（repo＋sub）按**相对路径＋SHA-12** 双向比对，得「远端独有」清单（云端路径／指纹／字节） |
| **P2 不臆断归属** | 远端独有件 **⛔ 不默认可传**——逐件判是否属禁传面；禁传者**不入镜像区、不入对外清单**，但**入内部册**（标「远端独有·禁传」） |
| **P3 GLM 侧特则** | 名含 `glm`／`_alan__` 者**单列一节**，逐件五栏：路径／指纹／字节／**主题一句**／**是否属「理论值相关」** |
| **P4 不回拉** | ⛔ 0 擅自回拉本地；回拉与否**候 PI** |
| **P5 入册** | 可传者 → 入**成果清单**（六要件）＋**线索册**；禁传者 → 只入**线索册**「远端独有·禁传」节 |
| **P6 反查回报** | 报「远端独有 N 件：可传 a／禁传 b」＋可传者完整清单 |

⚠ **限**：「324 项」系**一个面**之实测，⛔ 0 充「远端全部」；`doc`／`readout`／`source`／`verdict` 四面之独有件数**未测**。
