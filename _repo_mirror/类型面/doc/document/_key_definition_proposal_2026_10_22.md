### §6-3 候选丙（**由 payoff 表实算之均衡响应集（全体纯策略均衡之行动并集）**）

### §6-4 `T4-B` 之荐案

### §8-3 候选丙（**受限信息下之期望最优：信念加总之 argmax**）

| 属性 | 内容 |
| :-- | :-- |
| **白话定义** | **决策者只知道眼前这点信息，那么「最优」就该按「各种可能情形下的平均收益」来算：取平均收益最高的那个动作当标准答案。** |
| **逐字定义式** | `K_t^B := { a ∈ options : E_{s ∼ π(·|obs_t)}[ v(s,a) ] = max_{b ∈ options} E_{s ∼ π(·|obs_t)}[ v(s,b) ] }`，其中 `s` ＝ **隐藏状态**，`π(·|obs_t)` ＝ 决策者所持之信念 |
