**模式二 ·「枚举与计数脱钩」**（实证：B-3 四处三说 6/6/7/实列 8、B-4 分项 299 vs 合计 297、B-7 B 线 9/21 vs 逐行 10、D4 Q-3 镜像双计 ×2、D5 J_unknown 哨兵 45.5% 混入 n_distinct）
——计数是**转录或心算产物**而非枚举清单长度的机械产物；口径（分母域、哨兵、时点）在出数之后才补。

**模式三 ·「同概念多口径并存、无对账责任面」**（实证：B-5 830=830 但 390/440 vs 399/431【**总量一致分区互换型——肉眼最难察觉**】、REPO 件数四读 1,699/1,700/1,704/1,706 vs 实测 1,712、`.tmp` 560 vs 441、D16 终判分布跨件漂移）
——各件各自时点各自口径都「如实」，但没有一件承担**调和责任**，漂移静默累积。

**模式四 ·「权威引用被转述置换」**（实证：D7 gate_one 分布互换 + 引不存在的 §2-4、①毕宣告节位臆写、B-8 F4 锚值错挂、D14 委托件 R-2 措辞失真——**同族第 4+ 例**）
——转述他件内容时**未回读原件**；SHA 锚未与所指件在册值比对。

**模式五 ·「声明强度超出承载面」**（实证：D6「全部为本棒实测」含 ±22h 错值、D5「6/6 同值」系同一装载赋值恒等式、B-5「830/830 三方一致（字节级）」、D11「全仓 0 既有用法」49 分钟即过期、历史「7 种读法均不复现」）
——强声明只在其自身测量面内成立，而**测量面本身已实证失效过**（GBK 解码、`$sub` 覆写、`-notin` 抛错、all-pooled 口径）；过度声明 + 仪器未自审 = 把错误锁进证据链的**放大器**。

### §3.2 八条逆化规程（实验侧落盘前自查清单）

| # | 规程 | 机检判准 | 对应模式 |
|---|---|---|---|
| **R-1** | **落盘后回读三件套**：SHA-12 + bytes + mtime 须**同批单命令实测并回读比对**后才写入登记表；⛔ 占位符 `{}`/「—」带过；⛔ 落盘前预写指纹 | 登记表内 0 处 `{}`/「—」；指纹值 = 复算值 | 一 |
| **R-2** | **计数机械生成**：凡「N 项/件/处」必须 `len(枚举清单)` 生成；分项之和必须等于合计；⛔ 手填总数 | `sum(分项) == 合计` 断言；枚举数 == 声明数 | 二 |
| **R-3** | **口径先行**：出数前先写口径式（分母域 + 哨兵剔除规则 + 快照时点戳）；同概念两口径并存必须**双记并标注差异** | 件内含口径定义行 + 时点戳；两口径处含「并记」标记 | 二/三 |
| **R-4** | **跨件计数带来源戳**：引用他件计数/分布时必须带（来源件名 + SHA-12 + 时点 + 差异标注）；**总量一致而分区不同**者视为最高危（须逐分区核对） | 每处跨件计数含四元组；分区和逐项核对 | 三 |
| **R-5** | **转述必回读**：转述他件内容须打开原件对行号；SHA 锚必须与所指件**在册值比对**；⛔ 凭记忆/上下文转写 | 转述段含「L 行号」；锚值 == 在册值 | 四 |
| **R-6** | **强声明前仪器自证**：「一致 ✓ / 同值 / 三方一致」必须注明**两个独立实体 + 双侧独立实测时点**；凡「同值」先排除**同源赋值（identity）**可能；强声明前对已知值复算一遍 | ✓ 旁含两实体指纹 + 时点；一致性证据非恒等式 | 五 |
| **R-7** | **时点敏感断言带失效条件**：「全仓 0 命中 / 0 既有用法」类一律带（时点戳 + 失效条件「此后新增件不在此断言内」） | time-indexed 断言含时点戳 | 五 |
| **R-8** | **迁移评估纳入相对引用扫描**：Move-Item / 改名 / 归档前，除 CodeRefs 外还须扫 **md/py 内相对路径引用面**；迁移后对高引用件出「路径勘误」并回写引用面（当前仅出映射表不回改 = 系统性断链敞口：D9 三 runner 输入悬空实证） | 迁移前后相对引用扫描 diff = 0 断链 | 三/四 |

**附（沿既有纪律，0 新设）**：「succeeded ≠ 跑完」——exit 0 ≠ 验证完成，须附实测命令 + 读数；「修复 ≠ 翻案，标注 ≠ 篡改」；测量仪器自身误差**同案登记**（本函 §5.1 即实例）。
