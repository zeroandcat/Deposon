### §0.2 落地机制（沿 E-27 §13 拍板 + 各 verdict §1 字面）

每个实验结论（尤其实验 FAIL / 负面结论）必须**追问根因**，沿三分类登记：

| 类别 | 字面 | 适用 |
|---|---|---|
| **α**（命题层面被证伪 / 真证伪） | 命题方向与数据方向一致 + 构造非退化 + 素材覆盖 + 度量有分辨力 | 真证伪命中（K-N11-3 真证伪族） |
| **β**（构造 / 工具层面失灵） | 度量恒零 / 构造退化 / 计划 vs 样本量结构 gap / 调用侧 metadata 不可靠等 | 假证伪疑点族 |
| **γ**（不明 / 待补证） | 数据不足以分离 α 与 β | 待复核 / 待补测 |

**复合定性**允许并强制：判定表每行附根因列；「部分 α + 部分 β」是合法判定结果（沿 `_v4_pi_cot_v2_verdict_v2.md` `5D79e67a4e9d` §1.2 字面复核成立）——这是判死的标准动作，不是软化。
