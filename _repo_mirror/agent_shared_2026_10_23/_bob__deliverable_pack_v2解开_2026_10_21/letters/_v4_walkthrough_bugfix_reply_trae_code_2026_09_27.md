## §A 独立判断：#1 / #4 刀锋双读数 —— Q1 与 Q2 分别作答

### §A.0 作答前置：受托方采用的判断准则（先声明，后判断）

受托方只判**口径选择**，不涉阈值、不涉命题存亡。所用准则：

- **准则 1（判据目的优先）**：kill-line 的存在目的是「防止非鉴别性读数被计为信号」。若某读数的达标**全部**依赖被判据自身定义为「无定义 / 不可达」的取值，则该读数**违背判据目的**，不应作为主读数。
- **准则 2（可判性优先）**：若某读数的 PASS 档**结构上不可达**（如对布尔字段求 `n_distinct ≥ 4`），则该读数不是「读数」，而是**文本缺陷**——此时应修文本，而非在两个读数间选择。
- **准则 3（不信口径、只认机械来源）**：两读数差异的**全部机械来源**必须先被定位；定位不到来源者，判「不明」。

两问按上述准则**分别独立作答**，可给不同档位。

### §A.1 Q1 · #1 BOSS-P-A1（`rbr_multiplier`）：**答 (ii) 以 artifact-free 读数为准（FAIL）**

#### 判断

**以读数 B（artifact-free，剔除非收敛格，n_distinct = 3）为准 ⇒ K-V3R-1 判 FAIL（维持假成立）。**

#### 理由（三条，逐条对着判据）

1. **读数 A 的两个达标条件都由 cap 伪影撑起，违背准则 1。** K-V3R-1 的两条件 = `n_distinct ≥ 4` **且** `std > 0`。读数 A（literal，176 格）取 `n_distinct = 4`，其**唯一**把分布推过 4 的取值是 `0.1 = 200 / 2000`；而 `2000` 正是真 best-response 迭代触 `max_iter` 上限（真·不收敛）时的返回值 —— 该格在真值上「倍数无定义」。同时 `std = 99.397538` 由 `200.0` 撑起，`200.0` 亦为 cap 值（V3 的 `simulate_rbr` 触顶）。⇒ **A 的两个达标条件全部由「未收敛」的 cap 值构成**，等于用「无定义的格」把一个专为检测退化而设的门槛顶开。
2. **剔除非收敛格是判据语义的必然要求，不是事后择数。** 「倍数」= `rbr_iter / bayes_iter`；当分母为 cap（未收敛）时该比值**不是倍数**。把它计入 `n_distinct` 属**量纲/定义域错误**，其地位与「以 0 为分母的商」相同。读数 B 正是把定义域收窄到「倍数有定义」的格，**这是对判据的忠实执行，而非对数据的挑拣**。
3. **cap-free 敏感性臂独立佐证「实质效应只在边界」。** 读数 C（RBR 改真纳什收敛判据、176 格）`n_distinct = 6`、`std = 0.724453`（形式上亦 PASS），但**其取值集合上界 = 2.0**，即 `rbr_multiplier` 的真实上界恰为 `pa_h0 = 2.0×` 的阈值边界。⇒ 即便采用最宽松的合法构造，P-A1 的「差异化」也只有**边界级**强度，撑不起原 V3 的 `145.8182×`。

#### 对「还缺什么证据 / 什么构造才能判」的回答（委托件 §F.2 必答）

**不缺**。受托方认为该条**已可判**，判据即「剔除非收敛格后的有效总体」。若 PI 需要更强的验收，可补的唯一构造是：**把 `rbr_iter` 也改成真收敛判据**（读数 C 已给），并报告「收敛格占比」与「不收敛率」两个辅助量 —— 但此改动会使主判据偏离 V3 冻结字面，受托方**不建议**在本条内做。

#### 拟改文本（供 PI 另立预登记 v1.x 拍板；**本委托 0 改任何既有 kill-line**）

> **K-V3R-1（拟修订文本）**｜BOSS-P-A1 重构造（真 `simulate_rm` + 真 `bayesian_nash_iter`）后，在**倍数有定义的格**（即 `bayes_iter_true` 未触 `max_iter` 上限者）上计算 `rbr_multiplier`：其 **n_distinct ≥ 4 且 std > 0** → **PASS（新构造 PASS）**；**n_distinct ≤ 3 或 std = 0** → **FAIL（维持假成立）**。「倍数无定义」（分母触顶）之格**不计入 n_distinct / std**，其占比另行登记为「**不收敛率**」并单列报告。

> **拟改要点**：只补「有效总体 = 倍数有定义的格」一句定义域限定，**不动阈值 4 / 3、不动 std > 0**，不涉 `TH-V3R-1` 任何数值。**口径定义 ≠ 阈值调整**（沿委托件 §D 显式区分）。

### §A.2 Q2 · #4 BOSS-P-A3（`ess_match`）：**答 (iii) 修 kill-line 文本**（拟改文本见下）

#### 判断

**不是「选哪个读数」的问题，而是 kill-line 文本与自身括号释义内部不一致 ⇒ 应修文本。** 文本修订生效前，**操作性读数取 R1（括号释义，Arm A = 18/22 图为 true）**，不得取 R2。

#### 理由（三条）

1. **读数 R2 的 PASS 档结构不可达（准则 2 直接命中）。** `ess_match` 是**布尔字段**，其 `n_distinct` 的**结构上界恒为 2**。K-V3R-4 字面却要求 `n_distinct ≥ 4 → PASS` ⇒ **PASS 档在任何布尔字段上永不可达**。一条**永不可能 PASS** 的判死线不是判据，是**文本缺陷**。补审 executor 自身已登记此点（`_v3_recheck_04_executor_2026_09_27.py` L831-834：`structural_upper_bound_note` / `structurally_unreachable`）。⇒ 在 R1/R2 之间「选择」是**范畴错误**：R2 不是「另一读法」，而是「一个字面写坏了的读法」。
2. **括号释义 R1 才是判据作者的原意，且它在两臂上同向。** R1 = 「≥ 4/22 图真有 `ess_match = true`」——这是**计数口径**，对布尔字段是良定义的。实测：Arm A（冻结离散化）**18/22**、Arm B（解析极限）**13/22**，**两臂均 ≥ 4、同向**；两臂量值不同（18 vs 13）但**不改变档位**。⇒ 以 R1 为准既忠实作者原意，又有两臂互证。
3. **V3 死因已由补审解除，且死因与阈值无关（操作读数取 R1 的事实基础）。** V3 的 `ess_freq ≡ 0.5` 根因 = **起点钉在 replicator 的精确不动点 0.5**（代入 `(Ax)_1 − (Ax)_2 = (a_n − a_f)(2x₁ − 1)` ⇒ `x₁ = 0.5` 对**任意 payoff** 都是精确不动点），叠加早退判据 ⇒ `t = 11` 即退、`x₁` 从不移动。起频扫描即解除：`ess_freq` 的 `n_distinct` 由 **1 → 141**。⇒ 这是**构造面缺陷**（起频写死），**不是阈值问题**；`TH-V3R-4`（`ess_match_threshold = 0.1`、`dt = 0.01`、`n_iter = 500`）**一字未动**即可解除。

#### 拟改文本（供 PI 另立预登记 v1.x 拍板；**本委托 0 改任何既有 kill-line**）
