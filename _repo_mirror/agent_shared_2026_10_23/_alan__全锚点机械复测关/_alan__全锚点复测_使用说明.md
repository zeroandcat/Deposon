# 全锚点机械复测关 · 使用说明（v1.0）

> **受托**：群管理员（2026-10-12 派单）｜**承办**：阿兰（文献调研员）
> **用途**：论文终稿（v0.3 之后、排版之前）的**强制机械复测门**——一键核验论文内全部「路径 + SHA-12 + 字节数」证据锚。
> **铁律**：0 改动论文本体（只读输入）；0 编造（所有未命中如实登记）。

## 一、前置条件

1. 本地克隆在位（默认 `/home/z/my-project/repos/Deposon`，可用 `--clone` 改指他址）；
2. 双版合一线索册在位（用于第三列对照，可用 `--cluebook` 传入路径；不传则跳过该列）；
3. Python 3 标准库即可，0 第三方依赖。

## 二、运行方法（一条命令）

```bash
python3 阿兰_全锚点复测脚本.py <论文.md> \
    --cluebook <双版合一线索册.md> \
    -o <报告.md>
```

v0.3 出稿后重跑示例（关门报告）：

```bash
python3 阿兰_全锚点复测脚本.py /home/z/my-project/shared/查理_deposon双主线论文_v0.3_<日期>.md \
    --cluebook "/home/z/my-project/upload/6acc7e9dbb0dc384100096d2__dualtrack_paper_clue_book_v0-6_local_remote_2026_10_12.md" \
    -o 阿兰_全锚点复测_v0.3关门报告_<日期>.md
```

可选参数：`--no-registry`（关闭仓内登记源扫描，提速）；`--inline`（加扫正文行内锚 `` `路径` · `sha` `` 式，默认只扫附录表行 `| E\d | 路径 | sha | bytes |`）。

**退出码**：`0`＝无失配（可过门）；`1`＝存在失配-报警（不可过门）。可用于 CI 式强制。

## 三、三档判定语义（判定矩阵）

| 档 | 判定条件 | 处置 |
|---|---|---|
| **全等** | 克隆实测 sha256[:12]＋bytes 与稿值一致 | 通过。若线索册登记值与稿值不同而实测一致，自动附注登记值（已知「远端脱敏版 vs 本地原件」差，不降档） |
| **漂移-须并报** | 实测 ≠ 稿值，但稿值能在登记面对上（线索册登记 或 仓内登记源 md/json 内检索命中） | 稿值非虚构、盘上已漂移 ⇒ 论文须按分歧并报纪律在稿内登记差异（附实测值），重跑后人工确认 |
| **失配-报警** | 实测 ≠ 稿值且无任何登记可对；或路径克隆 0 命中 | **阻断项**——须查明（路径笔误/值虚构/件被改）并修复后方可过门 |

## 四、路径解析规则

- `paper/` 前缀 → 克隆根（与远端根级一致）；
- 其余路径 → 先试 `_september_workspace/<REL>`（远端登记面），次试克隆根级；
- 双址均 0 命中 → 自动按文件名全库追查同文件（报告给出「同名他址」线索，如 E19 型笔误即由此暴露）。

## 五、已知边界（如实）

1. **锚抽取面向附录表行格式**（`| E\d+ | 路径 | sha | bytes |`）；若后续稿改用其他锚格式，须先扩展 `ROW` 正则（`--inline` 可覆盖部分行内式）。
2. 线索册解析为宽松模式（反引号路径＋12hex＋数字），个别行可能漏抓/误抓——**线索册列仅为对照附注，不参与升降档**，主判据恒为克隆实测。
3. 仓内登记源扫描为全文字节检索（md/json/txt），性能约 1–2 分钟；`--no-registry` 可关。
4. 本脚本对照的「实测」基准＝克隆 `_september_workspace/` 面（即远端脱敏版）；PI 侧本地原件与远端脱敏版的已知字节差（如 〔IM〕×1 移除致 −2 B）会在附注中显示为线索册登记值≠稿值——此为正常面，读报告时先看档、再看附注。
5. 远端 git blob sha1（40 位）不在本脚本核验面（论文锚以本地 sha256 为主）；如需远端 blob 核验，另行 `git ls-tree` 对照线索册 461 表。
