## 一、本轮修复项（中英双版对称）

1. **CN 主字体三级回退链（arXiv 必要修复）**：原 `\setCJKmainfont{WenQuanYi Zen Hei}` 依赖本机系统字体，arXiv 服务器无此字体、必然编译失败。改为 `\IfFontExistsTF` 链：`FandolHei-Regular.otf`（fandol，TeX Live 自带，**文件名直载走 kpathsea，不依赖 fontconfig/系统字体**）→ Noto Sans CJK SC → WenQuanYi Zen Hei，三级均带 `AutoFakeBold=2.2`。本地实测命中 fandol 分支（tectonic 从 TeX Live bundle 实际拉取 FandolHei-Regular.otf 成功并渲染），与 arXiv 服务器解析路径一致。
2. **西文与符号兜底**：`\setmainfont{DejaVu Serif}` 包裹 IfFontExistsTF，缺失回退 Latin Modern（TeX Live 自带；TeX Live 自带 dejavu 包，arXiv 正常命中 DejaVu 分支）；★（U+2605）/≫（U+226B）的 DejaVu Sans 映射加回退 `\ensuremath{\bigstar}`/`\ensuremath{\gg}`（amssymb）。
3. **Data / Artifact availability 脚注化（中英一致）**：摘要前「数据可用性与证据强度约定」引用块 → 首页脚注 1（锚于 arXiv/Repository 头行）；文末「Artifact availability」段 → 脚注 2（锚于 §3.3 预登记锚点句末）；原孤立「¹ 项目版本与作者声明」文末注 → `\thanks` 星标脚注（∗，锚于作者名）。三条声明统一为标准脚注体系，正文无重复残留；搬移文字**逐字节取自原文**（脚本捕获，非人工转录），无任何文字改动。
4. **过程澄清（对既往轮次的更正）**：此前多轮记录的「`\usepackageargin` 残缺行」「标题 `\\m]` 残留」经本轮 od 字节级核验为**工具输出显示层假象**（`[m`/`[2m` 序列被传输层吞掉），源文件实际为完整的 `\usepackage[margin=1in]{geometry}` 与合法换行 `\\[2mm]`，无需也未曾损坏。本轮所有关键行均以 od/字节校验为准。
