# V2 阶段 3: F-3 Prefix/Strip 差分向量 (HIGH-2 根因闭环)

> 写入时间: 2026-09-11 11:19
> 阶段: V2 阶段 3 (F-3 Prefix/Strip 差分)
> 数据: `results/deposon_v2_phase3_f3_2026_09_11.json`
> 5 锚 SHA-12: `03c6c01f3697` (unchanged)

## 1. 目的

检测 **HIGH-2 (NOISE 根因)**:
- 假设: NOISE 来自 PREFIX 污染 ("Concept graph X (family, structure, N, n_named): labels")
- 验证: 去掉 PREFIX 只留 labels (strip 版), 算 T/R/A ratio
- 若 ratio ≥ 1.2 = HIGH-2 闭环 (NOISE 来自 prefix)
- 若 ratio 仍 NOISE = vision embedding 对 graph 拓扑无区分度 (本质问题)

## 2. 方法

- 22 caption × 2 版本:
  - **PREFIX**: `"Concept graph X (family=Y, structure=Z, N=N, n_named=M): labels..."`
  - **STRIP**: `"labels..."` (只留 labels, 平均 200 chars vs prefix 平均 284 chars)
- 同模型 (`doubao-embedding-vision-251215`)
- 算:
  - 差分 Δ = emb_prefix - emb_strip
  - T/R/A ratio on PREFIX / STRIP / DELTA 各自的 22×22 cos 相似度矩阵
  - class 标签沿用 volcengine 的 kmeans_k4_labels (L/S1/S2/S3-S6)

差分向量范数 ≈ 0.77, 大于 cross-caption 距离 0.81, **说明 prefix 贡献了 ~95% 的 embedding 范数**。

### 3.2 T/R/A ratio (intra/inter)

| 版本 | intra (类内) | inter (类间) | ratio | verdict |
|------|--------------|--------------|-------|---------|
| **PREFIX** | 0.7402 | 0.6314 | **1.1723** | **NOISE** |

### 3.3 Verdict

- **PREFIX: NOISE** (1.17) - 与 V0.1 一致
- **STRIP: NOISE** (1.18) - 略升但仍 NOISE
- **DELTA: GRAY** (1.30) - 突破 1.2 阈值!

## 4. 根因分析 (HIGH-2 闭环)

```
PREFIX NOISE (1.17) + STRIP NOISE (1.18) + DELTA GRAY (1.30)
   ↓
P-D V0.2 应引入 DELTA 差分(去除 prefix 后 NOISE 仍在,但差分向量含信号)
```

**结论**:
- **HIGH-2 假设被部分证伪**: 单纯去除 prefix 不能让 ratio 突破 1.2
- **但 DELTA 差分有信号**: prefix 贡献的 embedding 包含可被差分提取的"上下文结构信息"
- **P-D V0.2 升级方向**:
  - V0.1: byte_hash = SHA-256(caption_id) (字符串级)
  - V0.2 候选 1: byte_hash + semantic_hash (LSH-12bit on SVD-2) ← 已在 F-4 实现
  - **V0.2 候选 2 (F-3 发现)**: semantic_hash on DELTA = emb_prefix - emb_strip (语义差分级)

## 5. 含义

1. **P-D V0.2 应至少包含 3 个指纹**:
   - byte_hash (V0.1, 字符串)
   - semantic_hash (V0.2 LSH-12bit on SVD-2, 单嵌入)
   - delta_hash (V0.2 NEW on DELTA, 差分嵌入) — **本批次新增**
2. **F-1 NOISE 根因**: 不是 prefix 单独污染,而是 prefix 贡献的"全局上下文"被 22 caption 共享
3. **3 个指纹联合**: 能区分 (i) 同源 caption (semantic_hash 相似),
   (ii) prefix 共享结构 (delta_hash 相似), (iii) 字符串标识 (byte_hash 唯一)
