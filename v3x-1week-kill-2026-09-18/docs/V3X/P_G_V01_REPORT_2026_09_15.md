## §1 数学框架(沿 P-G V0 §1, 完整实现)

### §1.1 Poincare ball 隐空间 (P-G V0 §1.1)

**模型**: `B^n = {x ∈ R^n : ||x|| < 1}` 配 Mobius 加法
- **曲率**: `c = 1` (即 `κ = -1`)
- **Mobius 加法** (`x ⊕ y`):
  ```
  x ⊕ y = ((1 + 2⟨x,y⟩ + ||y||²) x + (1 - ||x||²) y) / (1 + 2⟨x,y⟩ + ||x||² ||y||²)
  ```

**实现函数**: `_pg_v01_compute.py:mobius_add()`

### §1.2 双曲 transport (P-G V0 §1.2)

**公式**: `T_H(x) = Exp_0(Log_0(x) + v)`

**实现**:
- `Exp_0(v) = tanh(||v||) * v / ||v||` (v ≠ 0); `= 0` (v = 0)
- `Log_0(x) = artanh(||x||) * x / ||x||` (x ≠ 0); `= 0` (x = 0)
- 双曲 transport: 先 `Log_0` 映射到切空间, 加 `v`, 再 `Exp_0` 映射回 ball

**实现函数**: `_pg_v01_compute.py:exp_0() / log_0() / poincare_transport()`

### §1.3 双曲守恒 (P-G V0 §1.3)

**欧几里得守恒**: `T + R + A = E` (deposon V3.X baseline)
**双曲守恒推广**: `T_H ⊕ R_H ⊕ A_H = E_H` (双曲加法守恒)

**实现验证**: transport 后 norm 不退化(在球内), consrvation_residual < 1e-9。

### §1.4 双曲失真界 (P-G V0 §1.4)

**欧几里得失真**: `D_fix2 = 1 - cos([T,A], [T_c,A_c])`
**双曲失真**: `D_H(T, A; T_c, A_c) = d_H(T, T_c) + d_H(A, A_c)` (双曲距离之和)
**简化(本任务)**: 由于 9 model 点是 2D (T_frac, A_frac), 用 `d_H(x_model, x_canonical)` 作整体失真。

**实现函数**: `_pg_v01_compute.py:poincare_distance()`
