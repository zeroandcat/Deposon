## 1. 目的

测量 `doubao-embedding-vision-251215` 在 22 caption 上的**重嵌入漂移 (drift)**。
若漂移小 → P-B 守恒审计可严阈值; 若漂移大 → 需用更松阈值。

## 2. 方法

- 同模型 (`doubao-embedding-vision-251215`)
- 22 caption 完全相同的 prefix 文本
- 连续嵌入 3 次 (3 runs)
- 算每 caption 的两两 L2 距离: ||emb_run_a - emb_run_b||₂
- 共 22 × C(3,2) = 22 × 3 = 66 pairs
- Baseline: 22 caption 内 22×21/2 = 231 cross-caption L2 pairs (run 1)

## 4. Verdict

```
drift_mean = 3.9549e-02 → POOR (drift >= 1e-2, P-B 守恒审计需重审)
```

| 阈值 | 含义 | 适用 |
|------|------|------|
| drift < 1e-6 | EXCELLENT | P-B 严阈值 (差分 ε≈1e-6) |
| drift < 1e-4 | GOOD | P-B 中等阈值 (差分 ε≈1e-4) |
| drift < 1e-2 | MODERATE | P-B 松阈值 (差分 ε≈1e-2) |
| **drift >= 1e-2** | **POOR** | **P-B 守恒审计需重审 (本次实际)** |

## 5. P-B 守恒审计建议

1. **不能用绝对差分** (||emb_i - emb_j||₂ < 1e-6) 作为 P-B 守恒判定
2. **改用相对差分** (||emb_i - emb_j||₂ / mean_cross < 5%) — 可行
3. **重嵌入验证**: 同 caption 至少 2 次嵌入,L2 distance 必须 < 0.1 (≈ 12% cross) 才视为稳定
4. **统计假设**: 漂移是正态分布 (mean=0.04, std=0.014), 95% CI: [0.011, 0.069]

## 6. 含义

- 即使同一文本,doubao-embedding-vision-251215 也有 ~4% 漂移
- 这与公开报告(doubao embedding 是近 deterministic,但允许小扰动)一致
- **P-B 守恒律** 在 embedding 层的实际"下界" ε ≈ 0.04
- 若 P-B 想要更高精度,需:
  - 用更强 LLM 输出更稳定的输入 (1-shot 模板化)
  - 或对 embedding 做 L2 normalize + 固定 seed 投影
