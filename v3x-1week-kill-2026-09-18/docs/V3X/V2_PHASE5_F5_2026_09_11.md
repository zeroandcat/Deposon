## 5. 解释

D 路径三模态**不满足** 1 个简单守恒律 (Fresnel / Quantum / Scattering)。

但从分解看:
- text 通道 T = 0.34 (透射)
- image 通道 R = 0.97 (反射极强, 几乎全留)
- cross 通道 A = 0.28 (跨模态吸收)

**D 路径的"散射截面"图景**:
- text 通道有 ~66% 散射 (offdiag), 剩下 34% 透射
- image 通道有 ~3.5% 散射, 几乎全反射
- text↔image 跨模态只有 28% 散射, 暗示有 **72% 信息差** (跨模态信息保留度高)

**P-B 守恒失败的根因**: image 通道 R 太高 (0.97) + cross A 太低 (0.28) 导致
T + R + A 总是 > 1。需要在守恒公式中**显式区分** R_image 的"模板冗余"和 R_text 的"信息冗余"。

## 6. P-B 候选修正

1. **R_image 修正**: 把 R_image = 0.97 替换为 R_image_corr = R_image × α, α = 信息保留因子
2. **A_cross 修正**: 显式 A_cross = (1 - ti_off) × β, β = 跨模态耦合强度
3. **新守恒律候选**: T_text + R_image_corr + A_cross = 1, 待 α, β 校准
