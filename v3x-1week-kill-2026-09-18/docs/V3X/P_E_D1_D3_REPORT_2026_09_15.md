## 4. D_fix2 阈值推荐 (待 user/Mavis 拍板)

### 4.1 推荐: **strict** (<0.05 / [0.05, 0.15) / >=0.15)

**理由 (4 条)**:

1. **失真界语义直接对应 D_fix2 数学定义** (1 - cos_sim), strict 三档口径明确反映 "高保真 / 偏离 / 显著失真"
2. **与 skill_c P-E 3modal 原阈值量级一致**: skill_c 用 `<0.30 / [0.30, 0.50) / >=0.50` (eps_3modal_sum 是模态差和, D_fix2 是角度失真, 口径不同但档数对齐)
3. **deepseek-v4-pro 是关键判别带**: strict FAIL / loose GRAY 的差异在于 D_fix2 ∈ [0.15, 0.20) 区间是否被记录为 FAIL — 这是 P-E "非平凡判别" 信号 (1/9 model 在 [0.15, 0.20) 区间)
4. **loose 7+2+0 退化到全员通过**: 与 v3 §6 表达力线 "存在失真即记录" 初衷冲突, 失去 D_fix2 metric 的存在意义

### 4.2 备选: loose (<0.10 / [0.10, 0.20) / >=0.20)

适用场景: 若 user 倾向 "宽容采样" (例如接受 deepseek-v4-pro 作为 GRAY 进一步观察), 可改 loose。但需明确放弃 v3 §6 表达力线判死, 改走 "全员通过 + GRAY 长期观察" 路线。
