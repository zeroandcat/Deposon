## §2 不变原则 4 → 8

**V1 四条(保留, 出处 P-D V0.1.1)**:
1. successor 永不信子代理自报数字 → 必后置复跑
2. spec 必含 verify_X 接口
3. 数字溯源 = 重读 JSON 字段
4. 冻结工件零触碰(/tmp 副本)

**V2 新增四条(出处见 §1)**:

5. **四一致原则**(E1/E2/E6): 任何计算结果落盘前, 参数(全声明值)、公式(含全部项)、数值(由公式重算而非粘贴)、口径(同一物理量同一名称)四者必须一致。表值必须由公式**重新计算**一遍, 不允许复制中间结果。
6. **判定线双预原则**(E8/E9/E10): 判定线必须(i)**预注册**——计算数字之前锁定阈值与口径, 写在报告独立小节; (ii)**双源稳健**——换第二数据源重算, 判定线不得失效(分母为零/恒等/∞ 均为失效); 任何"提升 X×"声明必须附 Spearman 排序增量(区分标度放大与信息增加)。
7. **工件三件套原则**(E4/E5): 任何 hash 值落盘, 必须同时具备: ①输入字符串(或输入数据指针) ②算法描述(可复现级别) ③**真实存在的脚本路径**(引用前必 Test-Path)。三缺一 = 不可审计值, 只能标 UNVERIFIED。
8. **勘误追加原则**(E17/E18): 修错不重写历史——erratum 追加块 + `pre_erratum_file_sha12` 保链; **生产方原始工件(脚本/输入串)第三方不可代写**(代写=伪造), 只能标注并退回生产方落盘。

## §4 环境操作手册(Win/PowerShell/沙箱/web, successor+data 共用)

1. **多行 Python**: 禁 PowerShell here-string 内联 → 写临时 .py 到 repo 外(如 `C:\tmp\`), `python -B <path>` 执行, 用后删
2. **沙箱**: `-B` 防止 `__pycache__` 写入; 避免 `ast.unparse` 等隐式编译操作(改子串检查)
3. **红色 PSSecurityException**: profile 快照无害噪音, 判定以**退出码 + 实际输出**为准
4. **web 官方源**: 首轮不中 → 加 `site:` 域名过滤 + 纯英文术语 + 换同义词, **不换平台**; 官方文档用 WebFetch 直抓(docs.nvidia.com 等效果好)
5. **Embedding API 调用**: 分块(10/批)+ 块级失败只降级该块条目 + 保持 no-retry 铁律; 代理场景必须 `install_opener(build_opener(ProxyHandler({})))`(env 清理不够, Windows 读注册表)
