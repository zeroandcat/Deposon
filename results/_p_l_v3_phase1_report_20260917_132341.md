## §2 P1 尺寸标度 (Size Scaling)

### §2.1 单 backbone fit (30/45/100) — 主指标

- **数据点** (Mistral Large 2512, 同一 backbone):
  - L=30: O = 0.8000
  - L=45: O = 0.5111
  - L=100: O = 0.4600
- **log-log fit**: log(O) = 1.0731 + (-0.4140) * log(L)
- **R^2** = **0.7447** (阈值 ≥ 0.9 = 幂律成立)
- **slope** = -0.4140 (幂律指数估计, 期望负或接近 0)
- **p-value** = 0.337203
- **verdict** = **FAIL** (无幂律 (<0.9))

**老实交代**: R^2 = 0.7447 < 0.9 → size scaling 在 30/45/100 cells 区间不成立. 原因可能是 (a) Mistral Large 2512 单 backbone 不足以覆盖 size scaling 信号, (b) StrategyQA subset 新增 cells (15+70) 难度分布偏移导致 accuracy 单调下降, 或 (c) 三点拟合本身统计力不足 (n=3). 需 P2 跨 backbone β CI 检查.

### §2.2 含 60 档 fit (cross-backbone aggregate, 仅 reference)

- **数据点**: L=30:0.8000, L=45:0.5111, L=60:0.7111 (9 model mean), L=100:0.4600

### §3.1 单 backbone 主曲线 + 归一化残差

- **主曲线**: O(L) = exp(1.0731) * L^(-0.4140) = 2.9243 * L^(-0.4140)
